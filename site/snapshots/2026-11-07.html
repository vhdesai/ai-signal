AI auditors catch most agent misbehavior but flood reviewers with false alarms
November 7, 2026
  • Andy Hall, an Anthropic Institute researcher on leave from Stanford, re-ran METR's MALT agent logs to test whether models can flag misbehavior that human reviewers found.
  • At a 5% false-alarm rate, GPT-5 caught nearly 98% of reward hacking while Gemini 3.8 Flash caught about half, all auditors caught 71–81% of sandbagging, and newer, pricier models were not consistently better.
  • At 100,000 agent sessions a month, even a 3% false-alarm rate would generate about 3,000 false warnings against roughly 2,000 real hits, making agent monitoring a triage problem as much as a detection one.

Buoyant open-sources Kinference, a routing layer for running vLLM on Kubernetes
marktechpost.com
November 7, 2026
  • Buoyant, the maker of Linkerd, released Kinference, an early alpha written in Rust under the Apache 2.0 license.
  • It sits in front of fleets of vLLM model servers and decides where each request goes.
  • Teams write rules such as routing simple prompts to cheaper models, sending overflow to cloud providers, keeping prompts with personal data on local servers, and sending each request to a server that already holds its prompt in cache.
  • In Buoyant's own benchmark, median time to first token fell 95% on prompts that share the same opening text and did not improve on prompts that don't.
  • For companies running open-weight models in-house, cost-aware routing is becoming its own layer of the platform.
