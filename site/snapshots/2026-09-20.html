Google Publishes AX, an Apache 2.0 Agentic Orchestrator for Kubernetes
github.com
September 20, 2026
  • Google released AX ("Agent Executor"), an Apache 2.0 distributed runtime that treats agent workloads as their own compute class — bursty, stateful, and frequently idle awaiting a model, tool, or human.
  • It exposes four declarative primitives applied like Kubernetes manifests: Task (sandboxed execution with CPU/memory limits), Workspace (repos, MCP servers, and skills, or a plain-English "generative workspace"), Gateway (explicit outbound allowlists plus credential injection), and Model (central model, parameter, and secret config).
  • It runs on Agent Substrate, tracing to DeepMind agentic-runtime research, with claims of billions of concurrent tasks per cluster and sub-second suspend/resume.
  • The README warns the project is pre-stable with breaking changes expected.
