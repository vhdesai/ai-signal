marktechpost.com
November 9, 2026
  • Aspen is a single program written in Rust that stores branches in PostgreSQL or SQLite and stores code in object storage.
  • It updates each branch independently, so pushes to different branches never wait on each other, following the design OpenAI described for its internal Pando server.

  • Source control is becoming a bottleneck as companies run hundreds of coding agents at once.
