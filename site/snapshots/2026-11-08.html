AWS engineer says the key control for coding agents is the list of actions they may take without approval
businessinsider.com
November 8, 2026
  • David Yanacek, a senior principal engineer at AWS, says he spends most of his time maintaining the "auto-trust" file that sets which tools and commands an agent may run on its own and which need a person's approval.
  • He describes the ideal engineer as "paranoid and lazy": alert to what could go wrong, and unwilling to do repetitive work by hand.

  • Companies should treat agent permission files as security-relevant configuration, with owners, reviews, and audits.

Google's Elephant-Goldfish plugin makes coding agents write a spec and have it reviewed before writing code
marktechpost.com
November 8, 2026
  • The Apache 2.0 plugin works in Antigravity, Claude Code, Codex, ChatGPT, and other tools.
  • It has a long-running agent session draft a design document.
  • Fresh helper agents with no conversation history then review it in five stages, ending with an implementation-readiness check, before any code is written.
  • Google says thousands of its engineers use it.
  • The project has not published accuracy benchmarks, uses a lot of tokens, and has an open issue about project files leaking into the reviewers' context.
  • Google first announced the plugin in late October; this coverage reflects newly documented support for more coding tools.
  • It reflects a broader move to catch AI-generated errors at the design stage instead of in code review.
