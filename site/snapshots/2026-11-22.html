Google previews Tool Retrieval in the Gemini API for agents with large tool libraries
November 22, 2026
  • Google launched Tool Retrieval in preview in the Gemini Interactions API, letting agents keep large tool libraries available without sending every parameter schema in every prompt; the model sees only each tool's name and a short description and loads the full schema when a task needs it.
  • Google's documentation notes that a few dozen function declarations can otherwise consume tens of thousands of tokens per request.
  • In server-side mode, search, schema loading and the function call resolve in a single API request and work with remote MCP servers, though Google still recommends static loading for fewer than 20 stable tools.

Microsoft AI's Suleyman says models now help improve their successors, and he's "really, really nervous"
November 22, 2026
  • In an interview with Deirdre Bosa recorded at Ignite, Microsoft AI CEO Mustafa Suleyman said models inside Microsoft are increasingly "fully involved" in improving their successors by checking for bugs, producing training data and building evaluations.
  • He called recursive self-improvement "definitely a dangerous capability," described the past three months as "a total watershed moment" and said industry warnings are not alarmist.
  • His prescription is to prove models safe step by step before they reach production, with engineers still in the loop.
