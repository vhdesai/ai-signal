Shepherd: an open-source substrate that lets meta-agents fork, replay, and revert any agent run
August 8, 2026
  • Researchers at Northeastern and Stanford released Shepherd, an MIT-licensed Python runtime that records an agent's execution as a Git-like trace of typed events, so any prior state — including the live process and filesystem via copy-on-write — can be forked and replayed.
  • Reported gains include forks 5× faster than Docker and over 95% prompt-cache reuse on replay.
  • In demonstrations, a live supervisor lifted CooperBench pair-coding pass rates from 28.8% to 54.7%, and forked RL rollouts improved Terminal-Bench 2 from 34.2% to 39.4%.
  • It ships as an early alpha.
