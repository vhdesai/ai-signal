qwenGPU builds a working GPU into Qwen3.5-2B's weights that runs real CUDA code
marktechpost.com
November 2, 2026
  • An independent developer added 45 untrained layers, with weights calculated by a compiler, to Qwen3.5-2B.
  • The layers implement a small four-lane GPU that executes real CUDA code inside the model's forward passes.
  • In the developer's tests, every program launch produced exact results, the reference interpreter matched an NVIDIA T4 on 49 of 49 programs, and the model's normal text output changed only negligibly.
  • Throughput is about 10 to 15 tokens per second, so this is a research demonstration of exact computation inside an LLM, not a practical tool.
