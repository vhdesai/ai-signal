# OpenClaw 2.0 ships the open-source AI client's largest-ever update

Version 2026.8.1 lands with 933 contributors and more than 16,000 merged pull requests. Installation now reuses existing ChatGPT/Claude subscriptions, API keys and local models; a rebuilt Control UI cut test-harness startup from ~1.6s to 575ms; and sessions move into SQLite with one trust boundary per gateway. A first-class browser app and shared cloud sessions enable multi-user context handoff.
