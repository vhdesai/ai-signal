# Runway Unveils Solaris, Its First “Interface World Model”

Runway introduced Solaris, a real-time model that generates interactive software interfaces frame-by-frame — treating a user interface as a live visual world rather than as rendered code. It is built on Runway’s Gen-4.5 model. In a 250-participant study, evaluators preferred Solaris over Claude Opus 5–coded interfaces in 61% of instruction-following comparisons and 71% of natural-behavior comparisons. Early access is available by request.
