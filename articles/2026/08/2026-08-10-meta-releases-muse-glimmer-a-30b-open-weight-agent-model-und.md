# Meta releases Muse Glimmer, a ~30B open-weight agent model under Apache 2.0

Meta Superintelligence Labs released Muse Glimmer, a roughly 30-billion-parameter dense open-weight model with a perception encoder, tuned for multi-step tool use, coding, multimodal understanding and long-running local agents. Weights ship under the permissive Apache 2.0 license, and quantized builds are reported to run in roughly 18GB of memory on a single GPU. Nvidia published deployment recipes and cites a 120K+ token context window. Meta has also signaled it will release Muse Spark 1.2 weights, extending the open push.
