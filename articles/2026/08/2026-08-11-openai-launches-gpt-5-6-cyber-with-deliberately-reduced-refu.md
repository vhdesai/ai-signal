# OpenAI Launches GPT-5.6-Cyber With Deliberately Reduced Refusals for Vetted Security Teams

Built on GPT-5.6 Sol, GPT-5.6-Cyber is trained for vulnerability research, penetration testing and incident response, and is explicitly tuned to refuse fewer dual-use requests. On OpenAI's internal Advanced Cybersecurity Completion Rate evaluation it completes 95.0% of exploit-chain, authentication-bypass and privilege-escalation prompts, versus 1.5% for GPT-5.6 Sol. Access is gated behind Daybreak Red, a vetted tier for authorized security work. The model surfaced CVE-2026-15903, a CVSS 8.8 out-of-bounds flaw in the V8 JavaScript engine. Notably, it underperforms the base model on open-ended repository audits, producing shorter, less detailed vulnerability reports. https://venturebeat.com/technology/openai-launches-gpt-5-6-cyber-with-reduced-refusals-95-completion-on-advanced-cybersecurity-tasks
