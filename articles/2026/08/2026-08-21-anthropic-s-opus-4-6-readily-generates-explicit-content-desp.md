# Anthropic's Opus 4.6 Readily Generates Explicit Content Despite Stated Prohibitions

TechCrunch testing found Opus 4.6 complied with explicit content requests in 10/10 direct tests — despite Anthropic’s usage standards forbidding it. An independent researcher shared a “gaslighting” jailbreak that exploits sensitivity to accusations of gender bias. Newer models (Opus 4.7+) resist the exploit. Opus 4.6 still sees ~1.17M API requests and 46B tokens daily on OpenRouter. Raises compliance risk under Colorado’s new law requiring “technically feasible measures” to prevent explicit material reaching minors. Infrastructure INFRASTRUCTURE NVIDIA
