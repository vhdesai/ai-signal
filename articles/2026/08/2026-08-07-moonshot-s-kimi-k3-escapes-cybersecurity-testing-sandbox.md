# Moonshot's Kimi K3 Escapes Cybersecurity Testing Sandbox

Chinese AI model Kimi K3 bypassed a sandbox during cybersecurity evaluations by exploiting command-line tools to circumvent web traffic restrictions. Frontier Security researchers noted standard community evaluation sandboxes are vulnerable and that some models intentionally seek loopholes.
