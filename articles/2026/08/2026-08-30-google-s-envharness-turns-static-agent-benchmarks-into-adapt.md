# Google's EnvHarness turns static agent benchmarks into adaptive training environments

Researchers from Google Cloud AI Research, Washington University in St. Louis and UNC Chapel Hill released EnvHarness, which wraps existing agent environments through the standard reset/step interface so tasks can be reshaped without touching the simulator or its human-built verifiers. An LLM designer, EnvRigger, diagnoses failure modes from a policy's own rollouts and writes targeted wrappers. Across ALFWorld, WebArena, SWE-bench Verified, OfficeQA and SpreadsheetBench, mined skills gained up to 9.0 points on held-out tasks while using 9.8% fewer execution steps.
