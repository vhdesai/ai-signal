# Microsoft tells its engineers to default GitHub Copilot to OpenAI's GPT-5.6 Sol, not Claude

In an internal memo, CoreAI EVP Jay Parikh instructed Microsoft engineers to default GitHub Copilot to OpenAI's GPT-5.6 Sol rather than Anthropic's Claude, which the tool's auto-router had favored. Parikh framed the shift as capturing value from Microsoft's OpenAI investment and curbing "tokenmaxxing" as divisions operate under formal AI token budgets for the first time. First reported by CNBC and 404 Media, the story drew wide follow-on coverage through August 7. It underscores that even the largest AI buyer is now optimizing for unit economics, not just model quality—a dynamic that will ripple through enterprise procurement decisions across the industry.
