# Anthropic makes Claude Code's auto mode the default for paid users

Anthropic is enabling Claude Code's auto mode by default for paid users, shifting the coding agent toward greater autonomy without per-step confirmation. Auto mode was first introduced as a test in March as a balance between speed and human control. Making it the default changes the risk posture of every team already running the tool.
