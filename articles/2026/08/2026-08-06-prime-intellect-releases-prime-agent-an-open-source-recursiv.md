# Prime Intellect releases Prime Agent, an open-source “Recursive Language Model” harness

Prime Intellect released Prime Agent, an MIT-licensed self-improving coding/research harness built on a Recursive Language Model — sub-agent calls become functions inside a persistent IPython kernel — paired with a self-editing “Continual Harness.” Running with Opus 5, it reports 95.5% Best@1 on ARC‑AGI‑3, edging the reported human-expert baseline of 95.4%. The headline benchmark is self-reported and awaits independent replication.
