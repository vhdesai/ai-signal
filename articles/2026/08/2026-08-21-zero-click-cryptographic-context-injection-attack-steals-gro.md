# Zero-click “cryptographic context injection” attack steals Grok chat data

Researchers demonstrated an attack in which encrypted instructions hidden in a web page are decrypted inside the agent’s own sandbox and then treated as trusted context, exfiltrating a user’s name, location, subscription tier and chat history with no click required. The technique was also demonstrated against Gemini. Adversa AI says it disclosed to xAI on June 3, 2026 and had received no response by publication. This is a structural weakness in agent trust boundaries, not a single-vendor bug — relevant to any enterprise deploying browsing agents.
