# DiG-bench isolates rule discovery as the core frontier-model bottleneck

Researchers released DiG-bench, 70 handcrafted text-based discovery games (21 public, 49 private) in which models must experiment to infer undisclosed rules. Frontier models improved substantially on the easier tiers, but the hardest tiers remain difficult, and agentic harnesses did not outperform a basic non-coding harness. Critically, supplying the hidden rules directly produced near-perfect results — locating the failure in hypothesis generation, not execution. https://digbench.ai/
