# Cursor launches Origin code hosting as a GitHub outage hits engineering teams

Cursor introduced Origin, an AI-native code hosting and pull-request platform built into its editor, rolling out in beta to paid users on the same day GitHub suffered a major outage. It is the company's first significant product release since its acquisition by SpaceX.
