# Anthropic Previews Model Hardware Standard to Let Agents Operate Physical Machines

Anthropic introduced the Model Hardware Standard, a protocol for letting AI agents interface with and operate physical machines, released initially as a research preview with a stated intent to open source it later. It extends the company's pattern of standardizing the agent-to-external-system interface, following its earlier work on tool/context protocols. For industrial and operations leaders, this is an early signal that agent governance scope will need to expand from software actions to actuated equipment.
