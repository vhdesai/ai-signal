# Google open-sources HEIR, a compiler that runs AI inference on encrypted data

Google published HEIR, an open-source compiler toolchain that converts pre-trained models to run inference directly on homomorphically encrypted inputs, so a server can compute without ever seeing the underlying data. Google demonstrated four applications — private content recommendations, credit-card fraud detection, encrypted network anomaly detection, and hotword detection — all compiled with HEIR on single-threaded CPU. The stated goal is a one-click path for non-experts, though cryptographic overhead still varies sharply by operation.
