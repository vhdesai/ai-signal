# Liquid AI releases LFM2.5-2.6B, a powerful model that runs on a Raspberry Pi

Liquid AI released LFM2.5-2.6B, a 2.6B-parameter open-weight model with a 128K context window and native tool calling that “can run entirely on local hardware — from smartphones and laptops down to a Raspberry Pi — without relying on cloud inference or GPUs.” It shipped on Hugging Face with day-one support for llama.cpp, MLX, vLLM, SGLang, and ONNX. The launch underscores momentum toward capable agents running fully on-device.
