# Google Open-Sources HEIR: Inference on Encrypted Data

HEIR converts trained models to run inference under homomorphic encryption — the server computes without seeing the data. Demos: private recommendations, fraud detection, encrypted network anomaly detection, hotword detection. Overhead varies dramatically by operation, so not a drop-in replacement. But it is the most credible path for regulated-data inference where the model host cannot be trusted with plaintext — directly relevant to healthcare, finance, and defense use cases where data sovereignty currently prevents cloud inference.
