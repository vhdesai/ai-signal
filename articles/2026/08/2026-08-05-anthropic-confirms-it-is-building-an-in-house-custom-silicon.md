# Anthropic Confirms It Is Building an In-House Custom Silicon Team

Anthropic publicly acknowledged for the first time that it is standing up an internal silicon team to co-design chips and models so Claude runs faster and more efficiently at scale, and hiring has begun. The company says it still intends to use hardware from AWS, Google, Nvidia, and AMD rather than consolidate on a single supplier.
