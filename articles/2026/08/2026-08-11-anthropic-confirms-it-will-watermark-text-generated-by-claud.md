# Anthropic Confirms It Will Watermark Text Generated by Claude

Anthropic confirmed in an updated support document that it will apply invisible, text-native watermarks to output from new Claude models, to comply with European regulations. The watermark is encoded statistically in token selection rather than stored as strippable metadata, so it survives copy-paste and light editing. Google has used a comparable token-bias approach for Gemini text since 2024, making Anthropic the second major lab to adopt it. Enterprises should expect provenance detection of AI-generated text to become a compliance-auditable capability, not a research curiosity. POLICY
