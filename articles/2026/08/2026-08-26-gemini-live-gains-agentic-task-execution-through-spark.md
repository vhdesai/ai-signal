# Gemini Live gains agentic task execution through Spark

Google shipped an agentic upgrade to Gemini Live, integrating it with Spark so users can set up multi-step tasks by voice that then run on their own across Google Docs, Sheets, Drive, and the web. Google says Spark handles long-running and scheduled jobs spanning days or weeks even when the user is not in the app, and that Gemini Live now retains context across past conversations and connected Google apps. The release also adds a spoken Daily Brief consolidating Gmail and Calendar, plus hands-free inbox triage. The strategic read is that voice is being positioned as the entry point to background agent execution rather than as a query interface.
