# Code-as-World turns real videos into executable MuJoCo physics programs

MirroS released Code-as-World, an agentic loop that converts real video into executable world representations that can be run in MuJoCo. The system proposes, instantiates, executes, renders, and verifies scene programs over multiple rounds, then uses verified worlds as training data with exact physical labels. The approach is relevant for robotics and simulation because it treats video as evidence for recoverable physics, not just pixels to predict. ENTERPRISE AIAGENT GUARDRAILS
