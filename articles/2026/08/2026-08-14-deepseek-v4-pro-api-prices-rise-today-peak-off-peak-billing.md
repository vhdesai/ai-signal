# DeepSeek V4-Pro API Prices Rise Today — Peak/Off-Peak Billing Now Live

DeepSeek's steep API repricing takes effect today (August 16), with new peak and off-peak tiers replacing flat-rate pricing. Reported increases range from 50% to 1,100% depending on the workload and time of day. V4-Pro rates run at several multiples of V4 Flash. Even after increases, DeepSeek remains cheaper than most Western frontier alternatives — but the cost gap that drove Chinese-model adoption in price-sensitive workloads is narrowing materially. Enterprises that standardized on DeepSeek for cost arbitrage should re-baseline unit economics this week.
