# Tencent unveils Hy4 preview — a 770B-parameter open-source model

Tencent released a preview of Hy4, an open-source model with 770B total parameters (~49B active per request) and a 1M+ token context window, targeted at practical work: coding, financial and data analysis, document and presentation creation, and playable game prototypes. Tencent's own blind evaluation (163 experts, 203 tasks) scored Hy4 at 2.99/4 against Z.ai's GLM-5.3 (2.92) and Moonshot's Kimi K3 (2.94) — an internal, non-independent benchmark. Access is via Tencent's CodeBuddy, WorkBuddy, Yuanbao and ima products, plus APIs. Note: release trackers log the preview itself as August 28; this write-up is August 30.
