# DeepSeek V4 Pro GA + Sharp Price Increases (Effective Aug 16)

V4 Pro goes GA with agentic capabilities and OpenAI API support. Flat-rate pricing ends Aug 16 with peak/off-peak billing — increases of 50%–1,100%. Peak: up to $1.32/M input, $3.96/M output. Still cheaper than most Western alternatives. Also open-sourced Harness, a modular agent runtime (27.5K GitHub stars day one). The company that proved cheap inference is now testing willingness to pay for premium performance while moving up the orchestration stack. Cost-driven buyers should re-baseline immediately.
