# OpenAI's Jalapeño Chip Outperforms Nvidia Blackwell on Inference Benchmarks

At Hot Chips, OpenAI shared first benchmarks for Jalapeño, its custom inference ASIC built with Broadcom. On SemiAnalysis’ InferenceX benchmark, it showed more tokens per user and more throughput per kilowatt than Nvidia Blackwell. Head of hardware Richard Ho said deployment begins in “very small volumes” by end of 2026. The chip minimizes data movement by keeping model state local, addressing prefill and communication bottlenecks. OpenAI plans it as a multigenerational platform.
