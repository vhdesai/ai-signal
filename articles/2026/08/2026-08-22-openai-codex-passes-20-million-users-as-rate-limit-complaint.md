# OpenAI Codex Passes 20 Million Users as Rate-Limit Complaints Mount

OpenAI’s Codex reached 20 million active users. Developers report quotas depleting faster than expected; OpenAI attributes drain to “sub2api” credential resale rather than limit changes. For engineering leaders, coding-agent capacity—not model access—is becoming the practical procurement constraint.
