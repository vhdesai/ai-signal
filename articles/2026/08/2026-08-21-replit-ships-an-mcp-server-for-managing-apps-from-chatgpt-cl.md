# Replit ships an MCP server for managing apps from ChatGPT, Claude and Slack

Replit released an MCP server that lets users create, inspect, update and publish Replit apps directly from ChatGPT, Claude, Slack or any MCP client. The release also adds workspace region selection and team-shared skills. It is a further sign that MCP is consolidating as the default interoperability layer between assistants and developer platforms.
