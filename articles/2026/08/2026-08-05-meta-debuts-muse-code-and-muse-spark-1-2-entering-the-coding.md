# Meta debuts Muse Code and Muse Spark 1.2, entering the coding-agent market

Meta released Muse Code, its first coding agent, powered by a co-trained Muse Spark 1.2 model and built around a terminal interface with persistent asynchronous background agents. The launch places Meta directly against Anthropic’s and OpenAI’s coding products, the highest-revenue agentic category to date. Reporting notes the default onboarding path routes developer code and prompts into Meta’s training pipeline unless explicitly opted out — a material procurement consideration for enterprises with proprietary codebases. Early analyst commentary is that the architecture is competitive but not yet differentiating. OPEN WEIGHTS
