# OpenAI launches Codex Security in research preview

OpenAI released Codex Security, an open-source CLI and code-review tool that analyzes diffs and pull requests, flags vulnerabilities with severity scores, and offers remediation guidance. Available to Enterprise, Business, Edu, and Pro customers, it notably lands the same week as fresh disclosures about agent security incidents—positioning OpenAI to capitalize on the very concerns its agents helped create. For security teams, the tool offers a new layer of automated code review; for the market, it signals that AI-native security tooling is becoming a competitive differentiator as code-generation scales and attack surfaces expand.
