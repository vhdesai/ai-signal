# Tencent Open-Sources TencentDB Agent Memory v2.0 — Team-Level Memory for AI Agents

Tencent Cloud released TencentDB Agent Memory v2.0 (MIT license), a self-hosted memory hub letting AI agents share context across a team. Converts conversations and code into four versioned, access-controlled memory assets: Chat Memory, Skill, Wiki, and CodeGraph. Key differentiator is governance — visibility runs private/team/restricted with ACL-based binding. Reports PersonaMem accuracy improving from 48% to 76%. Deploys via Docker with Claude Code, OpenClaw, and SDK integrations. ________________________________ 🔬 Research Breakthroughs RESEARCH AGENTS
