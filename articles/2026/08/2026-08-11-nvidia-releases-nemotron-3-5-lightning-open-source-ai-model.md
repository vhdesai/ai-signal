# Nvidia Releases Nemotron 3.5 Lightning Open-Source AI Model

Nvidia's Nemotron 3.5 Lightning is a lightweight model designed to run on a single GPU, free for companies to download, use, and modify. The model was developed for agentic workloads using distillation from larger Nemotron models. Nvidia also released NeMo Switchyard, a model router that determines the cheapest and most appropriate AI model for any given task.
