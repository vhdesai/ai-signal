# Anthropic Details How Claude's Watermark Works — and Where It Fails

Anthropic published a technical explainer for the invisible text watermark it began applying globally on August 2 under the EU AI Act Transparency Code. The watermark uses Google DeepMind's SynthID-Text approach; detection is reader-imperceptible and cost-neutral but degrades sharply on code and factual text where token choice is constrained, and disappears entirely when Claude only edits human-written material or output is completely rewritten. Anthropic frames the mark as evidence Claude "likely contributed," not proof of authorship. The company plans to release a detection API and notes that ~190 EU Code of Practice signatories will implement comparable marks — provenance checking is becoming an industry baseline.
