# Meta Ships Muse Glimmer, a 30B Open-Weight Agentic Model That Runs Locally

Meta released Muse Glimmer, a 30-billion-parameter agentic model distilled from Muse Spark and designed to run on a single consumer GPU, with weights distributed via Hugging Face. It targets agent-style work — multi-step task decomposition, scheduling, file organization — without cloud dependency. Meta says an open-weight version of the larger Muse Spark will follow. The release accompanied a 6,500-word Mark Zuckerberg essay, "The Future Is for Everyone," arguing against concentrating advanced AI in a small number of institutions, positioning Meta explicitly opposite OpenAI and Anthropic in the open-versus-closed debate. https://www.forbes.com/sites/jonmarkman/2026/08/11/meta-unveils-muse-glimmer-a-30b-parameter-ai-model-that-runs-locally/
