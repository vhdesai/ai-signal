# Google researchers introduce EnvHarness for adaptive agent training environments

Researchers from Google Cloud AI Research, Washington University in St. Louis, and UNC Chapel Hill released EnvHarness, a programmable layer that wraps static agent benchmarks through standard reset/step interfaces. Instead of generating entirely new environments, EnvHarness modifies start states, action constraints, observations, and environment composition while preserving human-built verifiers. Reported gains include up to 9.0 points on held-out tasks and 9.8% fewer execution steps on SWE-bench Verified, making this relevant to enterprises building agent evaluation loops.
