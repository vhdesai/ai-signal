# Claude Gets Unified Memory Across Chat and Cowork — No More Rebriefing

Anthropic merged Claude’s memory between Chat and Cowork so the AI retains context across research and execution — ending the frustration of repeatedly briefing Cowork on things discussed in Chat. Memory updates in real-time during conversations, and users can read/edit/delete stored info. Sensitive data excluded by default (opt-in available).
