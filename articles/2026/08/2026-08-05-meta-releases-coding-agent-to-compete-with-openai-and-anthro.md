# Meta Releases Coding Agent to Compete With OpenAI and Anthropic

Meta released a new AI coding agent designed to compete directly with OpenAI's Codex and Anthropic's Claude Code, marking the company's most significant entry into the developer-tools market. The agent is built on Meta's Llama model family and is being positioned as an open-weight alternative to proprietary coding assistants. The launch is strategically important because it extends the Llama ecosystem from general-purpose inference into the high-value, high-retention developer workflow category — where OpenAI and Anthropic have built significant commercial traction. For engineering leaders, Meta's entry adds a third credible option for enterprise coding-agent adoption, potentially improving pricing dynamics and reducing single-vendor lock-in risk.
