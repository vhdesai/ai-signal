# Auto Mode Is Now the Default in Claude Code for Pro, Max, and Team Plans

Anthropic will make auto mode the default for new Claude Code sessions on Pro, Max, and Team plans starting August 14, replacing per-tool-call approval prompts with a classifier that blocks irreversible, destructive, or externally directed actions. In a controlled study with 1,053 paid testers, human reviewers caught 13.6% of dangerous commands versus 89% for auto mode, and human vigilance decayed with session length while the classifier’s did not. A third-party evaluation by Trajectory Labs recorded zero successful attacks across 720 indirect prompt-injection attempts against Claude models in auto mode. Enterprise and API remain opt-in for now. OPEN SOURCE
