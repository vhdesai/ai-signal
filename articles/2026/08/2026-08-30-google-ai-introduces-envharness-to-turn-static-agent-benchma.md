# Google AI introduces EnvHarness to turn static agent benchmarks into adaptive training worlds

Researchers from Google Cloud AI Research, Washington University in St. Louis, and UNC Chapel Hill released EnvHarness, an Apache-2.0 programmable layer that wraps existing agent environments through standard reset and step interfaces. The system uses an LLM designer called EnvRigger to diagnose failure modes and write targeted wrappers. Reported gains include up to 9.0 points on held-out tasks and 9.8% fewer execution steps across five benchmarks.
