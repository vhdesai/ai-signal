# Alibaba Cloud Opens First Brazil Region with Agentic-AI Services

Alibaba Cloud brought two São Paulo data centers online, its first cloud region in Brazil, offering cloud plus agent-based AI services and in-region data residency. The launch extends Alibaba’s multi-billion-dollar overseas AI infrastructure push into Latin America’s largest economy. It is a reminder that the compute buildout is now a geographic land-grab as much as a technical one.
