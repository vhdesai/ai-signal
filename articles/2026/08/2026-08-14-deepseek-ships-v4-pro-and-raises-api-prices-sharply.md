# DeepSeek Ships V4 Pro and Raises API Prices Sharply

DeepSeek moved V4 Pro out of preview with stronger agentic capabilities, adjustable reasoning, and native OpenAI Responses API support. Simultaneously it ends flat-rate pricing with peak/off-peak billing effective August 16 — increases reported at 50% to 1,100% depending on workload. Published peak pricing: up to $1.32/M cache-miss input and $3.96/M output tokens. Even after increases, DeepSeek remains cheaper than most Western alternatives. The company also open-sourced Harness, a modular agent runtime positioned against Claude Code. The direction matters: the company that proved cheap inference is now testing willingness to pay for premium performance while moving up the orchestration stack.
