# Ramp launches its own AI model router, called Router

Ramp launched Router, an API service that lets companies switch between large language models without rebuilding integrations, positioned explicitly at reducing inference spend. The launch lands days after Stripe's move to acquire OpenRouter, signaling that fintech incumbents see model routing as an extension of spend management. Routing is consolidating into a control point worth owning. AGENTS
