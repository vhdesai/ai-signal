# Cursor capitalizes on GitHub frustration, launches rival hosting platform

Cursor launched Origin, a code hosting platform covering repositories, pull requests, reviews and merges, designed around AI coding agents rather than human-first workflows. The launch landed alongside a GitHub outage and is Cursor's first major product move since its acquisition by SpaceX closed. Independent coverage flagged that early beta terms did not publish data retention or training-use policies — a material diligence item before any enterprise pilot.
