# Supabase releases an open-source benchmark for Claude Code, Codex, and OpenCode

Supabase released Evals, an open-source benchmark that scores Claude Code, Codex, and OpenCode on real Supabase tasks, according to MarkTechPost. The launch is notable because coding-agent competition is shifting from generic benchmarks toward workload-specific evals that reflect actual repository maintenance and product engineering tasks. For engineering leaders, the takeaway is that agent procurement should be grounded in internal task suites, not vendor demos.
