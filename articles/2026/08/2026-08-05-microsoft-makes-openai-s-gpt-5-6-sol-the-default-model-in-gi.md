# Microsoft makes OpenAI's GPT-5.6 Sol the default model in GitHub Copilot for staff

In an internal memo, Microsoft CoreAI EVP Jay Parikh told engineers to default to OpenAI's flagship GPT-5.6 Sol in GitHub Copilot, writing that shifting more workloads to OpenAI models helps Microsoft get greater value from its token investment. The move is explicitly about extracting return on Microsoft's OpenAI IP rights rather than pure capability ranking. It reflects a broader industry pivot from maximizing token consumption toward AI spend efficiency. Microsoft said Copilot now has 50 million users.
