# OpenAI launches ChatGPT desktop app for Linux

OpenAI released a preview ChatGPT desktop app for Linux, extending ChatGPT, ChatGPT Work, and Codex across the major desktop operating systems. Initial support covers Ubuntu 24.04 and 26.04 LTS, Debian 13, and Fedora 43 and 44. The move is strategically modest but important for developer adoption, especially as AI coding tools compete for open-source and Linux-heavy engineering workflows. ENTERPRISEAGENTS
