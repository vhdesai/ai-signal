# OpenAI introduces "Ultrafast" tier for GPT-5.6 Sol, powered by Cerebras

OpenAI added a new API service tier that runs GPT-5.6 Sol up to 14× faster, aimed at latency-sensitive agentic and interactive workflows. The tier runs on Cerebras hardware, marking one of the clearest instances yet of a frontier lab diversifying inference silicon away from GPUs. Cerebras separately teased a flagship product event the same day.
