# NVIDIA Releases NemotronLabs VoiceChat 11B — Open Full-Duplex Speech Model

NVIDIA released an open 11B end-to-end speech-to-speech model collapsing the traditional ASR→LLM→TTS cascade into a single hybrid Mamba/Transformer network. Turn-taking latency: 448ms. It is the first open full-duplex model to support tool calling via a side output channel while conversation continues. Licensed under OpenMDW-1.1 (research-only); requires one 80GB GPU. Ranks #2 on VoiceBench.
