# OpenAI’s GPT-5.6 Family Lands in AWS Kiro Coding Agent

GPT-5.6 Sol, Terra, and Luna are now selectable inside Kiro for planning, building, reviewing, and testing workflows. Joint optimization reportedly delivered ~82% lower cost on Terminal-Bench 2.1 tasks. Reinforces multi-model coding environments where model choice is a per-task configuration decision.
