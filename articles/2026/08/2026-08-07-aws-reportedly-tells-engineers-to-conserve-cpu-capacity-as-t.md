# AWS reportedly tells engineers to conserve CPU capacity as the compute crunch spreads

The Information reported that AWS managers told engineers to cut compute usage wherever possible — including on CPU servers — by decommissioning idle EC2 instances and reallocating capacity to customers, as the AI infrastructure crunch extends beyond memory and GPUs. One engineer said obtaining CPU capacity now takes days rather than hours. AWS disputed that anything has changed, saying it still meets "the overwhelming majority" of compute needs. The report lands alongside comments from AMD, Arm, and Intel that agentic AI workloads are pushing CPU-to-GPU ratios toward parity.
