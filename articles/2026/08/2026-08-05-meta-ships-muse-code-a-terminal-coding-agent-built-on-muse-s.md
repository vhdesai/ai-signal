# Meta Ships Muse Code, a Terminal Coding Agent Built on Muse Spark 1.2

Meta released Muse Code, its first coding agent, positioned as a lower-cost challenger to Anthropic's and OpenAI's developer offerings. The product runs persistent background agents with repository-scale execution, multimodal understanding, and built-in verification. Meta is reportedly pushing thousands of its own engineers onto an internal coding agent to generate training signal — the same self-as-customer pattern visible across the sector this week. ________________________________ RESEARCH
