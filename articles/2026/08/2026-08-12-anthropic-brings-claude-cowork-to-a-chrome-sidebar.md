# Anthropic Brings Claude Cowork to a Chrome Sidebar

Claude Cowork now runs inside the Claude for Chrome extension side panel, persisting conversation history and keeping Skills, connectors, and multi-step tasks synced across Chrome and Claude’s native apps. The integration puts agentic task execution directly alongside the browser tabs where most knowledge work happens, rather than requiring context-switching to a separate application. This continues the industry pattern of embedding agents into existing workflows. For enterprise teams already using Claude, the Chrome sidebar reduces adoption friction by making agent capabilities available during research, writing, and analysis. Anthropic is betting that persistent, context-aware agent presence in the browser drives higher engagement than periodic visits to a chat interface. AOL TRENDING CONTENT LICENSING
