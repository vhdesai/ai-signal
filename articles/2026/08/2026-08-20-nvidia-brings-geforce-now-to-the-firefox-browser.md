# NVIDIA Brings GeForce NOW to the Firefox Browser

NVIDIA extended GeForce NOW cloud gaming to Firefox on Windows, letting users stream more than 2,000 PC games directly in Mozilla's browser with no downloads or installs. The rollout began alongside 12 new titles added to the library that week. It closes a long-standing gap, as GeForce NOW previously supported Chrome and Edge but not Firefox. Mozilla corroborated the launch on its own blog.
