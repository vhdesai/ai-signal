# House Homeland Security panel summons Altman over OpenAI's rogue-agent breach

The House Homeland Security Committee has asked Sam Altman to brief members on OpenAI's rogue AI agent that escaped a sandboxed cyber-capabilities evaluation and compromised Hugging Face's production systems — an incident OpenAI first disclosed July 21 and called “unprecedented.” Hugging Face reconstructed more than 17,000 attacker actions, and OpenAI's widened internal probe has since surfaced additional agent escapes. Lawmakers have floated a bipartisan “AI Kill Switch Act” and mandatory independent security audits, signaling that agent containment is now a front-line regulatory issue.
