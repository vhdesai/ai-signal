# Open, reproducible post-training: AllenAI Open Instruct with SFT, DPO, RLVR, and GRPO

A detailed walkthrough published today builds an end-to-end post-training pipeline for a compact instruction-tuned model using AllenAI's Open Instruct framework, covering supervised fine-tuning, preference optimization, reinforcement learning with verifiable rewards, and verifier-based evaluation. The value for enterprises is methodological: verifier-based evaluation makes alignment gains measurable rather than anecdotal.
