# ChatGPT gains a Messages integration on macOS

OpenAI began rolling out a Messages integration for ChatGPT on macOS that can read, search, summarize, draft, and send messages once the user grants permission, with OpenAI saying data is processed locally and no separate conversation index is created. The move continues the shift from standalone chatbot to assistant acting across native applications. It also widens the prompt-injection surface: instructions embedded in an inbound message reach an agent with send permissions, which enterprises should treat as a policy question, not just a feature toggle.
