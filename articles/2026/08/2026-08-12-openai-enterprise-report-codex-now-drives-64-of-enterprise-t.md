# OpenAI Enterprise Report: Codex Now Drives 64% of Enterprise Tokens

OpenAI published usage data showing frontier firms generate 8.3× more output tokens per active user than typical enterprises (up from 2.6×). Codex accounts for 64% of combined enterprise token volume. The shape of the data is the story: enterprise AI consumption is migrating from interactive assistants to autonomous agents doing sustained background work, generating enormous token volumes without direct human interaction. This migration changes both cost modeling (token bills scale with agent runtime, not headcount) and governance requirements (autonomous work needs audit trails, containment, and rollback). Engineering and finance leaders should revisit AI budget assumptions in light of the gap between “typical” and “frontier” enterprise usage. OpenAI NEW ON-DEVICE AI
