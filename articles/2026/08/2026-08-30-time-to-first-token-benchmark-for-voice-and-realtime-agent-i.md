# Time-to-first-token benchmark for voice and realtime agent inference APIs

A new benchmark measures time-to-first-token across the full voice stack — LLM, speech-to-text, text-to-speech and speech-to-speech — with each figure labeled as independently measured, vendor-published or vendor-measured and verified against primary sources on August 30. The authors argue TTFT is “the right starting point and the wrong stopping point” when selecting an inference API. Useful reference for anyone evaluating realtime agent latency budgets.
