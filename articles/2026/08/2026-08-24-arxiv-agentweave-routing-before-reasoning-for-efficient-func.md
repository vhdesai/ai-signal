# arXiv: “AgentWeave” — routing before reasoning for efficient function callingNew

AgentWeave (Singla et al.) is a deterministic pre-inference routing layer that shrinks an LLM’s visible action space before it reasons, leaving the downstream model unchanged. On 48 BFCL V4 multiple-function tasks it achieved 6/48 native successes versus 0/48 for both all-tools and top-8 baselines, while presenting 70% fewer tools, using roughly 62% fewer input tokens and cutting local-model latency about 51%. The authors frame candidate-space construction as a distinct stage that materially affects a fixed model’s function-calling behavior.
