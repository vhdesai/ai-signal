# Anthropic puts Claude Mythos 5 behind Claude Security, adds a $35M open-source fund

Anthropic said its most cyber-capable model, restricted to vetted defenders since April, now powers vulnerability scanning inside Claude Security, in public beta for Claude Enterprise customers with no separate model add-on. Scans connect to a repository, trace data flows, and return findings with CWE category, confidence and severity ratings, plus a suggested patch. Users receive scan output rather than direct model access — a deliberate packaging choice that limits misuse of an offensive-capable model. Products & Tools ADOPTION
