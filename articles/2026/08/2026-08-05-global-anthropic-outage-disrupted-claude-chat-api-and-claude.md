# Global Anthropic outage disrupted Claude chat, API, and Claude Code

Anthropic experienced a broad outage affecting Claude’s consumer chat, the API, and Claude Code before service was restored. Developer and enterprise workloads built on the API were interrupted for the duration. The incident is a reminder that agentic development workflows now sit on a single-vendor critical path, and that multi-model routing is becoming an availability requirement rather than a cost optimization.
