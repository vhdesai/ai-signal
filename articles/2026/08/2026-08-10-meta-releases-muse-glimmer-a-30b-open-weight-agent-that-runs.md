# Meta Releases Muse Glimmer, a 30B Open-Weight Agent That Runs on a Single GPU

Meta Superintelligence Labs released Muse Glimmer, a roughly 30-billion-parameter dense open-weight model with a perception encoder, tuned for multi-step tool use, coding, multimodal understanding and long-running local agents. Weights ship under Apache 2.0, and quantized builds reportedly run in about 18GB of RAM on a single GPU; Nvidia reports a 120K+ context window and published deployment recipes across RTX, DGX, Jetson, SGLang and vLLM. Meta also plans to release Muse Spark 1.2 weights. The launch pairs with Zuckerberg's 6,500-word argument for broadly distributed superintelligence, making local ownership of capable agents a competitive wedge against cloud-rented intelligence.
