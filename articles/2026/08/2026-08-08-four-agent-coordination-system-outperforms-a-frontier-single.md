# Four-Agent Coordination System Outperforms a Frontier Single Model on Enterprise Coding

Researchers from Coral AI Labs and academic collaborators introduced AgentRadio, an asynchronous messaging layer for coordinating multiple coding agents. In evaluations on enterprise software tasks, four coordinated agents outperformed Claude Opus 4.8 operating alone, with the reported advantage coming from live agent-to-agent communication rather than improved prompting. The finding argues that orchestration architecture is becoming an independent performance lever alongside model selection — relevant to any organization currently standardizing on a single vendor endpoint.
