# OpenAI retires the o3 reasoning model from ChatGPT

OpenAI removed o3 from consumer ChatGPT in its first major retirement of a reasoning model, with a corresponding API shutdown signposted for December. Custom-GPT developers must rebuild workflows built on o3-specific behavior. The episode is an early data point on model-lifecycle risk for enterprises standardizing on a single vendor's reasoning tier. Single-source report.
