# OpenAI pushes agents deeper into the desktop, raising the control question

TechCrunch reports on OpenAI's expanding agent surface, centered on a desktop app that now takes broad access to a user's local environment. Lead engineer Andrew Ambrosino frames wide permissions as the only realistic way to test agentic workflows, which puts the burden of judgment on the deployer rather than the model. The piece surfaces the adoption gap between what agents can technically do and what risk-aware users will grant them. Enterprises evaluating desktop agents should treat permission scoping, not capability, as the primary deployment decision. RELIABILITY
