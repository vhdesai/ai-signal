# OpenAI's Jalapeño chip is built for fast inference at scale, benchmarks show

At Hot Chips, OpenAI released first benchmarks for Jalapeño, its Broadcom-co-developed inference processor, showing higher tokens per user and higher throughput per kilowatt than an Nvidia Blackwell reference system on Semianalysis's InferenceX benchmark. Hardware lead Richard Ho said the design minimizes data movement and communication delays, keeping KV cache local across inference phases. Deployment is limited to very small volumes at the end of 2026, scaling in 2027 — by which point the Nvidia comparison point will have moved.
