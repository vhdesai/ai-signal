# Microsoft adds an in-meeting “Report” button to Teams to counter AI deepfake meetings

Microsoft confirmed a new Teams control that lets participants report a security issue — including suspected AI deepfake impersonation — during a live meeting, rolling out in August 2026. The feature reflects rising concern that generative audio/video can be weaponized inside routine collaboration tools. For IT and security leaders, it adds an in-workflow reporting path that will need to be wired into incident-response playbooks. Infrastructure INFRASTRUCTUREMEMORYHARDWARE
