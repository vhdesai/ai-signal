# OpenAI's Brockman Warns of AI Cybersecurity Tipping Point

OpenAI president Greg Brockman published a detailed essay warning of increasing cybersecurity threats from AI, describing a tipping point that "may be underappreciated." He advises that "over the coming months, every organization will need to begin significantly automating its security program to stay secure." The essay argues agentic attack capability demonstrated in the recent OpenAI–Hugging Face incident is now months, not years, from broad availability — including via open-weight models due at the end of August. OpenAI describes triaging nearly all initial security alerts with models before human involvement, using agents to enumerate attack paths, and training models to write more secure code. The prescriptive section is the useful part for CISOs: give security teams an agent, run assessments against internet-facing systems first, and automate detection triage incrementally rather than attempting an autonomous SOC. The framing is urgent but actionable — a rare combination in security vendor communications.
