# Claude Code adds cross-session messaging for parallel agent coordination

Anthropic shipped cross-session messaging in Claude Code, letting separate coding sessions communicate directly instead of requiring a human to copy context between terminal windows. The feature makes multi-agent workflows cheaper to operate.
