# Pokee AI releases Isaac 28B, a 10M-token agentic model for customer-boundary deployment

Pokee AI released Pokee-Isaac 28B, a text-only foundation model with a claimed 10 million-token context window designed to run inside a customer boundary. The model is positioned for regulated industries and public-sector deployments where data cannot leave a VPC, on-premises, or device environment. The release reflects growing demand for long-context agentic systems that combine cloud-like capability with local deployment controls.
