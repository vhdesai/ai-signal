# Anthropic Details How Claude's New Text Watermarking Will Work

Anthropic published a blog post explaining the mechanics of watermarking Claude's text output — how it works, whether editing removes it, and its effect on generated code — to comply with the EU AI Act's Transparency Code. The move has drawn user backlash, with some claiming they canceled subscriptions. For enterprises, this is an early template for how provenance obligations will surface in commercial model terms.
