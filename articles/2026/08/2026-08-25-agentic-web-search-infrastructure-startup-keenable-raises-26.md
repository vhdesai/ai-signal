# Agentic web search infrastructure startup Keenable raises $26M

Keenable.ai exited stealth with $26 million to rebuild web search infrastructure for machine consumers rather than human readers. The thesis is that retrieval layers designed around pages, ads, and ranking are a poor fit for agents that need structured, verifiable results at high call volume. Expect more infrastructure spend to migrate toward agent-native retrieval and tool interfaces.
