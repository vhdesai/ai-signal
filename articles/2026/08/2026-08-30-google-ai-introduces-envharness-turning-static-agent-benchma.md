# Google AI Introduces EnvHarness — Turning Static Agent Benchmarks Into Adaptive Training Worlds

Researchers from Google Cloud AI Research, Washington University in St. Louis, and UNC Chapel Hill released EnvHarness, an Apache-2.0 programmable layer that wraps existing agent environments through standard reset/step interfaces. An LLM designer called EnvRigger diagnoses failure modes from a policy's own rollouts and writes targeted wrappers. Gains include up to 9.0 points on held-out tasks and 9.8% fewer execution steps across five benchmarks. For enterprises building agent evaluation loops, a structured way to make benchmarks co-evolve with the agents they test.
