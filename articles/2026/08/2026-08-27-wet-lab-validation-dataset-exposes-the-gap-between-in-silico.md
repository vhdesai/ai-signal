# Wet-lab validation dataset exposes the gap between in-silico scores and real binding

A technical walkthrough uses Anthropic's claude-protein-binder-design dataset — 1,440 AI-designed miniprotein binders tested against 16 targets — to compare computational design metrics against measured laboratory outcomes. Because the release pairs computational predictions with wet-lab results, it enables direct assessment of how well in-silico scoring predicts real-world binding. The broader lesson generalizes past biology: benchmark performance and deployed performance diverge, and validation data is the scarce asset.
