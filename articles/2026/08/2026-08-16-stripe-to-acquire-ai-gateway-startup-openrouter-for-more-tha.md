# Stripe to acquire AI gateway startup OpenRouter for more than $7 billion

Per a Bloomberg report, Stripe has finalized a deal to acquire OpenRouter, the model-routing gateway that lets developers switch between hundreds of LLMs through a single API. The price tag exceeds $7 billion, an aggressive mark for an infrastructure layer that sits between applications and model providers. If confirmed, it positions payments infrastructure as a distribution point for AI inference and raises the strategic value of the routing tier. Neither party has confirmed the transaction publicly.
