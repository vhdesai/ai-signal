# NVIDIA Switchyard: Mid-Task Model Router Cuts Agent Costs to One-Third

NVIDIA released Switchyard, a router that reshuffles AI models mid-task to optimize cost-performance trade-offs for agentic workloads. In NVIDIA's tests, Switchyard cut task costs to approximately one-third while maintaining output quality by routing different steps of a multi-step agent workflow to the most cost-effective model. Addresses the growing enterprise pain point of token spend management in production agent deployments. OPEN-SOURCE VIDEO
