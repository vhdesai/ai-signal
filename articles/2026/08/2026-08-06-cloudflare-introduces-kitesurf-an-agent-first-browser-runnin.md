# Cloudflare introduces Kitesurf, an agent-first browser running on Workers

Cloudflare introduced Kitesurf, a stateless browser built for AI agents that runs entirely in V8 isolates on Cloudflare Workers, according to MarkTechPost. The browser drops human-facing overhead such as tabs and extension support in favor of machine-readable content, lower token overhead, isolation, and scale. It reflects a growing infrastructure layer around browser-using agents, where the standard human browser is often too heavy and unsafe for automated workloads.
