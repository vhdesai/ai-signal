# NVIDIA pushes AI storage stack at Future of Memory and Storage

NVIDIA published a storage-focused AI infrastructure update around the Future of Memory and Storage conference, including open-sourcing cuFile APIs with Google, Intel, and Meta as co-maintainers and launching the Storage-Next initiative with storage vendors. The post frames storage and memory access as bottlenecks for long-context and agentic inference workloads. The strategic point is that NVIDIA is extending platform influence beyond GPUs into the full data path required for AI-scale systems. INFRASTRUCTUREAI CLOUDSTORAGE SUPPLY
