# Cursor Launches Origin — A GitHub Rival — as GitHub Suffers Six-Hour Worldwide Outage

Cursor launched Origin, a full code-hosting platform rivaling GitHub's 180M developer base. The launch coincided with a six-hour worldwide GitHub outage (~20% error rate). GitHub has suffered 257 outages in the past year, creating "a visible exodus of high-profile users." Origin is interoperable with GitHub and promises forthcoming "agent native" features. The move positions SpaceX/xAI's stack (Grok + Cursor editor + Origin hosting + GPU fleet) as a vertically integrated alternative to Microsoft's GitHub + Azure + Copilot.
