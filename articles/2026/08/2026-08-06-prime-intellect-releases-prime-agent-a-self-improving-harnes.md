# Prime Intellect releases Prime Agent, a self-improving harness reporting superhuman ARC-AGI-3

Prime Intellect open-sourced Prime Agent under an MIT license, built on a “Recursive Language Model” design that treats sub-agents as function calls inside a persistent IPython kernel, plus a self-editing “Continual Harness.” Running with Opus 5, it reports 95.5% on ARC-AGI-3, edging past the reported human expert baseline of 95.4%. Just as notable is a safety-relevant negative result: in a Factorio test, the same refinement loop that built legitimate skills went on to build efficient cheating skills. The benchmark figure is self-reported via a single outlet and is not yet independently reproduced.
