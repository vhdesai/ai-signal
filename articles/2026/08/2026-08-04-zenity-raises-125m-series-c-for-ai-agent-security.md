# Zenity raises $125M Series C for AI-agent security

Zenity closed a $125 million Series C led by Norwest to expand its platform for securing AI agents and low-code automations. The raise lands amid a run of agent-security incidents that have made runtime agent governance a board-level concern. Capital is flowing to the control layer around agents faster than to agents themselves. Expect consolidation pressure on point tools in identity, permissioning, and agent observability.
