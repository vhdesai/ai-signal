# FreeToken: an edge-native MoE serving engine running a 753B model on a single workstation GPU

FreeToken splits mixture-of-experts cache misses between PCIe fills and CPU execution using measured bandwidths, allowing a 753B-parameter GLM-5.2 to run on a single workstation GPU. The approach targets the memory-bandwidth wall that normally forces frontier MoE models into multi-GPU clusters. For enterprises weighing on-premises inference against cloud API spend, serving-side engineering like this is where the cost curve is currently moving fastest.
