# Nvidia Is Building a 1-Trillion-Parameter Open Model, Nemotron 4

Nvidia is developing Nemotron 4, an open model family reportedly targeting roughly one trillion parameters, intended to compete with leading open-weight models globally. The strategic logic differs from closed-lab economics: Nvidia does not need the model to be profitable, only to drive downstream demand for GPUs, networking, and its software stack.
