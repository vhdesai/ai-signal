# Benchmarking agent sandboxes: cold start, per-second pricing, network policy

A comparative benchmark of the leading agent execution sandboxes evaluates measured cold-start latency, per-second and idle billing, and network/egress policy. The analysis is aimed at teams building agentic systems that must run untrusted model-generated code securely and at predictable cost. It is a useful reference point for anyone standardizing an internal agent runtime.
