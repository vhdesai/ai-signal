# Z.ai's GLM-5.3 posts frontier cyber scores — and reportedly found a serious flaw in Cursor

Z.ai released GLM-5.3, delivering large coding and cybersecurity gains achieved largely through post-training on the same base model, and scoring 84.5% on CyberGym — narrowly ahead of the leading Anthropic and OpenAI models on that benchmark. Coverage notes the model reportedly surfaced a serious vulnerability in Cursor during testing. The dual-use profile is the point: a low-cost open-weight model with credible offensive-security capability changes the threat model for every organization that assumed frontier cyber capability stayed behind API guardrails.
