# Anthropic opens Claude Security scans powered by Mythos 5 to all enterprise customers

Anthropic moved Claude Security vulnerability scanning into public beta for all Claude Enterprise customers, powered by Mythos 5 — the cyber-capable model previously restricted to a vetted-defender cohort. The service scans GitHub repositories and returns findings with severity, confidence, and suggested fixes that open directly in Claude Code. It is the first broad public access to Mythos 5's capabilities, and notably Anthropic is releasing the model's findings to defenders without releasing the model itself. PRODUCT PRIVACY
