# OpenClaw 2.0 ships guided model setup and a single trust boundary per gateway

The open agent runtime's 2.0 release rebuilds onboarding around guided model configuration, cuts control-UI startup to 575 ms, and reorganizes its security model so each gateway carries one trust boundary. Session storage moves to SQLite, with conversation search, safer credential prompts and improved Slack support.
