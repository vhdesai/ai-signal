# Gradium AI Ships a New Default Text-to-Speech Model — 81.0% Hard-Case Pass Rate at 216 ms Time-to-First-Audio

Gradium AI released a new text-to-speech model and made it the default across its API and Studio. The model reports an 81.0% human-rated pass rate on a 500-sentence hard-case set spanning five languages, and a 216 ms P50 time-to-first-audio — 170 ms faster than the model it replaces. Gradium open-sourced the 500-sentence evaluation set on Hugging Face under a Creative Commons license, an unusually transparent move for a commercial speech vendor.
