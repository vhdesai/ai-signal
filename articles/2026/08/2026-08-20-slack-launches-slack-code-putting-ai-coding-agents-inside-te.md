# Slack Launches Slack Code, Putting AI Coding Agents Inside Team Channels

Slack introduced “code channels” where engineering teams and AI coding agents write, review, and ship code in a shared, observable thread, available across Slack plans from launch day. Founding agent partners span Anthropic's Claude Code, OpenAI's ChatGPT, Cognition's Devin, and GitHub Copilot — a deliberately multi-vendor posture. The strategic read is that Salesforce is trying to make the collaboration layer, not the IDE, the system of record for agentic work.
