# Meta releases Muse Glimmer, a 30B open-weights agentic model that runs on one consumer GPU

Meta Superintelligence Labs released Muse Glimmer, a 30-billion-parameter agentic model under the permissive Apache 2.0 license, designed to run locally on a laptop or a single consumer GPU. The release directly targets the cost and data-residency arguments for cloud inference. For enterprises, it strengthens the case for on-premises or edge deployment of mid-tier agentic workloads. The competitive pressure falls hardest on paid API tiers serving routine agent tasks. https://www.forbes.com/sites/jonmarkman/2026/08/11/meta-unveils-muse-glimmer-a-30b-parameter-ai-model-that-runs-locally/
