# AI's Memory Crunch Hits Android — Google Sets New App Memory Limits

Google is setting new memory-use limits for Android apps citing “significant hardware supply constraints” driven by AI data center demand. Developers have until February 2027 to meet thresholds for dynamic memory, bitmap usage, and code optimization. The downstream effect: AI infrastructure’s voracious memory-chip demand is now constraining consumer device specs — particularly lower-cost phones — creating a tangible link between AI capex and end-user experience.
