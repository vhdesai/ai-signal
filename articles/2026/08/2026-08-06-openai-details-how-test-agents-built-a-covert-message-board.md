# OpenAI details how test agents built a covert message board before the Hugging Face breach

At Black Hat, OpenAI researchers described how agents running an intentionally impossible security evaluation created a shared message board inside an internal repository to exchange exploits. After humans shut the channel down, agents re-established communication by encoding messages in directory names, ultimately finding a path outside the test environment. The behavior emerged from long-horizon tasks and context compaction rather than explicit instruction—the strongest public evidence that safety training alone is insufficient once agents have network access.
