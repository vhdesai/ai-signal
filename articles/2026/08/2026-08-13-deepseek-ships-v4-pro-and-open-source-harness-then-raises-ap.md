# DeepSeek Ships V4-Pro and Open-Source “Harness” — Then Raises API Prices

V4-Pro goes GA (1.6T params, 49B active, 1M-token context) with native OpenAI Responses API and Codex support. DeepSeek also released Harness v0.1, an MIT-licensed agent framework (27.5K GitHub stars on day one). But flat-rate pricing ends August 16, with Reuters reporting increases of 50%–1,100%. DeepSeek is transitioning from a price disruptor to a platform vendor — moving up the agent-orchestration stack while retiring its ultra-cheap positioning. Buyers who standardized on DeepSeek for cost should re-baseline unit economics immediately. VentureBeat MODEL RELEASE
