# An AI research system discovered novel HTTP desync attacks affecting ~700 live sites

PortSwigger’s James Kettle published HTTP Terminator, an autonomous AI research system that tested roughly 30,000 candidate desync vectors against thousands of authorized websites and identified approximately 700 vulnerable targets, including banks, government infrastructure, security products and an airport. The system generated new attack classes — a dual-matching Content-Length pattern, a “dangling-byte” technique for more reliable response queue poisoning, and shared-parser confusion — and a human-guided cascade also surfaced an Apache Traffic Server zero-day. Kettle frames this as AI producing genuinely novel security research rather than reapplying known bug classes. Security leaders should treat AI-discovered attack classes as a near-term change to patch-cycle assumptions. ANALYSIS
