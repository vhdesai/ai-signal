# OpenAI publishes “From asking to doing” on how the world uses ChatGPT

OpenAI released new OpenAI Signals data offering country-by-country insight into how ChatGPT’s roughly one billion weekly users are shifting from asking questions to completing real work. The report frames a transition from informational queries toward task execution and agentic workflows — a useful read on enterprise adoption patterns.
