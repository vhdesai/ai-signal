# NVIDIA Open-Sources NOOA, an Object-Oriented Agent Framework Hitting 82.2% on SWE-bench

NVIDIA Labs released NOOA (Object-Oriented Agents) under Apache 2.0, collapsing an agent into a single Python class where methods are actions, fields are state, docstrings are prompts, and type annotations are enforced contracts. Reported results: 82.2% on SWE-bench Verified at roughly half the token cost of prior SOTA, 86.8% on CyberGym L1, and 73.0% on Terminal-Bench 2.0. Model-agnostic via LiteLLM; ships as v0.0.8 alpha. NVIDIA warns AST checks are not containment — production use requires container or VM isolation.
