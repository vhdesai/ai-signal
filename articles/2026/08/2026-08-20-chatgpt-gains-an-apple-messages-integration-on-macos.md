# ChatGPT Gains an Apple Messages Integration on macOS

OpenAI shipped a Messages plugin for the ChatGPT macOS desktop app that can read, search, summarize, draft, and send messages once the user grants permission, available across all plans. OpenAI states the integration processes data locally and does not build a separate index of conversations. Granting an assistant read/write access to personal messaging surfaces creates a real prompt-injection vector that security teams should assess before broad deployment.
