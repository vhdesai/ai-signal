# Open-source course maps three ways to run an agent loop — and the provider economics behind each

This analysis argues that the agent harness, not the underlying model, is the dominant driver of agent quality, citing a LangChain Terminal-Bench experiment where changing only the harness moved a coding agent from roughly 30th place into the top five. It formalizes three run modes — interactive/online (latency-bound, per-token pricing), remote/offline (throughput-bound, GPU-hour pricing), and async/online (batch-billed) — and maps each to distinct inference-provider economics, illustrating a 1,000-document workload at roughly $97 on frontier API rates versus about $13 batched on serverless GPU. It is applied engineering analysis tied to an open-source course, not a peer-reviewed result.
