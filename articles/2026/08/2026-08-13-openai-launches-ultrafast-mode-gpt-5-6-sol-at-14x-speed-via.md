# OpenAI Launches 'Ultrafast' Mode — GPT-5.6 Sol at 14x Speed via Cerebras

OpenAI introduced “Ultrafast,” a new mode that runs GPT-5.6 Sol at 14x standard speed, delivering up to 750 output tokens per second. The feature is powered by chipmaker Cerebras and is available in preview to select enterprise customers.
