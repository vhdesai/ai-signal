# NVIDIA Open-Sources NOOA — Object-Oriented Agent Framework Reaching 82.2% SWE-bench

NVIDIA Labs released NOOA (Object-Oriented Agents), an Apache 2.0 Python framework that collapses agent development into a single class — methods are actions, fields are state, docstrings are prompts, type annotations are enforced contracts. A benchmark-agnostic 253-line agent achieved 82.2% on SWE-bench Verified (vs. 78.6% for OpenCode), 86.8% on CyberGym L1, and 85.1% mean RHAE on ARC-AGI-3 — all at roughly half the token usage of compared harnesses.
