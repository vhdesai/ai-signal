# EnvHarness: reshaping static environments for agent learning

EnvHarness is a programmable plug-in layer that makes static agent environments trainable without rewriting them. The authors report a 9.0-point gain on held-out instances. It fits the same thesis as Nvidia’s AVO result — that the surrounding harness, not just the base model, is where near-term agent gains are being found.
