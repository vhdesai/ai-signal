# Mistral Releases Shieldstral 1.0 3B — Policy-Adaptive Safety Classifier Under Apache 2.0

Mistral released Shieldstral 1.0 3B, an open-weights multimodal safety classifier that treats moderation as a single yes/no question configurable at inference time — no retraining to change policy. The 3B model matches GPT-OSS-Safeguard-20B at 84.9% text F1 and leads multimodal baselines at 83.8% F1, while fitting in 16GB VRAM. Operators write moderation policy as a plain-language question; the model returns a continuous safety score in a single forward pass. Apache 2.0 licensed. RELEASE LONG-CONTEXT
