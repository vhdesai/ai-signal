# Anthropic makes Claude Code “auto mode” the default for Pro, Max and Team

Anthropic is flipping Claude Code’s autonomous “auto mode” on by default for Pro, Max and Team accounts starting August 14. The change shifts the default developer posture from supervised assistance to autonomous execution. For enterprise engineering leaders this is a governance trigger — sandboxing and permission policy should be reviewed ahead of the date.
