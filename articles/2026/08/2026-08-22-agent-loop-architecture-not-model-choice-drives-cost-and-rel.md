# Agent-loop architecture, not model choice, drives cost and reliability

A technical breakdown of an open-source coding-agent course maps three distinct ways to run an agent loop and the inference-provider economics attached to each. It cites a LangChain Terminal-Bench experiment in which changing only the harness — holding the model constant — moved a coding agent from roughly 30th place to the top of the field. The practical implication for platform teams is that harness engineering and provider routing deserve the review attention typically spent on model selection. Academic Research ACADEMIC
