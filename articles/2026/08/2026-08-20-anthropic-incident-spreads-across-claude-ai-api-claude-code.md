# Anthropic Incident Spreads Across Claude.ai, API, Claude Code and Cowork

Anthropic opened an incident after elevated error rates hit requests across a broad set of Claude models, with impact reaching the consumer app, the API, and its developer and agentic surfaces simultaneously. The blast radius — rather than the duration — is the signal: single-vendor agent dependencies now create correlated downtime across coding, chat, and workflow automation. Enterprises running production agents should validate fallback routing and degradation behavior, not just SLAs. Industry News M&AHOT
