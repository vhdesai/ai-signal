# OpenAI Terminates Cursor’s Model Access Following SpaceX Acquisition

OpenAI notified SpaceX that it intends to wind down the contract supplying models to Cursor, with a proposed shutoff date of November 12, 2026. OpenAI cited terms-of-service compliance and the acquiring group’s contracting record. For enterprises, model access is now revocable on ownership-change grounds, not just usage grounds.
