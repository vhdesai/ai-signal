# Anthropic makes "auto mode" the default in Claude Code across Pro, Max, and Team

Starting August 14, new Claude Code sessions on Pro, Max, and Team plans will run in auto mode, replacing repeated approval prompts with a classifier that vets each tool call for irreversible, destructive, or out-of-bounds actions. Anthropic said it stopped charging for the classifier’s token overhead effective August 7. It cited a 1,053-person study in which human reviewers caught only 13.6% of dangerous commands versus 89% for auto mode, while cautioning that classifiers "cannot eliminate risk." Auto mode remains opt-in on Enterprise, the API, and cloud partners including AWS Bedrock, Google Cloud, and Microsoft Foundry.
