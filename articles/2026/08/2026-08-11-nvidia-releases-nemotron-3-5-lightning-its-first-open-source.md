# Nvidia Releases Nemotron 3.5 Lightning, Its First Open-Source Model Since Huang's Open-Weight Push

Nvidia published Nemotron 3.5 Lightning, a lightweight open-source model that runs on a single GPU in a laptop or desktop and is free to download, modify and deploy without a license fee. It is the company's first open-source release since Jensen Huang publicly argued against "premature restrictions" on open models in late July. The commercial logic is direct: free models still consume GPU cycles, and cheaper inference broadens the installed base against proprietary offerings from OpenAI and Anthropic. https://www.cnbc.com/2026/08/11/nvidia-releases-nemotron-3point5-lightning-open-source-ai-model-.html
