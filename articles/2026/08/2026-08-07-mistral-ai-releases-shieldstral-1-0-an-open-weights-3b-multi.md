# Mistral AI Releases Shieldstral 1.0, an Open-Weights 3B Multimodal Safety Classifier

Mistral released Shieldstral 1.0, a 3-billion-parameter open-weights, policy-adaptive safety classifier built on Ministral-3-3B-Base with a native vision encoder, covering prompt moderation, response moderation, prompt-response pair classification, refusal detection, and safety filtering across text and image inputs. Open weights at this size make in-house moderation viable for organizations that cannot route sensitive traffic through a hosted moderation API.
