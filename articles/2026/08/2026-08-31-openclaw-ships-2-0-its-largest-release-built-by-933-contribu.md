# OpenClaw Ships 2.0 — Its Largest Release, Built by 933 Contributors

OpenClaw released version 2.0 of its self-hosted, open-source personal agent platform, contributed to by 933 developers. The release centers on reducing operational friction: guided model setup, a rebuilt browser-first application, shared sessions, expanded agent options, and a tightened trust model of one trust boundary per gateway. MarkTechPost's benchmark of the release cites a 575 ms control-UI startup. The trajectory here matters — a self-hosted agent runtime maturing into a general personal-assistant platform is a credible alternative to vendor-hosted agent stacks for security-sensitive organizations. https://techgenyz.com/openclaw-2-0-update-better-browser-agent-options/
