# Asana ships company-wide agent memory with built-in access controls

Asana introduced AI agents that share memory across an organization while enforcing access controls, so sensitive work — such as an undisclosed M&A deal — cannot leak to unauthorized employees. The design targets a central enterprise-agent problem: making shared context useful without breaking information barriers. It reflects a broader vendor shift toward governance and permissioning as prerequisites for production agent deployments. PRODUCT
