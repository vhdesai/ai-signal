# Cursor Releases Origin, an Agent-Native Alternative to GitHub

Cursor launched Origin, a Git-based code hosting platform embedded directly in its AI editor, positioning it as an alternative to GitHub for teams already working inside Cursor. The move extends Cursor from authoring into hosting and review, capturing more of the software lifecycle.
