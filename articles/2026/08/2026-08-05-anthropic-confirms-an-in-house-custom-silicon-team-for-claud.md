# Anthropic confirms an in-house custom silicon team for Claude

Anthropic publicly confirmed for the first time that it is building an internal chip-design organization to co-design silicon and models for Claude, and has begun hiring engineers. The company said it will continue to run on AWS, Google, NVIDIA, and AMD hardware rather than shifting to a single supplier. The move follows the pattern set by Google’s TPUs and Amazon’s Trainium: labs pursuing per-token inference cost control as inference volume, not training, becomes the dominant spend line.
