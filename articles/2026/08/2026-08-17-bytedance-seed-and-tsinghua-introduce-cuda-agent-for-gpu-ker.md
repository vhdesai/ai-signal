# ByteDance Seed and Tsinghua Introduce CUDA Agent for GPU Kernel Generation

ByteDance Seed and Tsinghua University's Institute for AI Industry Research released CUDA Agent, a large-scale agentic reinforcement learning system that trains a language model to write GPU kernels that outperform compiler-generated code. The work targets one of the highest-leverage cost levers in AI operations: inference efficiency at the kernel level. If results generalize, model-generated kernel optimization becomes a credible path to reducing serving cost without new hardware.
