# OpenAI updates GPT-Live after SynthID audio-watermarking rollout

OpenAI's GPT-Live release page was materially updated in the current window and includes a dated update that supported GPT-Live audio generated through ChatGPT Voice and the OpenAI API now carries SynthID watermarking. GPT-Live is OpenAI's full-duplex voice architecture, built to listen and speak simultaneously while delegating harder reasoning to frontier models in the background. The watermarking component matters because real-time voice AI raises fraud, impersonation, and provenance risks beyond text interfaces. MODEL ECONOMICSOPENAIPRICE PERFORMANCE
