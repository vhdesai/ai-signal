# Perplexity Ships “Portable Computer” on NVIDIA DGX Spark

Perplexity packaged local models, an agent harness, an OS-enforced sandbox and connectors into a single system running on NVIDIA DGX Spark. Local steps carry zero per-token cost, with optional escalation to cloud frontier models for harder work. The design is an early template for hybrid local/cloud agent runtimes where cost and data residency, not capability alone, drive placement decisions.
