# Google says AI agents helped fix 1,072 Chrome security bugs

Google said AI-driven tooling helped identify and remediate 1,072 Chrome security vulnerabilities across two recent releases. The disclosure is one of the strongest production-scale examples of AI improving defensive software security workflows. It also highlights the dual-use dynamic: the same agentic capabilities that accelerate patching can also make offensive vulnerability discovery faster.
