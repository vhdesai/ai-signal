# Microsoft moves to order 300,000+ Maia 300 accelerators from TSMC

Microsoft is reported to be in talks with TSMC to produce more than 300,000 Maia 300 AI accelerators for 2027 delivery, with the chip expected to be unveiled this fall. Maia 200 is already deployed in Azure data centers while Maia 300 remains in design. Microsoft hopes large Azure customers — Anthropic among them — will adopt the in-house silicon. The scale of the order is a direct attempt to reduce accelerator dependence on Nvidia.
