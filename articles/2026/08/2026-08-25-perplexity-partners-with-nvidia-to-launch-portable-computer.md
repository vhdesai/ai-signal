# Perplexity partners with Nvidia to launch Portable Computer, a fully local AI agent with zero token costs

Perplexity shipped Portable Computer, packaging local models, an agent harness, an OS-enforced sandbox, and connectors to run privately on Nvidia DGX Spark and RTX-powered Linux desktops. Local steps incur no per-token cost, with escalation to cloud models gated by user approval per step. The economic argument — capex-funded inference on owned hardware instead of metered API spend — is the part enterprises should model, alongside the data-residency benefit.
