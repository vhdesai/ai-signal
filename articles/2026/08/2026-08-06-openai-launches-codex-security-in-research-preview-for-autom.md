# OpenAI launches Codex Security in research preview for automated code and PR review

OpenAI released Codex Security in research preview — an open-source CLI plus a code-review capability that analyzes diffs and repository context on GitHub pull requests, flags vulnerabilities with severity and remediation, and is available to Enterprise, Business, Edu, and Pro customers. It positions Codex directly against GitHub/Microsoft and startups embedding AI security review into developer workflows. Notably, it lands the same week as fresh disclosures about AI agents' own security behavior. Infrastructure M&ACHIPS
