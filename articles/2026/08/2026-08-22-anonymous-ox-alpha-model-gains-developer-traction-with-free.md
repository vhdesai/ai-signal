# Anonymous "Ox Alpha" Model Gains Developer Traction With Free 1M-Token Access

A stealth model called Ox Alpha appeared on OpenRouter with no named provider, no price, a roughly 1-million-token context window and multimodal (text, image, video) input, and is reportedly outperforming leading commercial coding models in developer testing. The unnamed operator retains every prompt submitted to it.
