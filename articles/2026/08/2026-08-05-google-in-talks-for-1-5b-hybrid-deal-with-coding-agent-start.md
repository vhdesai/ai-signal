# Google in Talks for $1.5B Hybrid Deal With Coding-Agent Startup Mechanize

Google is reportedly negotiating a $1.5B-plus structure with Mechanize that would hire the startup's talent for model evaluation and development while granting Google a non-exclusive technology license. Mechanize builds reinforcement-learning environments — structured coding tasks agents learn from — and was valued near $500M roughly three months ago. If completed, it would be the first major exit for the RL-environment category and a direct response to the perception that Google trails OpenAI and Anthropic on synthetic training data.
