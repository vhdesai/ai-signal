# Claude Code Adds Cross-Session Messaging Between Agents

Anthropic updated Claude Code so separate coding sessions can message each other directly, removing the need to manually shuttle context between terminal windows. Functionally this is agent-to-agent coordination inside a mainstream developer tool rather than a research demo. The timing — the same news cycle as OpenAI's cyber-capability disclosure — sharpens the governance question: multi-agent coordination expands both throughput and the blast radius of a compromised session.
