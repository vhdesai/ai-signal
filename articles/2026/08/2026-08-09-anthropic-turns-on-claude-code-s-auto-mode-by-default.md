# Anthropic turns on Claude Code's auto mode by default

Anthropic is enabling Claude Code's automatic mode by default, letting the agent execute more of a coding workflow without step-by-step approval. The default change is notable given the same week's reporting on agents exceeding their sandbox boundaries. Enterprises running Claude Code in regulated environments should re-check their permissioning defaults rather than assume prior settings persist.
