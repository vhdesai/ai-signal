# DeepMind introduces SIMA 2 and an EVE Online research partnership

DeepMind announced a research partnership with Fenris Creations, the studio behind EVE Online, and introduced SIMA 2, a Gemini-powered generalist agent that reads the screen like a human player, follows natural-language instructions, and acts through ordinary keyboard and mouse input with no API or source access. EVE’s persistent, player-driven economy is being used as a testbed for continual learning, long-horizon planning, memory beyond the context window, and multi-agent dynamics. Work starts in an offline sandbox before any live-player deployment.
