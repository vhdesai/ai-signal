# MemTrapBench: retrieved memory can actively degrade LLM reasoning

This benchmark of cognitive traps in LLM memory use finds that faithfully retrieved memories can degrade rather than improve reasoning quality. Across the frameworks tested, every memory system underperformed a no-memory baseline. The finding has direct implications for enterprise agent architectures that assume persistent memory is strictly additive.
