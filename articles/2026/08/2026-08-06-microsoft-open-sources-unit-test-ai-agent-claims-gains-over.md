# Microsoft Open-Sources Unit-Test AI Agent, Claims Gains Over GitHub Copilot

Microsoft released code-testing-generator, an MIT-licensed, polyglot AI agent that writes and validates unit tests using a research-plan-implement pipeline, supporting .NET, Python, Go, TypeScript, Java, Rust, Swift, and Kotlin. On an internal 152-task benchmark, Microsoft reports 92.1% task completion versus 78.9% for stock GitHub Copilot, with the largest gains on vague prompts and diff-targeted tasks. Open-sourcing a competitive coding-agent component signals Microsoft's strategy of contributing tooling to the broader GitHub ecosystem. Infrastructure INFRAPRODUCT
