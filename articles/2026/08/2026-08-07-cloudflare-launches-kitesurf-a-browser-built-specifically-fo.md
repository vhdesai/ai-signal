# Cloudflare Launches Kitesurf, a Browser Built Specifically for AI Agents

Cloudflare unveiled Kitesurf, a cloud-hosted headless browser designed for AI agents rather than human users, running entirely on its serverless Workers platform with a modular Rust-based rendering stack. Built in 12 weeks and positioned as significantly more CPU- and memory-efficient than Chromium for agent tasks like screenshotting and HTML extraction, it is in free beta and already passes over 215,000 web-platform tests. The move inserts Cloudflare directly into the AI agent infrastructure layer, competing with Playwright- and Puppeteer-based agent stacks. ________________________________ PRODUCTOPEN-SOURCE
