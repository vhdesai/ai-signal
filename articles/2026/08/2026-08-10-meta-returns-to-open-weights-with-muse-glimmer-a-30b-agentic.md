# Meta Returns to Open Weights with Muse Glimmer, a 30B Agentic Model

Meta released Muse Glimmer, an Apache 2.0-licensed 30B dense model with native vision input, trained end-to-end around the agent loop and shipping with quantized variants and a speculative-decoding drafter. It is sized to run on a single consumer GPU or a well-specified Mac or PC. The release marks Meta's return to permissive open-weight distribution amid renewed scrutiny of its AI spending. For enterprises, it lowers the floor for on-premises agentic workloads where data cannot leave the perimeter. venturebeat.com — Meta returns to open source with Muse Glimmer OPEN WEIGHTS VIDEO
