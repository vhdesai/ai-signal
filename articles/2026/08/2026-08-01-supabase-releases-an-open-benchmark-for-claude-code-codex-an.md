# Supabase releases an open benchmark for Claude Code, Codex, and OpenCode

Supabase released Evals, an open-source benchmark that scores coding agents on real Supabase repository tasks rather than synthetic puzzles. The benchmark compares systems including Claude Code, Codex, and OpenCode, making it a useful signal that agent evaluation is moving toward production-like workloads. Engineering leaders should treat this as another reminder that internal eval suites are becoming essential for AI tool procurement. URL: Supabase Evals benchmark
