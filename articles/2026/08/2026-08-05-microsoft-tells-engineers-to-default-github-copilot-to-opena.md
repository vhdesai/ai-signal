# Microsoft tells engineers to default GitHub Copilot to OpenAI's GPT-5.6 Sol, not Claude

In an internal memo, CoreAI EVP Jay Parikh instructed Microsoft engineers to default GitHub Copilot to OpenAI's GPT-5.6 Sol rather than Anthropic's Claude. Parikh framed the shift as capturing value from Microsoft's OpenAI investment and curbing "tokenmaxxing" as divisions operate under formal AI token budgets for the first time.
