# AWS adds native web search grounding to Amazon Bedrock

AWS launched Web Search as a native built-in tool in Amazon Bedrock, allowing foundation-model responses to be grounded against a refreshed web index and knowledge graph. It makes Bedrock more complete as an enterprise AI platform without requiring a separate search-grounding vendor.
