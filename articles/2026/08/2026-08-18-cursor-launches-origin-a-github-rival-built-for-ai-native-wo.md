# Cursor Launches Origin — A GitHub Rival Built for AI-Native Workflows

Cursor (now SpaceX-owned) launched Origin, a full code-hosting platform covering repositories, pull requests, reviews and merges, designed around AI coding agents rather than human-first workflows. The launch landed alongside a six-hour worldwide GitHub outage. The move positions SpaceX/xAI's stack (Grok + Cursor + Origin + GPU fleet) as a vertically integrated alternative to Microsoft's GitHub + Azure + Copilot. Early beta terms did not publish data retention or training-use policies — a material diligence item before any enterprise pilot.
