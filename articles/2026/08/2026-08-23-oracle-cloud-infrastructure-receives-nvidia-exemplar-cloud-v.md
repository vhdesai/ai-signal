# Oracle Cloud Infrastructure receives NVIDIA Exemplar Cloud validation for GB300 NVL72 and HGX B300

Oracle published that OCI achieved NVIDIA Exemplar Cloud validation for NVIDIA GB300 NVL72 and HGX B300. The validation matters because customers increasingly need assurance that cloud environments can support next-generation NVIDIA systems at scale with appropriate networking, reliability, and operational characteristics. For infrastructure buyers, cloud validation is becoming a due-diligence signal as GPU architectures grow more specialized and power-dense.
