# Anthropic makes Claude Code’s auto mode the default

Anthropic is turning on auto mode by default in Claude Code, shifting the agentic coding tool from a permission-per-action model toward autonomous execution with guardrails. The company first previewed auto mode in March as a way to balance speed against control. Making it the default is a meaningful change in the risk posture of enterprise coding agents and warrants a policy review for teams running Claude Code against production repositories.
