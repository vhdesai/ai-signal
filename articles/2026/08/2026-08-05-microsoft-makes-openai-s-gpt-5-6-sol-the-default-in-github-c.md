# Microsoft Makes OpenAI's GPT-5.6 Sol the Default in GitHub Copilot for Its Own Staff

Microsoft directed internal developers to default to OpenAI's top model inside GitHub Copilot as part of an efficiency push, leaning on its token investment and IP rights under the OpenAI agreement. The move is notable less as a product change than as a signal of how Microsoft is monetizing its OpenAI position internally.
