# Meta Launches Muse Code, an AI Coding Agent for Large Codebases

Meta released Muse Code (beta), a terminal-based coding agent powered by its Muse Spark model, designed to plan, write, and validate code across multiple files in large repositories by fanning out sub-agents into isolated worktrees. Meta AI chief Alexandr Wang positioned the product on cost against OpenAI Codex and Anthropic Claude Code. This marks Meta Superintelligence Labs' first direct entry into the agentic developer-tooling market. ________________________________ PRODUCT
