# Copilot Autofix Introduced Shell Injection in Snowflake’s CI/CD

A GitHub Copilot Autofix patch replaced sanitized input with raw string interpolation of a GitHub issue title — opening command injection. A conditional gate evaluated true on issue events (PR object was null), admitting unauthenticated attackers; a crafted title exfiltrated a Jira token. AI-authored security patches must be treated as untrusted changes requiring the same review rigor as external contributions. Audit merge policies now. Unite.AI POLICY
