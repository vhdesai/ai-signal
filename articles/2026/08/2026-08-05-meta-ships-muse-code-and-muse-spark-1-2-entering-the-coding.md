# Meta ships Muse Code and Muse Spark 1.2, entering the coding-agent market

Meta released Muse Code in beta, a terminal-based coding agent powered by the co-trained Muse Spark 1.2 model. The launch places Meta directly against Anthropic Claude Code and OpenAI Codex with persistent asynchronous background agents and repository-scale execution.
