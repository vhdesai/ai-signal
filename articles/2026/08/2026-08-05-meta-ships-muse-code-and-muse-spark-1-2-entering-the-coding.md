# Meta ships Muse Code and Muse Spark 1.2, entering the coding-agent market

Meta released Muse Code in beta, a terminal-based coding agent powered by the newly co-trained Muse Spark 1.2 model, with persistent asynchronous background agents, repository-scale execution, and built-in verification. Co-training the model with its harness is the technical differentiator Meta is claiming against OpenAI’s Codex and Anthropic’s Claude Code. Enterprises should note the default on-ramp routes code and prompts into Meta’s training pipeline unless explicitly opted out — a material procurement and IP consideration for proprietary codebases.
