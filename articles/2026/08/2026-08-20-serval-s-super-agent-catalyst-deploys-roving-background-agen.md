# Serval's super agent Catalyst deploys roving background agents to fix IT issues pre-ticket

Serval introduced Catalyst, a system of persistent background agents that scan enterprise IT estates and remediate issues before a ticket is filed. The design shifts agentic IT operations from reactive request handling toward continuous autonomous maintenance. The open question for buyers is change-control: pre-emptive remediation without an approval gate is an audit exposure.
