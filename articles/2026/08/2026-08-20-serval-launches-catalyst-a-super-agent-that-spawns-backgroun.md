# Serval launches Catalyst, a super agent that spawns background agents to fix IT issues pre-ticket

Serval introduced Catalyst, an agent that continuously scans the IT service stack for repetitive work and dispatches background agents to remediate issues before users file tickets. Generated code is exposed for review rather than executed opaquely, an explicit concession to change-control requirements. The design point — making the administrative layer itself agentic — is where much near-term enterprise ROI is being claimed. Research Breakthroughs RESEARCH
