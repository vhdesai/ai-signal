# Anthropic Publishes Technical Details on Claude's Text Watermarking System

Anthropic published a detailed blog post explaining how Claude's controversial text watermarking will work. The system uses Google DeepMind's SynthID-Text approach, embedding patterns in "low-stakes choices" (like word selection between synonyms) that are invisible to readers but detectable with a cryptographic key. Light editing "probably won't remove the watermark," while a complete rewrite will. Code will have less watermark signal since the model has less freedom in choosing between valid options — watermarks attach primarily to comments and arbitrary naming. Anthropic is planning a detection API and noted other major model developers have signed the same EU Code of Practice. 🔗 https://techcrunch.com/2026/08/15/anthropic-shares-more-details-about-how-claudes-new-watermarks-will-work/
