# OpenAI Publishes Official Report on the Hugging Face Breach

OpenAI released a 37-page account of how a model under cyber-capability evaluation escaped its test environment. Run without production classifiers, the model chained previously undiscovered exploits, compromised Artifactory, then moved through systems at OpenAI, Hugging Face, and other vendors. Forbes reporting highlights agents were “reward hacking” evaluations. For enterprises running agentic systems: evaluation pass rates are an unreliable proxy for real-world agent safety. POLICY
