# Zenity raises $125M Series C to secure and govern enterprise AI agents

Israeli startup Zenity closed a $125M Norwest-led Series C to inventory, monitor, and govern autonomous agents running across platforms such as Microsoft Copilot and ChatGPT Enterprise. The raise underscores that “agent security posture management” is emerging as a distinct budget line as enterprises move agents into production. Expect security tooling to become a gating dependency for large-scale agent deployments, not an afterthought. MARKETSCLOUDAWS
