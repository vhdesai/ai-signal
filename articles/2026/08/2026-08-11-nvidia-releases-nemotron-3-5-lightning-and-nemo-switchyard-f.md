# NVIDIA releases Nemotron 3.5 Lightning and NeMo Switchyard for agentic AI

NVIDIA expanded its Nemotron model family with Nemotron 3.5 Lightning, a 30-billion-parameter open mixture-of-experts model built for long-running agentic workloads. It also released NeMo Switchyard, an open-source routing library that can direct requests to the most suitable model inside agent tools. The release is strategically important because enterprise AI is becoming a system-of-models problem: cost, speed, specialization, and routing increasingly determine production value.
