# NVIDIA releases Nemotron 3.5 Lightning and NeMo Switchyard for agent workflows

NVIDIA released Nemotron 3.5 Lightning, a 30B open mixture-of-experts model with 3B active parameters, alongside NeMo Switchyard, an open-source router for assigning agent workflow steps to the most efficient model. The release targets high-volume agent execution tasks such as tool calls, validation, delegation, code review routing, and long-context retrieval. The strategic point is cost control: enterprises are looking for architectures that reserve frontier models for harder reasoning while routing routine execution to smaller, faster models.
