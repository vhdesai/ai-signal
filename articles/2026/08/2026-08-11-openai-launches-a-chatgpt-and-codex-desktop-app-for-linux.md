# OpenAI launches a ChatGPT and Codex desktop app for Linux

OpenAI released a preview ChatGPT desktop app for Linux, bringing ChatGPT, ChatGPT Work and Codex to Ubuntu 24.04 and 26.04 LTS, Debian 13 and Fedora 43 and 44. The release completes OpenAI's desktop coverage across Windows, macOS and Linux, closing a long-standing gap for developer users. It arrives roughly a month after Anthropic shipped its own Claude app for Linux.
