# "GhostSplice": malicious MCP servers split instructions to make coding agents exfiltrate secrets

Researchers disclosed an attack, dubbed GhostSplice, in which a malicious Model Context Protocol server distributes instruction fragments across separate channels that an AI coding agent recombines into a working exfiltration payload — pulling SSH keys, secrets and source code. Because no single fragment is malicious in isolation, conventional prompt-injection filters and per-message scanning miss it. Organizations running agentic coding tools should inventory connected MCP servers, pin trusted sources, and constrain agent credential scope now.
