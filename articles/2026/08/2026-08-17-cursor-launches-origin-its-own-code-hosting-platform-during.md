# Cursor Launches Origin, Its Own Code-Hosting Platform, During GitHub Outage

Cursor rolled out Origin, a repository and pull-request hosting service, in early beta across all paid plans, with bidirectional GitHub sync and integrations for Vercel, Depot, and Buildkite. The timing — coincident with a global GitHub disruption — sharpened the competitive framing. The strategic argument: agents that open, review, and update PRs perform better when hosting and editing share one surface. The counter-consideration for enterprises is repository custody and data terms under SpaceX ownership. This is the first credible code-hosting alternative to emerge from inside the AI-coding ecosystem.
