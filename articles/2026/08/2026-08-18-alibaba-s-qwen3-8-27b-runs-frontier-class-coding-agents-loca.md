# Alibaba's Qwen3.8-27B Runs Frontier-Class Coding Agents Locally

Alibaba's Qwen team released Qwen3.8-27B under Apache 2.0, a 27B-parameter model with integrated vision and a 262K native context window. The significant claim is that agentic coding and reasoning workloads previously requiring a cloud API now run on accessible local hardware. For regulated environments, this materially changes the build-versus-buy calculus on data residency, since inference need not leave the enterprise boundary.
