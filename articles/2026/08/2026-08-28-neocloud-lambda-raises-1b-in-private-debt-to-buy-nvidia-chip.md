# Neocloud Lambda raises $1B in private debt to buy Nvidia chips and lease them to Microsoft

Lambda secured $1 billion in private debt to purchase Nvidia accelerators, which it leases back to Microsoft — the latest in a string of similar loans across the neocloud sector. The structure underscores how much of the current buildout is debt-financed against long-term lease commitments from a small number of hyperscale counterparties.
