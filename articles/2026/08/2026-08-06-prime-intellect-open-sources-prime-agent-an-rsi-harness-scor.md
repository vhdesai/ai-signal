# Prime Intellect Open-Sources Prime Agent, an RSI Harness Scoring 95.5% on ARC-AGI-3

Prime Intellect released Prime Agent under an MIT license, a self-improving coding and research harness combining a Recursive Language Model (sub-agents as function calls in a persistent kernel) with a "Continual Harness" that lets the agent edit its own prompts, skills, and sub-agent specs mid-run. Paired with Anthropic's Claude Opus 5, it achieved 95.5% Best@1 on ARC-AGI-3, edging past the reported 95.4% human-expert baseline. The harness works across all major model providers and self-hosted endpoints, making it immediately deployable. ________________________________ RESEARCH
