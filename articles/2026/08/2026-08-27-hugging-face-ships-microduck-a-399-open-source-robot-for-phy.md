# Hugging Face Ships Microduck, a $399 Open-Source Robot for Physical AI

Hugging Face opened preorders for Microduck, a 25cm bipedal robot at $399 built with Pollen Robotics, with 15 motors, camera, lidar, and two inertial sensors. The SDK, simulation environment, and RL stack are published on GitHub with a documented sim-to-real path. First deliveries before year-end. Strategically a distribution play — gives the industry's largest model hub a cheap physical target for open weights.
