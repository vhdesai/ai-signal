# OpenAI launches a safer ChatGPT for teens

OpenAI released ChatGPT for Teens, adding age-appropriate safety measures, parental controls and learning tools intended to steer minors away from harmful content and from using the assistant to complete homework dishonestly. Expect it to become a reference point in pending state-level age-assurance rulemaking. Infrastructure INFRAOPEN SOURCE
