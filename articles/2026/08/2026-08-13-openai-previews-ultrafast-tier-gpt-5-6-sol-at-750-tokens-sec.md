# OpenAI Previews Ultrafast Tier: GPT-5.6 Sol at 750 Tokens/Second on Cerebras

A limited-preview API tier running GPT-5.6 Sol on Cerebras wafer-scale hardware at up to 750 output tokens/sec — ~14× Standard tier. Extends a $10B OpenAI–Cerebras compute agreement. Use cases: incident response, real-time financial research, fraud screening, voice support, in-session commerce. Early testers include Jane Street, Podium, Basis, and Rogo. Latency at this level changes what is architecturally feasible for interactive agents — multi-step reasoning chains become conversational rather than batch. The commercial question is whether Cerebras holds this margin as Nvidia closes the inference-latency gap.
