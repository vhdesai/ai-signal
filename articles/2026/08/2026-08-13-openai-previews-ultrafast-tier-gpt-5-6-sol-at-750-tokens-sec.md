# OpenAI Previews Ultrafast Tier: GPT-5.6 Sol at 750 Tokens/Second on Cerebras

OpenAI opened a limited preview of Ultrafast, an API service tier running GPT-5.6 Sol on Cerebras wafer-scale hardware at up to 750 output tokens per second — roughly 14× the Standard tier. The tier extends a previously announced $10B OpenAI–Cerebras compute agreement. OpenAI frames the use cases as latency-bound work: incident response, real-time financial research and fraud screening, voice support, and in-session commerce. Early testers named include Jane Street, Podium, Basis, and Rogo. Latency at this level changes what is architecturally feasible for interactive agents — multi-step reasoning chains that previously read as batch jobs become conversational. The commercial question is whether Cerebras's specialized silicon holds this margin as Nvidia's rack-scale systems close the inference-latency gap.
