# Runway Introduces Solaris, an "Interface World Model" That Generates UI Frame by Frame

Solaris treats a software interface as a generated visual world rather than rendered HTML/CSS/JS — user clicks and drags condition the next generated frame. Runway reports evaluators preferred Solaris output over Claude Opus 5-built UIs in 61% of instruction-following and 71% of natural-behavior judgments. No independent verification has been published. Access is early and request-based. The open question: whether generated interfaces can maintain state and consistency outside curated demos.
