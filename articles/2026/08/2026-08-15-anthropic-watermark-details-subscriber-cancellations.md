# Anthropic Watermark Details + Subscriber Cancellations

Anthropic published a technical explainer: the SynthID-Text watermark is reader-imperceptible and cost-neutral but degrades on code and factual text, disappears when Claude only edits human text or output is fully rewritten. A detection API is planned. Business Insider reports Max-tier subscribers publicly canceling over attribution concerns. The first clean read on the commercial cost of EU-driven transparency compliance.
