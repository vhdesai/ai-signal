# Agent-to-Agent Payment Rails Move from Pilot to Production

Autonomous agents are increasingly transacting using stablecoin-based payment protocols, with the x402 standard emerging as the settlement layer. Agents receive scoped wallets, spending caps and persistent identities tied back to an accountable human or organization. Transaction volumes remain small, so this is an architectural signal rather than a revenue one. The governance question — who is liable when an agent spends incorrectly — remains unresolved.
