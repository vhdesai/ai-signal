# Cursor launches Origin, its own code hosting platform, hours into a GitHub outage

Cursor rolled out Origin, a repository and pull-request hosting service, in early beta across all paid plans, with bidirectional GitHub sync and integrations for Vercel preview deploys, Depot, and Buildkite. The timing — coincident with a global GitHub disruption — sharpened the competitive framing. The strategic argument is that agents that open, review, and update PRs perform better when hosting and editing share one surface; the counter-consideration for enterprises is repository custody and data terms. https://venturebeat.com/infrastructure/cursor-launches-origin-code-hosting-platform-as-github-outage-exposes-opening-in-ai-coding-race
