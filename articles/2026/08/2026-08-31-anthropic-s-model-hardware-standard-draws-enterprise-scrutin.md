# Anthropic's Model Hardware Standard Draws Enterprise Scrutiny

Explainer coverage unpacked Anthropic's Model Hardware Standard (MHS), opened as a research preview on August 27, which specifies how AI agents can safely operate lab and manufacturing equipment. Anthropic intends to open-source the specification. If adopted, MHS would extend agent tooling standards from software APIs into physical instrumentation — a meaningful expansion of the agent attack surface and compliance perimeter for regulated manufacturing and life-sciences environments.
