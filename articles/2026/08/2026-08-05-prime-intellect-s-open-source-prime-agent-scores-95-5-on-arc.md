# Prime Intellect's Open-Source Prime Agent Scores 95.5% on ARC-AGI-3

Prime Intellect released Prime Agent, an open-source self-improving agent harness built around a recursive language model and a continual harness that refines its own workflow between attempts. Running on Opus 5, it reported 95.5% on ARC-AGI-3, a benchmark designed to test abstraction and in-context learning, and separately built working retro-console emulators from scratch. The significant claim is architectural rather than model-level: the scaffold around the model, not the model alone, is now a primary source of capability gains. ________________________________ Academic Research RESEARCH
