# Google cuts Gemini 3.7 Flash API price by 50%

Google is offering Gemini 3.7 Flash at half its standard API price through December 2026, with rates set to roughly double in January 2027. The report frames it as a limited window for developers building on Google's workhorse model. It lands amid intensifying price competition across frontier and mid-tier model APIs.
