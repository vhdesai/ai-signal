# Keenable AI Open-Sources NEEDLE, a Live Search Benchmark That Rebuilds Its Query Set Every Hour

Keenable AI open-sourced NEEDLE, an evaluation benchmark for search APIs and search agents that regenerates its query set hourly from fresh public sources so that answers cannot be memorized or leaked into training data. NEEDLE stands for News, Everyday, Expert, Deep-tail and Legal Evaluation, and it pools results across engines into a synthetic “oracle” engine used for scoring. It ships as a Python CLI. Continuously refreshed benchmarks are a direct response to benchmark contamination.
