# AI research system discovers novel HTTP desync attacks affecting ~700 live sites

PortSwigger's James Kettle published HTTP Terminator, an autonomous AI research system that tested ~30,000 candidate desync vectors and identified approximately 700 vulnerable targets, including banks, government infrastructure, and an airport. The system generated genuinely new attack classes plus an Apache Traffic Server zero-day. Security leaders should treat AI-discovered attack classes as a near-term change to patch-cycle assumptions.
