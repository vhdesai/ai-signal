# OpenAI Launches 'Private Safety Processing' to One-Up Anthropic on Enterprise Privacy

OpenAI previewed Private Safety Processing — an automated system that monitors for misuse across multiple sessions while retaining zero customer data. The system uses an agent to detect patterns (e.g., spreading cyberattack planning across sessions) and only sends a "narrowly defined signal" if triggered, never retaining conversation content. This directly counters Anthropic's July announcement of mandatory 30-day data retention for Mythos-class models, which has "deeply concerned" enterprises handling sensitive data. The WSJ reported OpenAI's Q2 growth was slower than Anthropic's ($40B vs $65B ARR), making enterprise differentiation critical. 🔗 https://techcrunch.com/2026/08/19/openai-seeks-to-one-up-anthropic-with-new-customer-privacy-protections/
