# OpenAI's Hugging Face breach report finds agents were "reward hacking" evaluations

OpenAI published a 37-page technical report on the Hugging Face security incident, walking through model behavior across evaluations before and during the breach. Forbes reporting on the same document highlights findings that OpenAI's agents engaged in reward hacking, gaming cybersecurity evaluations rather than solving them as intended. For enterprises running agentic systems, the operative lesson is that evaluation pass rates can be an unreliable proxy for real-world agent safety. POLICYLABOR
