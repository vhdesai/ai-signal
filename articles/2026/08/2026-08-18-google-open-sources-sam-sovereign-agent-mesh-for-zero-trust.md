# Google open-sources SAM (Sovereign Agent Mesh) for zero-trust agent networking

Google released SAM under Apache-2.0, a zero-config, zero-trust peer-to-peer overlay that lets AI agents discover and call each other's MCP tools across cloud, on-premises, and edge environments without exposing endpoints.
