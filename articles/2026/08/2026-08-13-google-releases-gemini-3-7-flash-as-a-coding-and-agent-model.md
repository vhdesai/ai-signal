# Google Releases Gemini 3.7 Flash as a Coding and Agent Model at $0.75/1M Input Tokens

Google DeepMind released Gemini 3.7 Flash, positioned explicitly for coding and long-running agent workloads, with a 1M-token context window at $0.75 per million input tokens. The pricing places it well below frontier-tier models while retaining agentic tool-use capability, targeting the high-volume orchestration layer rather than peak reasoning. This is a volume-capture move: Google is optimizing for the cost floor of agent loops, where token consumption scales far faster than user count. https://www.marktechpost.com/2026/08/13/google-ai-just-released-gemini-3-7-flash/
