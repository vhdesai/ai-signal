# AI coding tools are reinforcing JavaScript and TypeScript dominance

AI News argued that coding agents are contributing to the popularity of JavaScript and TypeScript because models perform best in the languages and frameworks most represented in training data. The result is a feedback loop: teams choose stacks that produce better agent output, publish more code in those stacks, and further improve future model performance on them. This has practical implications for enterprise architecture decisions because AI tool compatibility may now influence technology-stack selection.
