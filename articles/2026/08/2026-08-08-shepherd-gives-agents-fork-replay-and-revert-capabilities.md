# Shepherd gives agents fork, replay, and revert capabilities

Researchers at Northeastern University and Stanford released Shepherd, an open-source Python runtime substrate that records an agent run as a Git-like trace of typed events. The goal is to let developers fork, replay, and revert agent state rather than restarting long-running runs or patching forward with growing context. This is a meaningful agent-infrastructure direction because production agents need debuggability, state management, and reproducibility as much as raw model capability.
