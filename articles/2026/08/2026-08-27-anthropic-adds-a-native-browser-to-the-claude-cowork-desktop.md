# Anthropic Adds a Native Browser to the Claude Cowork Desktop App

Anthropic expanded its Claude Cowork desktop application with a built-in browser, allowing Claude agents to complete web-based tasks in the background rather than handing control back to the user. The move brings Anthropic into direct competition with agentic browsing efforts from OpenAI and Google. For enterprises, the practical question shifts from model quality to credential handling and audit trails for agent-initiated web actions. MONETIZATION
