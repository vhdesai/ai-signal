# AWS Details How Cohere Health Digitizes Clinical Policies Using Bedrock AgentCore

AWS published a case study on Cohere Health's use of Amazon Bedrock AgentCore to build Cohere Policy Studio, which automates digitization of clinical prior-authorization policies for health plans. The multi-tenant architecture uses AgentCore Runtime's microVM isolation for strict payer data separation, AgentCore Gateway for MCP-based tool access, and AgentCore Memory for analyst feedback loops — addressing a hard CMS regulatory deadline requiring API-based electronic prior authorization by January 2027.
