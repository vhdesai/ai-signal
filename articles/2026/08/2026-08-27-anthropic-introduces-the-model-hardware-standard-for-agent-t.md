# Anthropic Introduces the Model Hardware Standard for Agent-to-Machine Control

Anthropic announced the Model Hardware Standard (MHS), an interface designed to let AI agents operate any device that exposes a programmable interface — including scientific instruments and manufacturing equipment. Anthropic likened it to USB-C for machine interoperability; it is model-agnostic and in research preview with science, robotics, and manufacturing organizations, with plans to open-source it. This mirrors the 2024 MCP playbook: set the standard first, monetize the ecosystem later.
