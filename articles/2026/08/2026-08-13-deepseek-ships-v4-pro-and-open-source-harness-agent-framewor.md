# DeepSeek Ships V4-Pro and Open-Source "Harness" Agent Framework — Then Raises Prices

DeepSeek moved V4-Pro to general availability (1.6T parameters, 49B active, 1M-token context) with native OpenAI Responses API and Codex support, and released DeepSeek Harness v0.1, an MIT-licensed modular agent framework positioned against Claude Code and Codex that drew roughly 27,500 GitHub stars on day one. Simultaneously, DeepSeek ends flat-rate pricing in favor of peak/off-peak tiers from August 16, with Reuters reporting increases ranging from 50% to 1,100%. The move up the agent-orchestration stack while retiring the ultra-cheap-API positioning is a strategic pivot: DeepSeek is transitioning from a price disruptor to a platform vendor. Buyers who standardized on DeepSeek primarily for cost should re-baseline unit economics immediately.
