# FreeToken: Edge-Native MoE Serving Engine Runs 753B GLM-5.2 on a Single Workstation GPU

Researchers propose FreeToken, a serving system that maps Mixture-of-Experts computation across available GPU, CPU, memory, and PCIe bandwidth with bit-exact output. Reported: 753B-parameter GLM-5.2 at ~14.9 tokens/sec on a single workstation GPU, claiming 1.5–2.3× decode throughput over llama.cpp, Ollama, and KTransformers. Code ships under Apache 2.0. Claims are self-reported and not independently reproduced; the "single GPU" framing assumes 192–512GB of host DRAM.
