# Databricks makes Variant generally available for semi-structured data

Databricks announced general availability of Variant, an open standard for semi-structured data such as JSON, XML, and CSV developed with the Delta Lake, Apache Spark, Apache Parquet, and Apache Iceberg communities. The release includes Variant Shredding, which uses predictive optimization to column-store frequently queried fields and materially improve read performance. The strategic point is interoperability: Databricks is trying to own a key layer for AI-era data engineering across open table formats.
