# Meta releases Muse Glimmer for local personal agents

Meta released Muse Glimmer, a 30-billion-parameter open-weight model designed to run agentic workflows locally on consumer hardware. The model supports text and images and is intended for tasks such as working with files, screenshots, code, and personal workflows without sending all data to the cloud. Glimmer gives a concrete shape to Meta's personal-AI thesis: local inference may become a key privacy and cost lever for always-on agents.
