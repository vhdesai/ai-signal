# Warp's new system is an out-of-the-box software factory for AI development

Warp introduced Warp Factories, an infrastructure system that packages the components needed to stand up an AI software factory without assembling them individually. The pitch targets teams that have proven agentic coding in pilots but stalled on the orchestration, environment and governance plumbing required to scale.
