# Trump Administration Working on Rule to Curb China's Remote Access to AI Chips

The Trump administration is developing an AI rule to close the loophole that allows Chinese labs to access restricted Nvidia compute through overseas data centers — the same gap CNBC documented earlier this month. The rule would extend export controls beyond physical chip ownership to cover remote cloud access. If enacted, it would fundamentally reshape how AI compute is provisioned across Southeast Asian data centers.
