# OpenAI Codex Passes 20 Million Users Amid Usage-Limit Disputes

OpenAI's Codex coding agent reached roughly 20 million active users, but developers report that usage allowances are being consumed far faster than expected. OpenAI attributes much of the drain to "sub2api" reselling of subscription access through third-party API front-ends; parts of the developer community dispute that explanation. Enterprises standardizing on agentic coding tools should assume quota economics, not model capability, will be the near-term friction point.
