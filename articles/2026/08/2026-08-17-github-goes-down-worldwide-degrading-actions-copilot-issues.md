# GitHub goes down worldwide, degrading Actions, Copilot, Issues and Pull Requests

Microsoft confirmed a worldwide GitHub impairment affecting the web experience, API, archive and repository downloads, and SAML/OIDC/SCIM authentication, with Actions, Copilot, Issues and Pull Requests all degraded. CI/CD pipelines and coding-agent workflows broke for the duration.
