# GitHub Goes Down Worldwide, Degrading Actions, Copilot, Issues, and Pull Requests

Microsoft confirmed a worldwide GitHub impairment affecting the web experience, API, archive and repository downloads, and SAML/OIDC/SCIM authentication, with Actions, Copilot, Issues and Pull Requests all degraded. CI/CD pipelines and coding-agent workflows broke for the duration. The incident is a reminder that AI-assisted development has inherited — and amplified — a single-point dependency that most engineering continuity plans still treat as ambient infrastructure. Cursor's same-day Origin launch makes the timing more than coincidental.
