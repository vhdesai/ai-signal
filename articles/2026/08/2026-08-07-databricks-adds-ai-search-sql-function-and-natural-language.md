# Databricks adds ai_search() SQL function and natural-language Tag automations

Databricks released a Beta ai_search() SQL function that takes a natural-language query, generates optimized queries across one or more AI Search indexes, deduplicates and reranks results, and synthesizes a grounded answer. It is aimed squarely at batch RAG pipelines and compound AI systems built inside the warehouse. The same release notes add Tag automations in Beta, which apply or remove governed Unity Catalog tags on tables and volumes based on rules defined in natural language via Genie. Incremental, but a meaningful step toward retrieval and governance as first-class SQL primitives.
