# NVIDIA Releases NOOA, an Object-Oriented Python Framework That Turns an Agent Into a Single Class

NVIDIA Labs open-sourced NOOA (NVIDIA Object-Oriented Agents) under Apache 2.0, collapsing prompt templates, tool schemas, callbacks, and workflow graphs into a single Python class where methods are actions, fields are state, docstrings are prompts, and type annotations are runtime-enforced contracts. NVIDIA reports 82.2% on SWE-bench Verified and 86.8% on CyberGym L1 at roughly half the tokens of compared open harnesses. The package is classified alpha, and NVIDIA is explicit that its AST checks and deny-lists are defense-in-depth, not a containment boundary — production use requires container or VM isolation.
