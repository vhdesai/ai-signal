# Google open-sources HEIR, a compiler for running inference on encrypted data

Google published HEIR (Homomorphic Encryption Intermediate Representation), an open-source compiler toolchain that converts pretrained models so inference runs on encrypted inputs and the serving infrastructure never sees plaintext. Google demonstrated it on recommendation, credit-card fraud detection, network intrusion detection, and hotword detection workloads, and is co-developing hardware acceleration with several partners. The practical implication for regulated industries is a credible path to third-party inference without exposing customer data — though performance overheads remain the gating factor. https://blog.google/security/how-google-is-making-private-ai-practical-with-homomorphic-encryption/
