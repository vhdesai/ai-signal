# GLM-5.3 arrives with stronger long-horizon coding and cyber capabilities

VentureBeat reported that GLM-5.3 has launched with advanced cyber capabilities and has reportedly already found a serious vulnerability in Cursor. Related technical coverage says the model reuses the GLM-5.2 base model and attributes the gains to scaled post-training across longer-horizon task environments, coding, and cybersecurity. The release is strategically relevant because cyber-capable coding agents are moving from benchmark demos toward real vulnerability discovery, increasing both productivity potential and safety review requirements.
