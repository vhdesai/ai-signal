# AWS Reportedly Tells Engineers to Conserve CPU Capacity

AWS managers have reportedly instructed internal engineering teams to reduce compute usage wherever possible, including on CPU-based servers, with some engineers waiting days for resources. The significant detail is that scarcity has spread beyond GPUs into general-purpose compute and memory — consistent with agentic workloads consuming heavy orchestration cycles rather than pure matrix math. Enterprises modeling AI cost should stop treating CPU and memory as elastic background assumptions. Industry News A BUSINESS MODEL
