# Anthropic routes cyber-model Mythos 5 into Claude Security, adds $35M defender fund

Claude Mythos 5 — restricted to vetted defenders since April — now powers vulnerability scanning in Claude Security, in public beta for Enterprise customers. It connects to a GitHub repository, traces data flows across files, and returns findings with a CWE category, confidence and severity rating, and a suggested patch. A new $35M Defender Advantage credit fund backs open-source defense work. The packaging is the safety control: defenders receive scan outputs rather than direct model access, so the model cannot be steered into writing exploits.
