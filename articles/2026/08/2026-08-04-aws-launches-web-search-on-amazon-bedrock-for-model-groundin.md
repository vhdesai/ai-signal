# AWS launches Web Search on Amazon Bedrock for model grounding

AWS announced Web Search as a native built-in tool in Amazon Bedrock for grounding foundation model responses against a continually refreshed web index and knowledge graph. The feature is positioned for enterprise use with CloudTrail audit logging and data-control defaults, initially available for OpenAI GPT models served through Bedrock's next-generation inference engine. This is a direct move to make Bedrock more complete as an enterprise AI platform without relying on external search-grounding vendors. AGENTIC AIAWSOPERATIONS
