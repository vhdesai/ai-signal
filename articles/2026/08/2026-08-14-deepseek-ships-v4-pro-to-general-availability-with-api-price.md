# DeepSeek ships V4-Pro to general availability, with API prices rising today

DeepSeek moved V4-Pro out of preview with native support for the OpenAI Responses API and stronger agent benchmarks. The company paired the release with a steep API repricing — reported at several multiples of V4 Flash rates — taking effect August 16 with new peak and off-peak tiers.
