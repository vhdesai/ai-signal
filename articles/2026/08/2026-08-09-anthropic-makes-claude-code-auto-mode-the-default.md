# Anthropic Makes Claude Code Auto Mode the Default

Anthropic will make auto mode the default in Claude Code for Pro, Max, and Team plans starting August 14. A classifier blocks irreversible, destructive, or out-of-scope actions; in a controlled study it caught 89% of dangerous commands vs. 13.6% for manual review. Users in auto mode shipped ~25% more PRs. Enterprise and API remain opt-in. Engineering leaders should review sandboxing and permission policies before August 14. Industry News FUNDING
