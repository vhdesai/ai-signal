# OpenAI details Habitat — the storage platform now serving 1B ChatGPT users at 22M requests/sec

OpenAI published a rare engineering deep-dive on Habitat, the internal storage platform that evolved from a Python library into a globally distributed system now serving over 1 billion ChatGPT users and 22 million requests per second. The post details the architecture and scaling decisions that supported the Astra launch surge. For infrastructure and SRE leadership, it is a concrete external reference on frontier-scale AI-application storage — comparable in signal to the mid-2010s posts from Google, Meta, and Netflix on their own storage platforms.
