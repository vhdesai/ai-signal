# Anthropic details plans for a biology lab where Claude will guide robots through drug experiments

Following yesterday's TechCrunch reporting, The Decoder provides technical detail: Anthropic's in-house biology lab will have Claude directly orchestrate robotic wet-lab experiments — moving AI-for-drug-discovery beyond in-silico prediction into real-world experimental control. For life-sciences executives, the ability of a frontier model to run robotic biology experiments end-to-end is a materially different capability from the AlphaFold/AlphaGenome pattern and should reset planning for AI-for-pharma partnerships accordingly.
