# Apple explores return to server market with M8 Ultra + Nvidia NVLink Fusion, targeting 2029

Apple is developing dedicated AI servers built around future M8 Ultra processors in two- and four-chip configurations aimed at developers, enterprises, and governments, with no arrival before 2029. It would be Apple's first purpose-built server line since Xserve was discontinued in 2011, backed by CEO John Ternus. Notably, Apple has discussed using Nvidia's NVLink Fusion to link M8 chips at high bandwidth without placing Nvidia GPUs in the box. The project could still be cancelled or ship without Nvidia's interconnect. - https://www.techrepublic.com/article/news-apple-m8-ultra-ai-server-2029/
