# OpenAI expands Agents API documentation, including a self-hosted sandbox option

Expanded documentation now covers conversation state, background mode, streaming and WebSocket modes, mid-turn steering, multi-agent orchestration, webhooks and file inputs. The detail developers seized on was the option to self-host the agent sandbox, which commenters said could reduce vendor lock-in — a direct response to the data-residency and retention constraints flagged when the Agents API entered beta. Documentation updates are not formally dated, so treat as directional.
