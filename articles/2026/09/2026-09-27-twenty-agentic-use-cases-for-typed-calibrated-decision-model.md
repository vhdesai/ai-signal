# Twenty agentic use cases for typed, calibrated decision models

An applied evaluation of Jev, a “System One” model that returns typed decisions with calibrated probabilities instead of generated text, trained with Reinforcement Learning for Calibrated Decisions (RLCD). The piece documents 20 verified agentic use cases spanning model routing, tool-call risk gating, secret-leak guarding, prompt-injection screening, reranking and citation verification. Two measured results stand out for enterprise agent design: reranking across 40 CLERC legal queries lifted top-1 accuracy from 5% to 18%, and in an injection-screening case cosine similarity ranked a planted injection first (0.584) while Jev scored and dropped it at 0.99. The pattern — small typed classifiers guarding large generative agents — is the same architectural instinct behind Nvidia's Sentry.
