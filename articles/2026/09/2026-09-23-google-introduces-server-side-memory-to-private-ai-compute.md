# Google introduces server-side memory to Private AI Compute

Private AI Compute now supports secure server-side memory for personal AI, letting Gemini retain durable user context in a confidential-compute enclave rather than only in the local device. The change matters because it lets Google offer memory-backed personal assistants without weakening the "your data stays yours" claim that has been central to its differentiation from OpenAI on privacy-sensitive workloads.
