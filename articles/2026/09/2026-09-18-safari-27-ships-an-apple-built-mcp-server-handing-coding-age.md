# Safari 27 Ships an Apple-Built MCP Server, Handing Coding Agents the Browser

Apple's Safari 27.0 includes a Model Context Protocol server built into the safaridriver binary already shipped with macOS, letting Claude Code, Codex, or any MCP client drive a real Safari window. The server exposes ~16 tools — tab management, page content as markdown/HTML/JSON, screenshots, network inspection, console output, JavaScript execution, dialog handling, and viewport/media emulation. It runs entirely locally, makes no network calls of its own, and sends captured data only to the connected agent.
