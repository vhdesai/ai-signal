# Oracle emphasizes securing database estates against AI-enabled attacks

Omdia published an analysis of Oracle's approach to protecting database estates from AI-enabled attacks at the source. The item is relevant because AI-assisted intrusion, credential misuse, and automated data discovery increase the value of controls embedded close to core enterprise data. For technology leaders, the operational question is whether AI security investments should sit primarily at the application layer, the model layer, or deeper in identity, data, and database infrastructure.
