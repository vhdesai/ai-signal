# MiniMax Ships M3.1-Flash-Preview Inside MiniMax Code — No Card, No Pricing, No API

MiniMax confirmed on September 27 that M3.1-Flash-Preview is live in its MiniMax Code assistant, positioned for everyday development work — bug fixes, reviews, and small features — alongside M3, M2.7, and M2.7-highspeed. The release introduces a five-tier reasoning-effort control (low through max, default max), replacing M3’s simpler thinking toggle. MiniMax published no model card, benchmark table, context limit, API identifier, or pricing, and the public endpoint remains gated; circulating partner architecture notes describing all-sparse attention and 4-bit KV remain unverified. The quiet rollout fits a broader pattern of high-cadence, low-price Chinese model releases now capturing a majority of token volume on routing platforms such as OpenRouter.
