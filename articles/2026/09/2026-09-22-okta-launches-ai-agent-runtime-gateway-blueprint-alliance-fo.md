# Okta launches AI Agent Runtime Gateway; Blueprint Alliance formed with AWS and CrowdStrike

SiliconANGLE and Business Wire report Okta launched an AI Agent Runtime Gateway and formed the Blueprint Alliance with AWS, CrowdStrike, and additional partners to define shared architecture for securing AI agents. The Alliance is a direct response to the OpenAI Codex Heapjack/Overpatch sandbox escapes, the Claude-Opus-5 OpenAI breach, the Google Gemini test breakout, and Cybernews's AWS AgentCore credential exposure disclosure. It's the most coordinated industry-wide effort yet on agent-runtime security and lands the same week as Salesforce's AIforce agent-governance layer.
