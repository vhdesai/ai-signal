# Perplexity Introduces Hybrid Compute, Splitting Agent Tasks Between Cloud Models and Local Macs

Perplexity launched hybrid compute for its Computer agent, allowing a single task to begin on frontier cloud models while steps touching confidential files are handed to an open-weight model running locally on Apple silicon — without restarting the workflow or losing context. This addresses the most common enterprise objection to autonomous agents: data egress. If the pattern holds, privacy-aware model routing becomes a standard component of agent infrastructure rather than a differentiator. https://www.cultofmac.com/news/perplexity-hybrid-compute-mac-release PRODUCT
