# Google open-sources AX, an agentic orchestrator for Kubernetes

AX — “Agent Executor” — spent Monday at the top of Hacker News as Google’s open (Apache 2.0) declarative control plane for running agent workloads at scale, built on a runtime Google calls Agent Substrate. It defines four primitives: Task (sandboxed execution with CPU/memory limits), Workspace (repos, MCP servers and skills, or a plain-English “generative workspace”), Gateway (explicit network allowlist plus credential injection), and Model (centralized model, parameter and secret configuration). Headline claims include billions of concurrent agent tasks per cluster and sub-second resume from suspend. The project is still v1alpha1 with breaking changes expected, so treat it as a directional signal on agent infrastructure rather than a deployment decision. AI Safety & Policy Breaking Policy
