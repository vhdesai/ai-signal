# Google Home MCP server opens third-party agent access — Claude, Antigravity, and OpenClaw are launch clients

Google's Home Model Context Protocol server gives third-party agents — including Anthropic's Claude — authorized access to Google Home data and device controls: discovering homes, finding connected resources, checking device state, reviewing historical events, and executing supported actions. Google restricts some physical actions (notably a prohibition on unlocking doors) and requires a Premium Advanced subscription plus OAuth setup. Antigravity and OpenClaw are also listed as compatible MCP clients. The rollout began September 16; this coverage published September 18. - https://www.techrepublic.com/article/news-google-home-claude-ai-agents/
