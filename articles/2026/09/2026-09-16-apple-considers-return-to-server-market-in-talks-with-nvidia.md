# Apple considers return to server market, in talks with Nvidia to use networking tech

The Information reports Apple has been working on plans for an enterprise server built on its own silicon that could incorporate Nvidia networking equipment — Apple's first serious server play since the Xserve discontinuation in 2011. The move is framed as an attempt to capitalize on surging interest in its consumer-facing Apple Intelligence stack, but the deeper read is vertical: Apple wants to control the inference substrate for on-device and edge-AI workloads it already ships. For hyperscaler and OEM strategists, an Apple/Nvidia-adjacent enterprise server SKU would open a new tier below the AI factory but above the workstation. - https://www.theinformation.com/search?utf8=%E2%9C%93&query=Apple+server+market+Nvidia+networking
