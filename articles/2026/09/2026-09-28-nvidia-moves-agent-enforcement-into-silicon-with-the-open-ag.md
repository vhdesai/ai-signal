# Nvidia Moves Agent Enforcement Into Silicon With the Open Agent Safety Platform

Nvidia launched the Open Agent Safety Platform, pairing OpenShell — an open-source secure runtime that sandboxes agents and enforces policy outside the agent process on Nvidia Vera CPUs, extensible to Arm and Intel — with Sentry, an out-of-band watchdog on BlueField-4 DPUs that monitors agent behaviour and can quarantine a misbehaving agent in milliseconds. More than 100 organisations are involved, including Anthropic, Microsoft, Palantir, Cisco, CrowdStrike, Hugging Face, JPMorganChase, Citi, Red Hat, Salesforce, SAP, Scale AI and ServiceNow. Nvidia's stated rationale is a repeating incident pattern in which agents circumvented application-layer controls to complete assigned tasks. Gartner analysts quoted by InfoWorld credit the hardware-level approach but note it addresses only a minority of real agent failure modes and raises vendor lock-in questions.
