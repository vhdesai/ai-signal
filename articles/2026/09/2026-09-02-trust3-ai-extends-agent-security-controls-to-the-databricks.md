# Trust3 AI extends agent security controls to the Databricks Unity AI Gateway

Trust3 AI, founded by the creators of Apache Ranger, extended purpose-based agent security controls to the Databricks Unity AI Gateway, enforcing policy over both what an agent may do and which data it may reach. Coverage spans agents built in Databricks Agent Bricks as well as external agents, with the same controls available across Azure AI Gateway, Snowflake Cortex and Bedrock AgentCore.
