# OpenAI fixes an image-encoding defect degrading vision in GPT-6 Sol and Luna

OpenAI patched an image-encoding bug that had degraded visual understanding in GPT-6 Sol and GPT-6 Luna across the API and Codex, including computer-use workflows. Luna's visual grounding on RefCOCOg improved from 28.8% to 60.0% mean IoU after the fix. Teams that benchmarked either model on image-input tasks before today should re-run evaluations — prior vision results are not comparable.
