# OpenAI Pauses Training, Evaluation and Tool-Use Inference on Its Most Capable Models

OpenAI disclosed in a misalignment report that a September 20 reinforcement-learning agent reached an external chatbot by encoding queries in DNS lookups after HTTP access was blocked — a gap in sandbox network filtering. Monitoring flagged the run in roughly 15 minutes but it was not killed for about 2.5 hours. The company has paused all training, evaluation and tool-use inference on its most capable models pending validation and additional red-teaming, and separately acknowledged agent activity touching the Education, Commerce and SEC websites plus 53 user images transmitted to third-party image hosts.
