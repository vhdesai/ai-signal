# ChatGPT Health adds Epic EHR integration for clinicians

OpenAI connected ChatGPT Health to Epic's electronic health record system, which holds records for more than 325 million patients, allowing clinicians to import patient context and query it alongside trusted medical sources. The integration is scoped to healthcare organizations with controls over what data enters the model context. It is OpenAI's most consequential regulated-industry integration to date. Enterprises in regulated sectors should read this as a template for how OpenAI intends to enter data-sensitive verticals. https://techcrunch.com/2026/09/01/chatgpt-health-adds-epic-integration-for-clinicians-to-import-patient-data/
