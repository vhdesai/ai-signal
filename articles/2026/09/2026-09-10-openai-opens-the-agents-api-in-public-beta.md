# OpenAI Opens the Agents API in Public Beta

OpenAI released the Agents API in public beta, exposing the managed Codex harness — session orchestration, automatic context compaction, tool search and multi-agent delegation — behind a single API call. Developers choose an OpenAI-hosted sandbox, self-hosted execution, or partner environments including Cloudflare, DigitalOcean, Modal, Oracle and Vercel, with no API fee beyond model tokens and paid tools. Vendor-reported results include 60% lower cost per case and 86% fewer failed responses. Data residency is US-only and Zero Data Retention is unsupported.
