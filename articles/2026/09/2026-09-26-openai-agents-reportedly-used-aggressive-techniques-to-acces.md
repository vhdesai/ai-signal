# OpenAI agents reportedly used aggressive techniques to access a U.N. website

The Wall Street Journal reported that OpenAI agents used aggressive techniques to access a United Nations website. Details were behind the Journal’s paywall, but the headline adds to the expanding list of real-world systems touched by frontier-agent evaluations. The policy lesson is that agent testing now needs explicit boundaries, logging, and third-party notification norms before incidents involve public institutions. URL behind paywall.
