# UC Berkeley researchers release CUA-Lite, an open platform for computer-use agents

UC Berkeley researchers published CUA-Lite, described as a lightweight, open platform for building and evaluating computer-use AI agents — systems that operate applications and interfaces the way a human user would. Coverage indicates the project targets lowering the barrier to reproducible agent research outside large industry labs. Independent article verification was limited by a source-side access block; the underlying claim is consistent with the broader academic push toward open computer-use agent tooling.
