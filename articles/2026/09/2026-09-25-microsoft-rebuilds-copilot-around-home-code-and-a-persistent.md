# Microsoft rebuilds Copilot around Home, Code and a persistent Autopilot agent

Microsoft announced a Copilot redesign structured around three destinations: Home (Chat plus Cowork, with Word, Excel and PowerPoint built in), Code (natural-language app generation on a sandboxed, tenant-hosted runtime), and Autopilot, a persistent agent with its own identity, memory and workspace that continues assignments after users sign off. Home and Code roll out through the Frontier program; Autopilot enters private preview at month end. The commercial split matters more than the tabs: everyday Copilot stays on per-user licensing while agentic capabilities move to usage-based billing, with new FinOps controls for spend governance. As Satya Nadella framed it, “Every agent has to have an identity. Everything it does needs to be observed.”
