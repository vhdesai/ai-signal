# Nvidia's SoL-Pi cuts coding-agent token usage by up to 49 percent

Nvidia researchers report that SoL-Pi reduces coding agents' token traffic by up to 49 percent with little change in task performance, by optimizing the harness — the control layer between model and environment — rather than the model itself. A research agent evaluated 152 approaches across more than 3,000 runs to arrive at four retained mechanisms covering action execution, context compaction, observation handling and delegated reading. On the 51-task EdgeBench evaluation the system cuts API cost by roughly one third; gains were smaller on other benchmarks. For teams running agents at volume, harness efficiency is a cost lever independent of model choice.
