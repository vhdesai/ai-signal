# NVIDIA releases Nemotron 3 Diarization for real-time speaker tracking

NVIDIA released Nemotron 3 Diarization, a 100M-parameter open-weight speaker diarization model that identifies up to eight speakers in live or recorded audio. Unite.AI reported that the model supports streaming and offline inference, can label speakers at configurable intervals as low as 320 milliseconds, and replaces multi-stage diarization pipelines with a single pass. This matters for meeting transcription, call-center analytics, and voice-agent systems where low-cost, real-time attribution is becoming table stakes. ROBOTICSOPEN WEIGHTS
