# StepFun launches Step 5 Preview, a 600B-total MoE model for long-horizon agentic work

MarkTechPost reported that StepFun launched Step 5 Preview, a mixture-of-experts model with 600B total parameters, 27B active parameters, and a 1M-token context window. The claimed design targets long-horizon agentic work where models need to maintain state, inspect large contexts, and coordinate multi-step tasks. If validated independently, the release would reinforce the industry's move from short conversational models toward long-context execution systems. Products & Tools AGENT TRAINING OPEN SOURCE
