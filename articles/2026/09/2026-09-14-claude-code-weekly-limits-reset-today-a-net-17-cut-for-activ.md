# Claude Code Weekly Limits Reset Today — A Net 17% Cut for Active Users

Anthropic's temporary 50%-above-baseline weekly allowance for Claude Code expired at 11:59 PM PT on September 13, replaced today by a permanent level set 25% above the pre-promotion baseline. Indexed, that is 100 before May, 150 through yesterday, 125 from today — a 16.7% reduction against the capacity teams have operated on since May 13. Scope is Pro, Max, Team and seat-based Enterprise plans; five-hour limits and Claude chat allowances are unchanged. Anthropic has published no absolute token figures, so engineering leaders should re-baseline sprint capacity empirically rather than from the headline percentage.
