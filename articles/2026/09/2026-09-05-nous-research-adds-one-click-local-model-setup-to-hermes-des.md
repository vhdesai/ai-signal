# Nous Research adds one-click local model setup to Hermes Desktop

Hermes Desktop now detects local hardware, fit-checks the model catalog against available GPU memory, selects the highest-quality build that fits, and configures llama.cpp automatically — with a 4-bit quantization floor and a 64K minimum context window. The change removes the main friction point in on-premises model deployment for individual workstations. Relevant to any organization evaluating local inference for data-residency or cost reasons.
