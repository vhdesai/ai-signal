# Safari 27 Ships a Native MCP Server, Letting Coding Agents Drive the Browser

Apple shipped a Safari MCP server in Safari 27.0, allowing Claude Code, Codex or any MCP-compatible agent to control a Safari window: reading the DOM, inspecting network requests, capturing screenshots, pulling console output and running JavaScript in the active tab. Developers enable it via “Allow remote automation and external agents” in Safari's Developer settings and connect through the existing safaridriver binary with a new --mcp flag. Apple states the server runs entirely locally, makes no network calls of its own, and has no access to personal Safari data.
