# UC Riverside Uses Machine Learning to Find Odorants That Repel Honey Bees From Treated Crops

A team led by Prof. Anandasankar Ray trained a model on odorant chemical structures plus behavioural response data, screened more than 50 million compounds, and identified about 130 predicted strong bee repellents; field trials confirmed all seven compounds tested reliably repelled bees from honey combs without harming them, published in eLife. Ray’s methodological claim travels well beyond entomology: “It is generally thought you need abundant data to do any kind of machine learning, but that’s not true for olfaction. You simply need good-quality data and iterative improvement steps.”
