# Microsoft's Project Zenith brings AI-generated native WinUI 3 apps to Windows 11

Microsoft is enabling AI-driven creation of native WinUI 3 desktop applications for Windows 11 in under 30 minutes, part of the "Project Zenith" developer initiative. The move pushes Copilot-style code generation beyond web-app scaffolding into native desktop deliverables, reducing the barrier for Windows developers building line-of-business tooling. It also positions Microsoft against cross-platform browser-first AI generators by tying code generation to native Windows APIs.
