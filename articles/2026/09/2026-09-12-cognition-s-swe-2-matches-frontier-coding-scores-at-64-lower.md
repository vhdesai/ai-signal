# Cognition's SWE-2 Matches Frontier Coding Scores at 64% Lower Cost

Cognition released SWE-2, post-trained with reinforcement learning from Moonshot's 2.8-trillion-parameter Kimi K3 base. It scores 50.0% on Cognition's FrontierCode 1.1 Main benchmark — within one point of Fable 5.1 — while running 64% cheaper, and leads the compared field on Terminal-Bench 2.1 at 92.8%. The methodological novelty is training all three reasoning-effort tiers in a single RL run using a cost-penalized reward, which moves the entire cost-performance frontier rather than one operating point. Two caveats matter commercially: the model has no open weights and no standalone API (it runs only inside Devin), and it trails Fable 5.1 and GPT-6 Astra by roughly 30 points on the harder Terminal-Bench 4 suite. All comparison figures are vendor-reported on Cognition's own benchmark. OPEN WEIGHTS
