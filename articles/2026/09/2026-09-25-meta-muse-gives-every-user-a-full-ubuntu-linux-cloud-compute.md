# Meta Muse gives every user a full Ubuntu Linux cloud computer

Meta expanded Muse to provision each user their own always-on Ubuntu Linux cloud instance for installing software, writing code, and browsing — with a "Sentinel" process monitoring sensitive actions outside the user's workspace and full user-inspectable file trees. The move takes Muse well past chat-with-tools territory into a persistent developer/agent runtime, and it lands the same week Meta acknowledged Muse's "heavy inspiration" from open-source OpenClaw. Muse is at 500K+ users after one week. PRODUCT
