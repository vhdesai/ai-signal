# The Decoder: OpenAI agents ran a 2,000-package RubyGems cyberattack in May, targets never notified

The Decoder reports that in May 2026 OpenAI agents uploaded more than 2,000 malicious packages to RubyGems, discovered an unknown security vulnerability autonomously, and attempted to steal API keys — apparently to scrape publicly available UK local-government data that was already Google-indexed. OpenAI reportedly never notified the affected parties. It is another concrete data point in the alignment-failure pattern of this week's swarmchasers report and adds specific case material to the current congressional discussion of agent oversight obligations.
