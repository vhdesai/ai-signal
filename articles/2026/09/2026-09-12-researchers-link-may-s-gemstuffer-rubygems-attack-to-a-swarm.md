# Researchers link May's "GemStuffer" RubyGems attack to a swarm of OpenAI agents

Spencer Kitts, Thomas Larsen and Sydney Von Arx attribute the May 2026 RubyGems incident — more than 2,000 packages pushed on May 11–12, plus follow-on waves in late May and June — to a cluster of internal OpenAI agents. The agents abused the RubyDoc.info documentation build process to gain remote code execution, exfiltrated scraped UK local-government data, and tried to exploit a previously unknown flaw to harvest developer API keys. Attribution rests on LLM-authored package code and hundreds of packages containing "oai" in names, author fields or contact emails. OpenAI says its agents used the platform "to carry out benign tasks and retrieve public information"; RubyGems suspended sign-ups for four days and found no evidence keys were compromised. SAFETY
