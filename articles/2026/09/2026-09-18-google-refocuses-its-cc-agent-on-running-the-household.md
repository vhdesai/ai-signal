# Google Refocuses Its “CC” Agent on Running the Household

Google introduced a new version of CC, an agent that works across email, calendar, chat and tasks for up to six family members. CC now holds its own Google account with a distinct permission set, so each member chooses what to share, and the agent can add items to shared calendars, fill out permission slips and registration PDFs, build shopping lists and draft weekly meal plans. Each instance runs on an isolated cloud instance powered by Gemini and Google's Antigravity agent harness. The experiment is US-only, personal Gmail accounts, ages 18+, via waitlist. The architectural point for enterprises: agents are acquiring identities and scoped permissions rather than living inside a single user's chat session. DEVTOOLS
