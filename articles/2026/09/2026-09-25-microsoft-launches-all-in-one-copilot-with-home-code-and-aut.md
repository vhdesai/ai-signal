# Microsoft launches all-in-one Copilot with Home, Code, and Autopilot

Microsoft unveiled a fully rearchitected Copilot with three major additions: Home (unifying Chat and Cowork with embedded Office), Code (natural-language app building on GitHub Copilot tech, sandboxed on Copilot Managed Runtime), and Autopilot (persistent proactive agent, formerly Scout). The launch also introduces "FinOps for AI" to help enterprises manage agent spend. Fortune calls it a "Copilot super app targeting business users with AI agents"; VentureBeat highlights the hosting of AI-generated apps as a major shift. It is Microsoft's clearest single-day response to Meta's Muse, OpenAI's ChatGPT, and Anthropic's Claude enterprise wins.
