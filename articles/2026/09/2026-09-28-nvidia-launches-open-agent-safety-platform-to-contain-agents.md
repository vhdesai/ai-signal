# Nvidia launches Open Agent Safety Platform to contain agents in silicon

Nvidia released the Open Agent Safety Platform, pairing OpenShell — an Apache 2.0 runtime that enforces policy and credential boundaries around an existing agent without rewriting it — with Sentry, an out-of-band watchdog on BlueField-4 DPUs that can quarantine a boundary-crossing agent in milliseconds. Jensen Huang described it to CNBC as "a browser for agents," and Nvidia said the design could have prevented the July Hugging Face incident, in which Hugging Face reported over 17,000 agents attacking its infrastructure. More than 100 organisations are building on it, including Anthropic, Microsoft, Oracle, Cisco, JPMorganChase, Palantir, Salesforce, Arm and Intel. The commercial subtext: agent governance is now tied to Nvidia Vera CPUs and BlueField-4 silicon.
