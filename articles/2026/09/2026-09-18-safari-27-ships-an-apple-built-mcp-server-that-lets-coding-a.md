# Safari 27 Ships an Apple-Built MCP Server That Lets Coding Agents Drive the Browser

Safari 27.0 includes a Model Context Protocol server that gives Claude Code, Codex, or another agent control of a real Safari window through sixteen tools — tab management, navigation, page content as markdown/HTML/JSON, screenshots, console messages, network request inspection, click/type/scroll interactions, JavaScript evaluation, dialog handling, and viewport/media emulation. Apple states the server runs entirely locally, makes no network calls of its own, has no access to personal Safari data, and sends captured data only to the agent the developer is running. Enabling it takes two settings checkboxes and one terminal command. Apple opening first-party browser automation to third-party agents is a notable posture change. ENTERPRISE
