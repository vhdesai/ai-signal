# Google Publishes AX, an Open Agentic Orchestrator for Kubernetes

Google released AX ("Agent Executor"), an Apache 2.0 declarative control plane for running agent workloads at scale, under its official GitHub organization. It defines four primitives — Task (sandboxed execution with CPU/memory limits), Workspace (Git repos, MCP servers and skills, or a plain-English "generative workspace" goal), Gateway (explicit outbound host allowlists plus credential injection) and Model (centralized model, parameter and secret config) — applied through a kubectl-shaped CLI. It runs on Agent Substrate, a runtime traced to Google DeepMind agentic-runtime research, with claims of billions of concurrent tasks per cluster and sub-second suspend/resume. The project explicitly warns of breaking changes before a stable release.
