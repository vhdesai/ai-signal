# AIR Security launches with $50M to build a firewall for AI agents

AIR Security emerged from stealth with $50 million across two seed rounds led by Sequoia and Greenoaks. Its platform discovers AI agents in enterprise environments, inspects the plug-ins, skills, and MCP servers they use, and blocks components that fail security checks. The launch reinforces agent supply-chain governance as a distinct category inside enterprise security.
