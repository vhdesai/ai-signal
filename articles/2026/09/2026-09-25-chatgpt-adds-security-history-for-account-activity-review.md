# ChatGPT adds security history for account activity review

OpenAI shipped “security history,” letting users review recent sign-ins, sign-outs and changes to MFA, passkeys and other security settings, each with time, location and device details, under Settings > Security and login on the web. The same day, Codex 0.157.0 added GPT-6 Sol and Luna support plus Amazon Bedrock integration. The security work lands amid OpenAI's ongoing agent-behavior disclosures (below).
