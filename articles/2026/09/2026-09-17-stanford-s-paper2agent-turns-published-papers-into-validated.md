# Stanford's Paper2Agent turns published papers into validated MCP servers

Stanford researchers released Paper2Agent, which converts a published paper into a validated Model Context Protocol server so an agent can re-run the paper's methods on new data. Demonstrations with AlphaGenome, Scanpy, and TISSUE were built in ~45 minutes each at ~$13–14 apiece; multi-agent collaboration among them independently identified GPR137 as a causal gene for psoriasis. Of 100 computational-biology papers processed, 74 were successfully agentified with 91.2% accuracy on 300 benchmark questions. The work targets the reproducibility gap between a published method and a runnable implementation. - https://www.theregister.com/ai-and-ml/2026/09/17/scientific_papers_become_agentic_chatbots_with_new_tool/
