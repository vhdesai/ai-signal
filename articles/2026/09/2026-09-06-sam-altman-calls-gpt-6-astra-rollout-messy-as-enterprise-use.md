# Sam Altman calls GPT-6 Astra rollout "messy" as enterprise users wait for access

Computerworld reported that OpenAI's GPT-6 Astra rollout faced early access issues after some paying ChatGPT users could not use the model shortly after launch, prompting Sam Altman to apologize publicly. The incident highlights the gap between model announcement and reliable availability across consumer, enterprise, and API tiers. For enterprise buyers, the relevant issue is production readiness: access controls, capacity allocation, and service communication matter as much as capability claims.
