# OpenAI opens ChatGPT to "Sponsored Agents," wiring ads into HubSpot and Shopify

OpenAI began testing Sponsored Agents, a format in which clicking an ad in ChatGPT opens a clearly labeled conversation with an advertiser's own agent rather than sending the user to an external site. The launch bundles natural-language campaign management through an Ads Manager plugin in ChatGPT Work, AI-generated ad copy and imagery, and first-party integrations with HubSpot (CRM) and Shopify (commerce). OpenAI has said ChatGPT Ads reached a $1 billion annualized run rate in under 200 days, on self-reported figures. The strategic question for enterprises is governance: the same interface now carries independent answers, paid conversations, and commerce execution — and employees treat it as neutral. - https://finance.yahoo.com/media-advertising/articles/openai-sponsored-agents-turn-chatgpt-155347973.html
