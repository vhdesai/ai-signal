# Georgia Tech finds many AI-generated security patches are semantically wrong

Georgia Tech researchers shared lessons from DARPA's AI Cyber Challenge at USENIX Security 2026, reporting that 38% to 46% of AI-generated patches were semantically incorrect despite passing surface-level checks, according to the source feed. The finding directly quantifies the verification gap in autonomous vulnerability remediation and argues for human review plus formal validation in agentic security pipelines.
