# Meta ships Muse Spark 1.3 as agent economics move to the foreground

Meta rolled out Muse Spark 1.3 for coding, tool use, and long-running agentic workflows, with source-feed reporting pointing to fewer tool calls and lower token consumption than the prior version. The important signal is economic rather than purely technical: as agents chain hundreds of steps, cost per completed task becomes more meaningful than cost per token or isolated benchmark scores. Meta is positioning the Spark family as a lower-cost path for high-volume agent workloads.
