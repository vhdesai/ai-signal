# xAI’s Grok 4.7 arrives on Amazon Bedrock with a 500K context window

AWS added Grok 4.7 to the Bedrock catalog, served on the bedrock-runtime endpoint through cross-Region inference profiles with a 500K token context window, text and image input, and four configurable reasoning-effort levels. The model is unchanged from its September 21 xAI release; what changes is the distribution path — IAM authentication, one AWS bill, and Bedrock Guardrails and logging for teams already standardized on AWS. AWS cites Artificial Analysis figures showing Grok 4.7 at an Intelligence Index of 46 versus 44 for Grok 4.6, with roughly double the output tokens per task — a cost trade-off worth setting effort levels deliberately for.
