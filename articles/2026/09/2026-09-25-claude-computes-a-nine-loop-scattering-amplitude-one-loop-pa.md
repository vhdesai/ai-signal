# Claude Computes a Nine-Loop Scattering Amplitude — One Loop Past the Human Record

Anthropic published a guest post by physicist and science writer Matt von Hippel reporting that Claude computed the six-particle hexagon amplitude in planar N=4 super Yang-Mills at nine loops, exceeding the eight-loop record set in 2023 by Lance Dixon and Andy Liu. The run used Fable 5.1 inside Claude Science, started from a one-line prompt, ran largely unsupervised for days, and solved the problem via two independent routes — a direct bootstrap and a form-factor path using antipodal duality. Dixon independently verified the result. Von Hippel’s own assessment is deliberately measured: Claude applied known methods with more compute rather than inventing new ones, and a human group at the Chinese Academy of Sciences reached most of the same result in the same weeks. The signal is throughput on established methods, not a paradigm shift. SCIENCE ADOPTION
