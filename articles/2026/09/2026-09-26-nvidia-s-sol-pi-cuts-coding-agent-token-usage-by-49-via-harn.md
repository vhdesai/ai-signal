# Nvidia's SoL-Pi cuts coding-agent token usage by ~49% via harness optimization

Nvidia published SoL-Pi, a system that reduces coding-agent token consumption by up to 49% at near-flat performance by optimizing the control layer (the "harness") between the model and its environment rather than the model itself. A research agent tested 152 harness variants across 3,000+ runs to arrive at the configuration. Gains were smaller on non-coding benchmarks, but the finding — that harness engineering carries meaningful compute-cost delta on top of the underlying model — reframes how enterprises should think about token budgets for their internal Codex/Claude Code deployments.
