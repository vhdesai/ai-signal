# UC Berkeley releases CUA-Lite, an open platform for computer-use agents

A UC Berkeley-led team released CUA-Lite, which unifies sandboxes, trace data, evaluation, and reinforcement learning for computer-use agents behind a single action space and data schema. The argument is infrastructural rather than model-centric: the four components required to train and benchmark such agents currently ship in incompatible formats. Standardized evaluation is a precondition for credible enterprise claims about agent reliability.
