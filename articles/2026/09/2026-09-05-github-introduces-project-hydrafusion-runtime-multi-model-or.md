# GitHub introduces Project HydraFusion: runtime multi-model orchestration in Copilot CLI

GitHub’s research preview treats workflow selection as an optimization problem rather than a model picker, routing each coding task between three execution patterns: Single, Cascade with a quality gate, and Critique with a read-only cross-family reviewer. Billing is per token consumed by whichever models the workflow invokes, at each model’s standard rate. The commercial question is whether per-task routing reduces total cost without a quality regression — early benchmark reporting suggests cost gains are consistent while quality parity is not.
