# Microsoft Publishes First "Humanist AI" Code of Conduct for MAI Models

Microsoft AI published its first-ever public Code of Conduct for MAI models, opening a six-week consultation. The Humanist AI Code frames "people matter more than AI," ranks the Code above operator policies and user preferences, and states MAI models must fail their task whenever completing it would violate the Code. Absolute Constraints ban CBRNE assistance, offensive-cyber operational capability, evasion of human oversight, and coordinated influence operations; Human Control Requirements ban resisting shutdown, initiating goals outside authorized scope, and communicating in "neuralese" chain-of-thought or agent-to-agent. Fortune reports Mustafa Suleyman is calling on frontier labs to coordinate on safety "now."
