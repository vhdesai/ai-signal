# Qwen Developers open-source zg, a local-first unified search layer for coding agents

Qwen Developers released zg (zvec-grep) under Apache 2.0, a local-first search layer unifying ripgrep, BM25 and vector search behind one interface. The aim is to let a coding agent move from a plain-language description to an exact line span without switching tools or leaving the local environment.
