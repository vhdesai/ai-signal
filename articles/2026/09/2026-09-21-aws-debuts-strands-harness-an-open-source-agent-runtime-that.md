# AWS Debuts Strands Harness — an Open-Source Agent Runtime That Runs on Any Cloud

AWS launched Strands Harness, a fully assembled open-source agent harness that runs locally or on AWS, Google Cloud, Azure, Modal, or Cloudflare, atop frontier models from Anthropic, OpenAI, Bedrock, Google, or local Ollama. It ships with read/write/edit, shell, and web-search tools, long-term memory across runs via session IDs, and context offloading to reduce token use. AWS claims 26% higher efficiency than other-framework agents, and that paired with Anthropic's Fable 5 it cost 77% less than Claude Code on comparable tasks while scoring higher on Terminal-Bench 2.1. It targets the gap between turnkey coding agents and fully custom loops — a meaningful portability signal for enterprises resisting single-cloud agent lock-in. NEW SECURITY
