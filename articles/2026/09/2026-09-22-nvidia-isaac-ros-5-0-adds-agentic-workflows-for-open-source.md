# NVIDIA Isaac ROS 5.0 adds agentic workflows for open-source robotics development

NVIDIA released Isaac ROS 5.0 at ROSCon, adding agentic workflows, ROS Lyrical and Ubuntu 24.04 support, and new reusable skills for robotics setup, manipulation, stereo fine-tuning, and pick-and-place. The release also adds an agent-ready FoundationPose inference library that NVIDIA says can track object pose up to 5.5x faster. The signal is that agentic development is moving into physical AI, where AI assistants help build and adapt robot perception and manipulation stacks. Infrastructure AI FACTORIES POWER & COOLING
