# OpenAI Pauses $200 ChatGPT Pro Sign-Ups as Astra Demand Outruns Compute

OpenAI halted new sign-ups and upgrades to its $200 ChatGPT Pro tier, citing system strain from demand for GPT-6 Astra. Existing subscribers are unaffected; the $100 Pro tier, Plus, Go, API and enterprise plans all remain open. The selection is the signal — OpenAI protected enterprise and API capacity and used consumer power users as the release valve. The practical lesson for technology buyers is that a model being announced and a model being available at production volume are two separate events; committed throughput comes from a contract, not a subscription, and production-critical workloads need a tested fallback model.
