# New NVIDIA open-sources Switchyard, a Rust proxy for cross-provider LLM traffic

NVIDIA released Switchyard, an Apache-2.0 Rust proxy and library that routes and translates LLM traffic between OpenAI (Chat/Responses) and Anthropic Messages API formats, including streaming. It ships four routing algorithms — passthrough, random, LLM-classifier and stage-router — plus Prometheus metrics that isolate routing overhead from model latency, letting tools built for one API target another. NVIDIA labels the project pre-alpha and explicitly not production-ready.
