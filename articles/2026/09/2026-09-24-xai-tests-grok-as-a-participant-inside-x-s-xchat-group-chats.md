# xAI Tests Grok as a Participant Inside X’s XChat Group Chats

Elon Musk amplified a post confirming Grok is being tested as a conversational participant inside XChat group chats, responding in-thread like another member. This extends xAI’s assistant from one-to-one chat into multi-party social messaging, where the agent sees the full group conversation rather than a single user’s prompts. No general-availability date was given. The pattern — an agent as a standing member of a shared channel — is the same one enterprise collaboration tools are converging on, and it carries the same data-scope questions.
