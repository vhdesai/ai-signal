# AWS ships SageMaker HyperPod Inference Gateway with GPU-aware routing

AWS launched SageMaker HyperPod Inference Gateway, a Kubernetes-native, GPU-aware routing add-on for EKS that inspects KV cache utilization, queue depth, LoRA adapter residency, and prefix cache to place LLM inference requests intelligently. AWS's own benchmarks report up to 82% lower first-token latency and 97–98% P95/P99 reductions on 8B–235B models versus round-robin. It deploys as a single EKS add-on with no sidecars or SDK changes, plugging a real production pain point in mid-scale inference deployments — and slotting neatly next to Microsoft's TauGrid open-source Kubernetes-native GPU stack shipped this week. - https://www.unite.ai/aws-launches-sagemaker-hyperpod-inference-gateway-for-gpu-aware-routing/
