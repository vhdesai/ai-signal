# Perplexity ships hybrid compute on Mac, gating cloud calls behind a local model

Perplexity introduced a hybrid compute mode that splits each Perplexity Computer task between frontier models in the cloud and a local model running on the user's Mac. Work executes on-device by default, with the system requesting permission before escalating any individual step to the cloud. The design targets the structural blocker for enterprise agent adoption: the most useful context — deal documents, privileged files, client records — is precisely the context that cannot leave the machine. https://www.unite.ai/perplexity-launches-hybrid-compute-on-mac-with-local-privacy-gate/ PRODUCT
