# Perplexity trains its computer-use agent on its own failures

A Perplexity Research post-training study trains a model inside Perplexity Computer on real user sessions — including failed ones — pairing rejection-sampling fine-tuning with hint-guided self-distillation. In a live A/B test, tool-call failures fell from 2.24% to 1.77%. The methodological contribution is treating failure traces, normally discarded, as supervision signal for agent post-training.
