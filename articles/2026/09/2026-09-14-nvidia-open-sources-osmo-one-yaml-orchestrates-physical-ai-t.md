# NVIDIA Open-Sources OSMO — One YAML Orchestrates Physical-AI Training, Simulation, and Robot Testing

NVIDIA open-sourced OSMO under Apache 2.0 — an orchestration layer that drives training, simulation, and on-robot hardware-in-the-loop testing from a single YAML spec across heterogeneous Kubernetes clusters. It spans data-center GPU training, workstation-class RTX sensor rendering, and edge robot testing, formalizing NVIDIA's "three computer problem" framing for robotics.
