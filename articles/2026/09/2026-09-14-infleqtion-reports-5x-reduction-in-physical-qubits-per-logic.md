# Infleqtion reports ~5x reduction in physical qubits per logical qubit using CUDA-Q Logical

Infleqtion (NYSE: INFQ) said it constructed and validated a high-rate quantum error-correction code requiring approximately six physical data qubits per logical qubit — roughly a fivefold improvement in code rate over the surface-code baseline used for comparison, and below its 10:1 architectural target. The work integrates the open-source qLDPC library, originally released with JPMorgan Chase researchers, with NVIDIA’s new CUDA-Q Logical compilation model.
