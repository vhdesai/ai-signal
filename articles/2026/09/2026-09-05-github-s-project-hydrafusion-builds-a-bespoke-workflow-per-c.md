# GitHub’s Project HydraFusion builds a bespoke workflow per coding task

HydraFusion, a research preview in Copilot CLI, treats workflow selection — not just model selection — as an optimization problem, assembling a per-request execution plan across multiple providers. It routes between Single, Cascade (draft plus quality gate plus escalation) and Critique (a tool-less cross-family reviewer) patterns, choosing the least complex workflow expected to clear a quality bar. Against a Claude Opus 5 baseline, GitHub reports +4.9 quality points at 67% lower estimated cost on TerminalBench 2.1, with marginal quality trade-offs at 36% and 65% lower cost on DeepSWE and CheckpointBench.
