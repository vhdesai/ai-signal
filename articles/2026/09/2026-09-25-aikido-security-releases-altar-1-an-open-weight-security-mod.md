# Aikido Security releases Altar-1, an open-weight security model pruned from GLM-5.3

MarkTechPost reported that Aikido Security released Altar-1, an open-weight security model pruned from GLM-5.3 to a 328 GB footprint. The release reflects growing demand for domain-specific security models that organizations can inspect, self-host, and adapt to internal code and vulnerability workflows. The key test will be whether open security models can deliver useful findings while reducing data exposure to external model providers. Products & Tools CONSUMER AGENTS GEMINI
