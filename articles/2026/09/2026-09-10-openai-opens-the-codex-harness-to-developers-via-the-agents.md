# OpenAI Opens the Codex Harness to Developers via the Agents API

The Agents API entered public beta, exposing the same managed harness and infrastructure that run Codex and ChatGPT for Work. A single call configures model, tools, MCP servers, sandbox environment, and subagent concurrency; OpenAI handles context compaction, session durability, and recovery for agents that run for hours or days. Developers choose an OpenAI-hosted sandbox, self-hosted execution, or partners including Cloudflare, Vercel, Oracle, and DigitalOcean, and pay only token and tool rates. Data residency is US-only and Zero Data Retention is not supported — a material constraint for regulated workloads.
