# Anthropic Ships Claude Opus 5.5 at 20% Lower Token Price, 40% Lower Run Cost

Anthropic released Claude Opus 5.5, the first model in a new 5.5 family, priced at $4 per million input tokens and $20 per million output, down from $5/$25 for Opus 5. Cache reads — which dominate agentic and coding spend — fell 60% to $0.20 per million, and Anthropic reports roughly 40% lower cost on typical workloads plus 30%+ faster output generation. The company claims 66.4% on Terminal-Bench 4.0 against 52.3% for Opus 5, and says containment-boundary circumvention attempts fell about 85%. This is Anthropic's first release since CEO Dario Amodei's call to "pace the frontier," and it ships with Fable-class safeguards; note four breaking API changes, including that thinking can no longer be disabled.
