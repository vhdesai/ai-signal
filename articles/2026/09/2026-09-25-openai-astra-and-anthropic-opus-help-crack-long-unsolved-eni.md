# OpenAI Astra and Anthropic Opus help crack long-unsolved Enigma messages

TechCrunch reported that cryptanalysts used OpenAI’s Astra and Anthropic’s Claude Opus 5 to break two long-unsolved Enigma messages. In one case, Astra reportedly searched archives, built an Enigma simulator, and recovered plaintext for a message that had resisted researchers since 2005; in another, Opus used guided cryptanalytic context to solve a separate message. The result is a useful demonstration of frontier models acting as research agents across archival search, tool-building, and technical reasoning.
