# Anthropic opens a formal submission portal for Claude plugins

Anthropic designated Plugins — bundles of MCP connectors, Agent Skills, or both — as the primary route for third-party extensions to Claude, and launched a developer portal for submission, automated validation, safety scanning, review tracking and post-launch usage analytics. The portal is open to developers on paid plans, accepting either a single remote MCP connector or a GitHub-hosted plugin bundle. Claude now supports the MCP 2.0 spec with MCP Apps (interactive UI in chat) and Enterprise Managed Auth for zero-touch OAuth. This follows the Claude Marketplace launch two days earlier and signals a deliberate move from ad-hoc integrations to a governed app-store model. CHINA PRICING
