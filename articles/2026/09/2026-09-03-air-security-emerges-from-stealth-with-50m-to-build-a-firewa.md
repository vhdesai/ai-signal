# AIR Security Emerges From Stealth With $50M to Build a Firewall for AI Agents

AIR Security launched with $50 million raised across two seed rounds led by Sequoia and Greenoaks, founded by former Israeli Unit 8200 specialists. Its platform discovers AI agents running inside an enterprise, inspects the plug-ins, skills and MCP servers they use, and blocks components that fail security checks — the company reports roughly 27% of publicly available add-ons it evaluates fail its criteria. Agent supply-chain governance is forming as a distinct security category alongside Noma, Zenity and Astrix. https://www.securityweek.com/ai-agent-firewall-startup-air-security-emerges-from-stealth-with-50-million/
