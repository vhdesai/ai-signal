# OpenAI's Agents API Puts the Codex Harness Behind a Single Call

OpenAI's Agents API is in public beta, exposing the managed harness that runs Codex — durable sessions, subagent orchestration, automatic context compaction, and failure recovery — through one API surface. Developers choose where execution happens: an OpenAI-hosted sandbox, their own infrastructure, or one of nine partner sandboxes including Cloudflare, Vercel, DigitalOcean, Modal and Oracle. There is no additional fee beyond standard model, tool and container rates. Two constraints are material for regulated enterprises: data residency is US-only during beta, and Zero Data Retention is not supported even when self-hosting the sandbox. Infrastructure CAPACITY
