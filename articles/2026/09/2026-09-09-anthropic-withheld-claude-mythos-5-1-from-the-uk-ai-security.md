# Anthropic withheld Claude Mythos 5.1 from the UK AI Security Institute

Anthropic did not give Britain's AI Security Institute pre-release access to Claude Mythos 5.1 — the reduced-safeguard variant released to vetted cybersecurity and life-sciences customers — the first time AISI has been excluded from an Anthropic frontier release. Access was limited to vetted US organizations, and UK national security officials have raised concerns that US export-control posture is now shaping private release decisions. A White House official told CNBC the administration does not formally approve private releases. If AISI loses default pre-release standing, multinational firms lose an independent evaluation reference point for procurement. *Source URL sits behind an FT subscription paywall; story retained per editorial policy.*
