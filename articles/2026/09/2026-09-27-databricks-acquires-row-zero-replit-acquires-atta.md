# Databricks acquires Row Zero; Replit acquires Atta

Databricks acquired Row Zero — a spreadsheet-native analytics tool designed for large data volumes — to plug natively into its Mosaic AI agent stack, positioning against Snowflake Cortex Agents and Microsoft Fabric Copilot-in-Excel. Separately, Replit picked up Atta, an AI business-analysis startup, to extend beyond code generation into requirements gathering and spec drafting. Both deals track the pivot from Copilot-style completion to end-to-end product-delivery agents.
