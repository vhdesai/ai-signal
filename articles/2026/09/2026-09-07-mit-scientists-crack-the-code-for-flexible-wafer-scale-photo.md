# MIT scientists crack the code for flexible wafer-scale photonics

MIT researchers reported a breakthrough in flexible wafer-scale photonics, a foundational technology that could enable higher-density optical interconnects for AI compute. As training and inference workloads scale, optical interconnects are increasingly seen as the path around electrical-bandwidth limits in accelerator clusters. If the flexibility gains hold at production scale, they would help address the wafer-level integration bottlenecks that have limited photonic co-packaging so far.
