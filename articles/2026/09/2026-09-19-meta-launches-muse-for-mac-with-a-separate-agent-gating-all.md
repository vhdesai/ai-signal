# Meta Launches Muse for Mac With a Separate Agent Gating All Outbound Traffic

Muse for Mac is the first Muse build that acts directly on a user’s machine across Files, Mail, Messages, Calendar and Notes in their native apps, running on Muse Spark with cloud execution inside a “Muse Secure VM.” The containment design is the notable part: a separate Sentinel agent must approve anything Muse sends to the internet, computer access is opt-in, and destructive or outbound actions require explicit approval. Free up to 100M tokens per week, US only. Disclosed limitation worth flagging for any enterprise evaluation — the Secure VM isolates users from each other but does not prevent Meta from accessing data to operate the service; a user-held-key Confidential VM is only promised later in 2026.
