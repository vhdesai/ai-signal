# Arm doubles its semi-custom server ceiling with Neoverse CSS N4 for agentic workloads

Arm announced Neoverse CSS N4, its most configurable compute subsystem to date, supporting up to 128 cores per die with LPDDR6 memory and PCIe Gen 7 — claiming up to 2x performance, 1.25x performance-per-watt, and 1.75x memory bandwidth versus CSS N3. Arm positions it explicitly for the CPU-side load created by agentic workloads: tool calls, database interaction, and accelerator orchestration. Arm also cited AGI CPU adoption with OpenAI, Meta, Cloudflare, Oracle, SAP, Lenovo, and Supermicro, and agent sandboxes running on Google Axion, Microsoft Cobalt 200, and NVIDIA Vera. The competitive point is that agentic inference is pulling custom CPU demand, not only GPU demand.
