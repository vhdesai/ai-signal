# Exa launches Agent Ultra, a subagent-swarm deep-research API

Agent Ultra is the highest-effort tier of Exa's Agent API, coordinating subagents across thousands of sources for exhaustive list-building and entity enrichment. Exa reports it beats Anthropic's Opus 5.5, OpenAI's GPT-6 Astra and Perplexity Agent on four benchmarks, including 81.4% soft recall on WANDR. These are vendor-reported numbers with no independent replication yet and should be treated as self-reported.
