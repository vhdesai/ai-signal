# Microsoft pushes AI agents that write native WinUI 3 Windows 11 apps in under 30 minutes

Microsoft is combining AI agents with quick-start guides so developers can stand up native WinUI 3 apps for Windows 11 in under 30 minutes, aiming to displace heavy web-wrapper applications with lighter native ones. The effort ties into broader internal messaging around Aspire and “Project Zenith” that agentic AI is reshaping how software gets built. It signals Microsoft steering its Windows developer ecosystem toward AI-assisted native app creation.
