# Google Ships Gemini 3.8 Flash and a Restricted Gemini 3.8 Flash Cyber Variant

Google DeepMind released Gemini 3.8 Flash with improvements to software engineering, long-running agent tasks and multi-step reasoning while holding Flash-tier pricing. The more consequential release is Gemini 3.8 Flash Cyber, which adds stronger vulnerability detection and automated patching but is available only through a new Fairwind Program for vetted governments, critical-infrastructure operators and software maintainers. Google also cites strengthened prompt-injection defenses and cyber/CBRN safeguards. Gating offensive-grade security capability behind an access tier is a template other labs are likely to copy. https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/
