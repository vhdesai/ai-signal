# Microsoft Rebuilds Copilot Around Home, Code, and Autopilot — Shifts New Surfaces to Usage-Based Pricing

Microsoft introduced a restructured Copilot app combining Chat and Cowork under a new Home surface, a Code tab built on the same technology as GitHub Copilot, and Autopilot — a persistent agent that operates across Teams and Outlook. Home and Code begin rolling out through the Frontier program in the coming weeks; Autopilot enters private preview at the end of this month. The commercial change is as significant as the product one: Cowork, Code, and Autopilot will be billed on usage rather than the $30 per-seat subscription model. Fewer than 7% of Microsoft’s 450M+ commercial Office seats currently carry an AI license — the pricing shift is a bet that broader consumption offsets per-seat economics as the enterprise ROI conversation intensifies.
