# Alibaba Qwen releases Qwen-Image-2.1, a 7B model for image generation and editing

Alibaba's Qwen team released Qwen-Image-2.1, a unified 7B diffusion-transformer model for text-to-image generation, multi-reference editing, local edits, and native transparent RGBA output. The model replaces the prior 20B Qwen-Image plus separate edit checkpoint with one smaller checkpoint, while supporting Diffusers, ComfyUI, vLLM-Omni, SGLang, and multiple chip platforms. The release points to a broader efficiency trend: capable media models are being compressed and packaged for lower-cost deployment rather than only peak closed-model quality. AGENT MODEL LOW COST
