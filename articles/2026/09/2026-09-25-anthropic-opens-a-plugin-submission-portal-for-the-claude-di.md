# Anthropic Opens a Plugin Submission Portal for the Claude Directory; Ships MCP 2.0 and Enterprise Managed Auth

Anthropic made plugins the primary path for third-party extensions to Claude, packaging MCP connectors and Agent Skills together, and opened a submission portal to developers on paid plans with automated validation, safety scanning, and review tracking. Published plugins receive usage analytics covering installs by product surface and version, listing views, and inbound search terms. The release adds support for the MCP 2.0 specification along with MCP Apps for in-chat interactive UI and Enterprise Managed Auth for zero-touch OAuth. Existing skills and connectors in the directory require no changes — a low-friction path for enterprise plugin fleets that keeps Anthropic’s developer surface competitive with OpenAI’s and Microsoft’s Copilot Code moves.
