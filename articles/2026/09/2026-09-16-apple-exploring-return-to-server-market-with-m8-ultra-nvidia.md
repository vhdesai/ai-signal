# Apple exploring return to server market with M8 Ultra + Nvidia NVLink Fusion

The Information reports Apple has been working on plans for an enterprise server using its own M-series chips that could incorporate Nvidia networking equipment, targeting AI developers, businesses, and governments. Two configurations are in scope — two or four M8 Ultra chips clustered — connected via Nvidia NVLink Fusion, with a 2029 sales target aimed at AI inference. It would be a striking strategic reversal for a company that exited enterprise servers with the last Xserve in 2011 and has publicly minimized Nvidia dependencies, and it puts Apple silicon into the same procurement conversation as Nvidia HGX and AMD Instinct systems.
