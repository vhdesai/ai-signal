# Microsoft Unveils "Project Zenith" for Local Frontier-Scale AI Development

Microsoft named its developer-optimized Windows configuration Project Zenith and tied it to a new class of PCs with at least 64GB of unified memory and 250GB/s of memory bandwidth, with first devices on AMD Ryzen AI Halo silicon shown at IFA. The configuration ships a curated toolchain intended to run 30-billion-parameter-plus models locally without metered cloud tokens. For teams handling sensitive code or unable to absorb token bills, this establishes an on-device inference tier between phones and the data center.
