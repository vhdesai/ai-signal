# Cognition releases SWE-2, a Kimi K3 post-trained coding model at 64% lower cost than Fable 5.1

Cognition released SWE-2, a coding model built by post-training Moonshot's Kimi K3 that reportedly matches Anthropic's Fable 5.1 on FrontierCode benchmarks at 64% lower cost. It's the second high-profile "post-train a Chinese open-weight model to challenge a closed-source frontier lab" release this week alongside Abacus.AI's Smaug agent-cost cuts. For enterprise buyers, the pattern suggests customized open models are becoming a credible economic alternative for coding workflows.
