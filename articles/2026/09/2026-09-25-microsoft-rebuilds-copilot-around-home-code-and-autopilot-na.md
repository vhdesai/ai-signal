# Microsoft Rebuilds Copilot Around Home, Code, and Autopilot — Nadella Calls It "a New OS for Work"

Microsoft announced its largest Copilot revision to date, consolidating Chat and Cowork into a Home surface, adding "Office in Copilot" for editable Word/Excel/PowerPoint artifacts, and introducing Code for natural-language app and dashboard building inside a tenant-hosted sandbox. Autopilot — previously Scout — is a persistent agent with its own identity, memory, and workspace that can be tagged in Teams and Outlook. Microsoft also previewed a proactive "Today" surface and new FinOps for AI cost controls in Agent 365. Home and Code roll out through the Frontier program in the coming weeks; Autopilot expands its private preview at the end of September. The commercial subtext matters: Cowork, Code, and Autopilot move to usage-based pricing, a bet that broader consumption will offset per-seat economics.
