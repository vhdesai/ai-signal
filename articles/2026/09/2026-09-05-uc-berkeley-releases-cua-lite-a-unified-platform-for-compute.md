# UC Berkeley Releases CUA-Lite, a Unified Platform for Computer-Use Agents

A UC Berkeley-led team released CUA-Lite, which consolidates the four ingredients required to train and benchmark computer-use agents — agents, environments, traces, and an evaluation and RL framework — behind a single action space and data schema. The stated problem is infrastructural rather than model-centric: these components ship today in mutually incompatible formats, making cross-lab comparison unreliable. Standardized evaluation is a prerequisite for enterprises to make defensible build-versus-buy decisions on desktop-automation agents.
