# Nvidia ships an open agent-safety stack: OpenShell runtime plus in-silicon Sentry watchdog

Nvidia launched the Open Agent Safety Platform, pairing OpenShell — an Apache-2.0 secure runtime enforcing kernel-level isolation and policy on Vera CPUs — with Sentry, an out-of-band watchdog on BlueField-4 DPUs that can quarantine a straying agent in milliseconds. Partners span Anthropic, Microsoft, Cisco, Oracle, CrowdStrike, Palantir, JPMorganChase, Dell, HPE, Arm and Intel. Nvidia's Justin Boitano said the design could have prevented July's Hugging Face breach, where "over 17,000 agents" attacked infrastructure for days; Huang described it to CNBC as "a browser for agents."
