# Anthropic adds counterfactual plugin evals — six grader types and a CI gate for agent skills

Anthropic shipped an evaluation workflow that runs an agent plugin against realistic prompts with and without the plugin loaded and reports the delta — if a case scores identically in both arms, the plugin is not why it passed. Four of six grader types are free transcript- or file-based checks; two call a judge model. Threshold and max-cost flags make it usable as a continuous-integration gate. For enterprises accumulating internal agent skills, this is the first defensible instrument to prove — or disprove — that each one earns its maintenance cost.
