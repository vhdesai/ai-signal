# OpenAI ships GPT-Live-1 for more natural voice via the API

OpenAI released GPT-Live-1 for developers to build more natural voice experiences via the OpenAI API. It complements OpenAI's earlier GPT-Realtime-Whisper and lands into an increasingly competitive market where Meta's Muse Voice Transcribe, xAI's Grok Voice Transcribe 2.0, ElevenLabs Scribe v2, and Google's Gemini Live have all shipped within the last two weeks. Voice-agent economics — TTS/STT latency and $/hour pricing — are becoming a formal battleground.
