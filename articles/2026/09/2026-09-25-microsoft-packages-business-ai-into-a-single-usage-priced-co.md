# Microsoft packages business AI into a single usage-priced Copilot app to chase Anthropic

Microsoft introduced an updated Copilot app for corporate users that combines Home (productivity), Code (GitHub Copilot-derived programming for non-technical users) and Autopilot (custom agents that act in Teams and Outlook). Rather than the $30-per-user-per-month seat model, Microsoft says customers will pay for Cowork, Code and Autopilot on a usage basis. CNBC reports fewer than 7% of Microsoft’s 450 million-plus commercial Office 365 seats currently carry a Copilot license. Home and Code reach Frontier program customers in the coming weeks; Autopilot enters private preview by the end of September. CHINA FINANCE
