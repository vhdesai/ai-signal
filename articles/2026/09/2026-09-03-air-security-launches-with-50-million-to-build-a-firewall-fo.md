# AIR Security launches with $50 million to build a firewall for AI agents

AIR Security emerged from stealth with $50 million across two seed rounds led by Sequoia and Greenoaks. Its platform discovers AI agents, inspects plug-ins and MCP servers, and blocks components that fail security checks. The funding reflects a fast-forming security category around agent inventory, tool-chain governance, and runtime control.
