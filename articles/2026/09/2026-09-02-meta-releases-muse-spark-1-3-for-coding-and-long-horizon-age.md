# Meta releases Muse Spark 1.3 for coding and long-horizon agentic workflows

Meta released Muse Spark 1.3 in Muse Code and the Meta Model API, emphasizing stronger performance on coding, agentic tasks, long-form instruction following, and multitasking in messy contexts. Meta says internal comparisons show roughly 20% fewer tool calls and 25% fewer tokens versus Muse Spark 1.2, which matters because agent cost is driven by turns, retries, and tool use, not just posted token prices. The release keeps Meta in the developer-agent race against OpenAI, Anthropic, and Google while it works toward larger models and eventual open weights. Products & Tools COMMERCEENTERPRISE
