# Perplexity ships hybrid compute that keeps confidential files on the local Mac

Perplexity’s Computer agent can now split a single task between frontier cloud models and an open-weight model running locally on Apple silicon, handing off steps that touch sensitive files without restarting the workflow or losing context. The design targets the primary enterprise objection to autonomous agents: data egress. If the pattern holds, privacy-aware model routing becomes a required feature of agent platforms rather than a differentiator. venturebeat.com/orchestration/your-files-stay-put-perplexitys-hybrid-ai-keeps-confidential-data-off-the-cloud
