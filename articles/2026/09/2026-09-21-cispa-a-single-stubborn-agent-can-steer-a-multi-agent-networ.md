# CISPA: A Single "Stubborn" Agent Can Steer a Multi-Agent Network's Decisions

CISPA researcher Samira Abedini and colleagues adapted the Friedkin-Johnsen opinion-dynamics model from social science to multi-agent LLM networks, and found it predicted when a manipulative agent succeeds. A single agent with high "stubbornness" can steer a network's collective decision if it also holds sufficient influence, with star-network hubs especially dangerous and larger networks requiring more attacker influence. A dynamic trust mechanism — periodic known-answer probes that downweight repeatedly wrong agents — measurably reduced manipulative influence. Preprint: "Don't Trust Stubborn Neighbors: A Security Framework for Agentic Networks" (arXiv, DOI 10.48550/arxiv.2603.15809).
