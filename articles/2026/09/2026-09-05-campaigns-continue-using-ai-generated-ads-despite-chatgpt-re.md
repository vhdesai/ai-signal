# Campaigns continue using AI-generated ads despite ChatGPT restrictions

The Washington Post reported that political campaigns are using AI-generated advertising despite ChatGPT restrictions on campaign ad creation. The item highlights the enforcement challenge for AI usage policies when outputs can be generated, modified, and distributed across many channels. For executives, the broader lesson is that policy language is not enough; high-risk AI use cases need auditability, provenance, and clear enforcement mechanisms.
