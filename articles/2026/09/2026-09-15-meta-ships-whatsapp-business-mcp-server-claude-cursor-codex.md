# Meta ships WhatsApp Business MCP server — Claude, Cursor, Codex, and ChatGPT can now automate account setup

Meta launched a WhatsApp Business MCP server that lets AI coding agents — including Claude, Cursor, Codex, and ChatGPT — handle account setup, messaging-template configuration, testing, and troubleshooting for the WhatsApp Business API. It is one of the most consequential MCP endpoints published by a major platform vendor to date: for the millions of SMBs on WhatsApp Business, agentic setup is now a first-class option. For enterprise developer-tools executives, MCP is now an addressable go-to-market surface, not just a technical spec. - https://techcrunch.com/2026/09/15/meta-now-lets-ai-agents-handle-the-boring-parts-of-whatsapp-business-setup/
