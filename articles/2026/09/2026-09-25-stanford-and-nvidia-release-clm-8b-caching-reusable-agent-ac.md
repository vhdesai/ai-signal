# Stanford and NVIDIA release CLM-8B, caching reusable agent actions for faster execution

VentureBeat reported that Stanford and NVIDIA released an open CLM-8B model that caches reusable agent actions and runs up to 9x faster than Jev in tests. The model targets a practical agent-performance bottleneck: repeated planning and action selection can become expensive when agents operate over long workflows. If the reported gains generalize, action caching could become a standard optimization layer for enterprise agents. VISION-LANGUAGE DECODING SPEED
