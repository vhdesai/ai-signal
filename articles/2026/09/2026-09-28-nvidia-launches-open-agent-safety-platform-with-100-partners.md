# Nvidia Launches Open Agent Safety Platform with 100+ Partners

Nvidia released an open software platform and reference design to contain AI agents, built with Microsoft, Oracle, Cisco, CoreWeave, Dell, HPE, Lenovo, Arm and Intel among others. It pairs OpenShell — a CPU-level containment runtime Jensen Huang described as “a browser for agents” — with Sentry, which monitors agent behaviour from network chips, out of band. Nvidia’s technical report argues drift cannot be trained away without capability loss, so containment must sit below the agent; the company says the design could have prevented July’s Hugging Face breakout, in which over 17,000 agents attacked its infrastructure. cnbc.com — Nvidia releases platform to stop AI agents misbehaving <https://nam06.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.cnbc.com%2F2026%2F09%2F28%2Fnvidia-releases.html&data=05%7C02%7Cvdesai%40microsoft.com%7Cbdff49bda26b44ea765d08df1e29f738%7C72f988bf86f141af91ab2d7cd011db47%7C1%7C0%7C639262837765020316%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=LpT0MeaFqmUj2uDqgFkbHiQ3ZIfY8BdmmsnF%2F5%2BpX%2FM%3D&reserved=0>
