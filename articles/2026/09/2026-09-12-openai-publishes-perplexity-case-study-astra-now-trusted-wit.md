# OpenAI publishes Perplexity case study — Astra now trusted with end-to-end production systems

OpenAI published a Perplexity case study describing how Perplexity now uses GPT-6 Astra to write internal communications, change software, and monitor production systems, checking in much less frequently than with earlier models. The framing — reduced human check-in cadence for production-touching agents — is a meaningful shift in how OpenAI is willing to publicly describe agent oversight. For any enterprise thinking about agent supervision policy, it is a useful reference point on what "acceptable" oversight cadence now looks like at a well-run AI-native company.
