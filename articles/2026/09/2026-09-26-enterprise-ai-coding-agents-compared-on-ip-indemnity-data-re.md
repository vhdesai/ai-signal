# Enterprise AI coding agents compared on IP indemnity, data residency and 500-seat cost

A contract-level comparison of GitHub Copilot, AWS Kiro, Cursor and Cognition (Devin/Windsurf), with every term verified against vendor pages as of September 26, 2026. GitHub offers uncapped IP indemnity for unmodified outputs and dropped its Duplicate Detection prerequisite on April 3, 2026; Cursor’s August 2026 MSA names “Suggestions” explicitly and carves indemnity out of its fee cap. Cognition is the outlier: its MSA defines Customer Data to include Outputs, excludes it from indemnity, and caps liability at 2× trailing twelve-month fees. Directly relevant to any enterprise standardizing on a coding agent under procurement review.
