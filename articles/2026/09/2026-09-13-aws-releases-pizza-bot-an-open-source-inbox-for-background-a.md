# AWS Releases Pizza Bot, an Open-Source Inbox for Background AI Agents

AWS introduced Pizza Bot, a self-hosted application for AI tasks that continue running while users work elsewhere; earlier internal versions served more than 2,000 people inside Amazon. It is built on DeepAgents and LangGraph with a Hono API server, with LangGraph checkpoints retaining thread state and approval pauses. Apache 2.0 licensed, with macOS, Windows and Linux desktop builds. Skill authors gate specific tools behind human approval via interruptOn and allowedDecisions — a concrete, inspectable implementation of human-in-the-loop control for long-running agents.
