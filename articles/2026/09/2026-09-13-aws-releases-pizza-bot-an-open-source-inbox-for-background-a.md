# AWS Releases Pizza Bot, an Open-Source Inbox for Background AI Agents

AWS released Pizza Bot, a self-hosted application that gives long-running background agents an inbox-style interface so tasks continue while users work elsewhere; earlier internal builds reportedly served more than 2,000 people inside Amazon. It is built on DeepAgents and LangGraph, with LangGraph checkpoints retaining thread state and approval pauses across sessions. Skill authors gate specific tools behind human approval using interruptOn and allowedDecisions — a concrete, inspectable implementation of human-in-the-loop control for agents that act over hours rather than seconds. Relevant to anyone drafting agent-governance standards, since it makes the approval boundary a configuration artifact rather than a policy document.
