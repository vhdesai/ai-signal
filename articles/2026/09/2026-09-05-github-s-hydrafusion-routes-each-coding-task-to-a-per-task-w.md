# GitHub's HydraFusion routes each coding task to a per-task workflow in Copilot CLI

GitHub introduced Project HydraFusion, a research preview in Copilot CLI that treats workflow selection as an optimization problem, routing between single-model, cascade-with-quality-gate, and cross-family critique execution patterns per coding task. GitHub's own benchmark data shows cost reductions in every test but quality parity in only one of three, so savings should be validated per workload rather than assumed. The economics are attractive for high-volume coding workloads; the quality variance argues for scoped pilots rather than default-on rollout.
