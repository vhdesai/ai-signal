# Contrastive-LM releases CLM-8B, scoring agent actions up to 9× faster than generative baselines

CLM-8B is an open "System One" model that scores candidate agent actions against a state rather than generating text, adding two small projection heads to a frozen Qwen3-8B encoder trained with a contrastive InfoNCE objective. Zero-shot, it runs up to 9× faster than TypeSafe AI's Jev. The broader pattern — cheap discriminative models gating expensive generative calls — is quickly becoming the dominant cost lever in production agent architectures.
