# Unity ships official plugins for Claude Code and OpenAI Codex to keep AI agents on current APIs

Unity released first-party plugins for Anthropic's Claude Code and OpenAI's Codex so AI coding agents inside game-dev workflows use up-to-date Unity APIs rather than the outdated tutorials LLM pretraining tends to lean on. It also standardizes agent-triggered scene manipulation, IAP configuration, and asset workflows. For any large-vendor platform team, this is a concrete template: publish a first-party MCP-style plugin so agents pull current authoritative docs instead of drifting on stale training data. PRODUCT
