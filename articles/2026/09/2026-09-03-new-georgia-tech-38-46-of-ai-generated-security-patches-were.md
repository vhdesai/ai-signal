# New Georgia Tech: 38–46% of AI-generated security patches were semantically incorrect

Georgia Tech researchers shared lessons from DARPA’s AI Cyber Challenge at USENIX Security 2026, reporting that between 38% and 46% of AI-generated patches were semantically incorrect despite passing surface-level checks. The finding directly quantifies the verification gap in autonomous vulnerability remediation. It is a strong argument for keeping human review and formal validation in the loop for any agentic security remediation pipeline.
