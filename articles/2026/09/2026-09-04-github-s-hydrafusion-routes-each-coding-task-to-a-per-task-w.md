# GitHub's HydraFusion routes each coding task to a per-task workflow

GitHub introduced HydraFusion, a research preview in Copilot CLI that treats workflow selection as an optimization problem, routing between single-model, cascade-with-quality-gate, and cross-family critique execution patterns. GitHub's own benchmarks show cost reductions across every test, but quality parity in only one of three. The economics are attractive for high-volume coding workloads; the quality variance argues for scoped pilots rather than default-on rollout. P INFRA ENGINEERING
