# Meta launches Muse, a consumer personal agent with payment and email authority

Meta introduced Muse in the US on web, iOS, Android, and WhatsApp for users 18+, powered by its Muse Spark model. The agent connects to email, calendars, payments, health, shopping, and smart-home services, runs long tasks in the background, and checks out via Link by Stripe using single-use card numbers. Each user gets a dedicated "Muse Secure VM" with a separate Sentinel process gating all network egress, and Meta says Muse data does not feed ad systems. Pricing tiers are free, $20/month, and $100/month. This is the first mass-market agent asking consumers to delegate money movement and mailbox access — the trust threshold it sets will shape enterprise agent expectations.
