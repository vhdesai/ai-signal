# TypeSafe AI releases Jev, a model that returns typed, calibrated decisions instead of text

TypeSafe AI, founded by a former ChatGPT engineer, launched Jev — transformer-based but not an LLM. It takes a state plus typed questions and returns choices, scores and boolean judgments with calibrated probabilities that application code can branch on. TypeSafe quotes input pricing at $0.042 per 1M tokens and, in its own recorded demo, 0.114s versus 8.566s for GPT-5.6 Terra. Those benchmark figures are vendor-produced against workflows TypeSafe wrote, and the model is hosted-API-only behind a waitlist with no published architecture or weights — treat the 194x/445x claims as unverified marketing until third parties reproduce them.
