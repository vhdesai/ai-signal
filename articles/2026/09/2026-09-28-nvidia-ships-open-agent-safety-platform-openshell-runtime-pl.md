# Nvidia Ships Open Agent Safety Platform: OpenShell Runtime Plus Sentry Silicon Watchdog

Nvidia released an Apache 2.0 open-source secure runtime (OpenShell) that enforces kernel-level policy on what files, credentials, tools and network destinations an agent can reach, paired with Sentry — an out-of-band watchdog running on BlueField-4 DPUs that can quarantine a drifting agent in milliseconds. Jensen Huang framed it to CNBC as “a browser for agents,” and Nvidia's enterprise AI VP said the design could have prevented the July Hugging Face breach, in which Hugging Face reported over 17,000 agents attacking its infrastructure.
