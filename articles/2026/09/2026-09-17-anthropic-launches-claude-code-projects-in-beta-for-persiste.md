# Anthropic launches Claude Code Projects in beta for persistent cloud coding sessions

Anthropic rebuilt Projects in Claude Code: instead of a folder plus one chat, a project is now a single ongoing conversation in which Claude acts as coordinator and decides which work spins out into a separate thread. Each thread is a full cloud session that keeps running after the laptop closes. Available in beta on Pro and Max tiers, this extends the same consolidation direction as the September 16 merge of Claude chat and Cowork. It raises productivity upside for software teams but also increases the need for session isolation, permission scoping, auditability, and controls over what agents can change while unattended. - https://www.marktechpost.com/2026/09/17/anthropic-launches-claude-code-projects-in-beta-parallel-cloud-sessions-that-keep-running-after-you-close-your-laptop/
