# Nokia open-sources AnyJev, a training-free layer that turns any open LLM into a calibrated decision model

Nokia's applied research team released a Python layer that converts any open LLM into a calibrated decision model choosing from a fixed answer set instead of generating free text. The team reports a 6.8× increase in automatable traffic through confidence-gated routing, with no fine-tuning and a standard PyPI install. For production stacks this is an inexpensive path to routing high-confidence decisions away from costly generative calls.
