# Trending Alibaba's Qwen-3.8-Max-0902 debuts at #1 on Code Arena WebDev

Alibaba shipped an updated Qwen-3.8-Max (build 0902) that took the top spot on the Code Arena WebDev leaderboard at 1,691 points, narrowly ahead of Claude Opus 5. The 2.4-trillion-parameter model is priced at $2/$6 per million input/output tokens, an order of magnitude below Opus 5's input pricing. Observers noted it reportedly matches Anthropic's Claude Fable 5 roughly two months after that model launched, fueling distillation speculation.
