# Stripping safety guardrails from open-weight models is now a commercial service

Startup Abliteration.ai sells hosted API access to open-weight models with trained safety refusals removed, currently built on Z.ai’s GLM‑5.3, and markets the result for offensive-cybersecurity and red-team work. Turning “abliteration” into a productized service materially changes the open-weight supply-chain risk picture. Original reporting TechCrunch Sept 3; this analysis is in-window.
