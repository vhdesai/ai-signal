# Supersonic Labs releases Julia 1, a 144.3M-parameter open decision model that runs on CPU

MarkTechPost reported that Supersonic Labs released Julia 1, a 144.3M-parameter open decision model designed to run on CPU. The release fits the broader trend toward smaller structured-decision models that can classify, route, score, and trigger software actions without invoking a large general-purpose model. If performance is competitive, this category could materially reduce latency and operating cost for high-volume enterprise decision points. SPEECH AI INDIC LANGUAGES
