# Microsoft rebuilds Copilot around a new "Autopilot" agent, switches to usage-based billing

Microsoft split Copilot into three surfaces — Home, Code, and a new Autopilot agent — with Autopilot built on top of OpenClaw and running continuously in the cloud to monitor Teams channels and complete tasks autonomously. Autopilot and Code move from flat-rate to usage-based billing, materially unwinding the AI-subsidy model that has defined Copilot's first two years. The pricing shift is the more consequential change for CIOs: it turns Copilot procurement into an ongoing consumption forecast rather than a per-seat license negotiation.
