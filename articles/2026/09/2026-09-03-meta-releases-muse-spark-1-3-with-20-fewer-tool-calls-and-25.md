# Meta Releases Muse Spark 1.3 With ~20% Fewer Tool Calls and ~25% Fewer Tokens

Meta rolled out Muse Spark 1.3 across Muse Code and its Model API, an agentic coding model with a 1M-token context window that reports roughly 20% fewer tool calls and 25% fewer tokens than version 1.2. The positioning is explicitly economic: a lower-cost option for high-volume agent workloads rather than routing every task to a frontier model.
