# Infleqtion Reports 5x Better Code Rate in Quantum Error Correction

Using an early-access build of CUDA-Q Logical with its open-source qLDPC library, Infleqtion constructed and validated a high-rate error-correction code requiring roughly six physical data qubits per logical qubit — about a fivefold improvement in code rate over the surface-code baseline used for comparison. The sub-10:1 ratio is the company's stated architectural target for near-term neutral-atom systems. Physical-qubit overhead remains the central cost obstacle between current hardware and commercially useful quantum computing. Infleqtion says portions of the integration were developed with AI assistance.
