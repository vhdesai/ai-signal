# UC Berkeley researchers release CUA-Lite, an open platform for computer-use agents

A UC Berkeley–led team released CUA-Lite, which unifies sandboxes, data, evaluation, and reinforcement learning for computer-use agents behind a single action space and data schema. The argument is infrastructural rather than model-centric: the four components needed to train and benchmark a computer-use agent currently ship in incompatible formats. Standardized traces and evaluation are a precondition for enterprises comparing computer-use agents on anything other than vendor demos.
