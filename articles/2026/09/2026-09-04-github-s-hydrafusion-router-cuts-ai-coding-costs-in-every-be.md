# GitHub's HydraFusion router cuts AI coding costs in every benchmark — but matches quality in only one

GitHub's new HydraFusion model-routing system reduced AI coding costs across every benchmark tested. However, GitHub's own data showed output quality holding up in only one of three evaluations, tempering the cost-savings pitch. The result is a useful caution for enterprises weighing router-based cost optimization against quality regressions.
