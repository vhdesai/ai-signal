# Microsoft announces Project Zenith — a ready-to-code on-device AI setup for 64GB Windows 11 PCs

Microsoft unveiled Project Zenith, a preconfigured Windows 11 developer experience tied to a new class of PCs with 64GB+ unified memory and 250GB/s bandwidth, with first devices on AMD Ryzen AI Halo silicon shown at IFA. It ships a curated toolchain so developers can run models above 30B parameters locally without metered cloud tokens. The move is a clear bid to make the local device a first-class AI development target.
