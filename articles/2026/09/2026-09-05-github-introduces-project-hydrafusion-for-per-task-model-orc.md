# GitHub Introduces Project HydraFusion for Per-Task Model Orchestration in Copilot CLI

GitHub released Project HydraFusion, a research preview that treats model selection as a runtime optimization rather than a fixed setting, building a workflow per coding task. It routes between three execution patterns — Single, Cascade with a quality gate, and Critique with a read-only cross-family reviewer. Independent coverage of GitHub's own benchmark data notes that HydraFusion reduced cost in every test but matched baseline quality in only one of three, so cost savings should be validated per workload before broad rollout.
