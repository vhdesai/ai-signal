# Microsoft patches CVSS 10.0 Azure AI Foundry flaw

Microsoft patched 18 vulnerabilities in AI and cloud products this Patch Tuesday, including a CVSS 10.0 Azure AI Foundry flaw enabling unauthorized privilege escalation. Coming the same week as Microsoft's Humanist AI Code of Conduct rollout and the OpenAI/Anthropic Claude-Opus breach, the AI-platform vulnerability surface is now a first-order enterprise security concern separate from and additional to model-safety risk. CIO Dive's Sept. 18 issue notes AI is now the leading driver of new cybersecurity spending per IANS/Artico.
