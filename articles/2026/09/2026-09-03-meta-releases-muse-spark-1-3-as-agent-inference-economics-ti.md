# Meta Releases Muse Spark 1.3 as Agent Inference Economics Tighten

Meta rolled out Muse Spark 1.3 across Muse Code and its Model API, targeting agentic workflows, tool use and long-running multi-step tasks on an unusually compressed release cadence. Meta is positioning the Spark family as a lower-cost option for high-volume workloads rather than routing every task through top-tier frontier models.
