# Microsoft’s Project Zenith turns high-memory Windows PCs into local AI development machines

Microsoft introduced Project Zenith, a developer-optimized Windows configuration tied to PCs with at least 64GB of unified memory and 250GB/s of memory bandwidth, with first devices on AMD Ryzen AI Halo silicon. The setup ships a curated toolchain — Windows Terminal, VS Code, GitHub Copilot, PowerToys — and targets running 30B-parameter-class models locally without metered cloud tokens. For teams with sensitive code or unpredictable token bills, this creates an inference tier between the laptop and the data center.
