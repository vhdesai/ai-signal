# Nvidia's SoL-Pi cuts coding-agent token usage by up to 49% via harness optimization

Nvidia's SoL-Pi paper — still circulating in enterprise architecture circles — establishes that optimizing the "harness" (the control layer between an LLM and its tools/environment) can cut coding-agent token usage by up to 49% with near-flat task performance. The team ran a research agent through 152 harness variants across 3,000+ trials to converge. For enterprise Codex, Copilot, and Claude Code deployments, harness engineering has just become an explicit unit-economics lever. Academic Research RESEARCH
