# OpenClaw 2026.9.5 Adds Atomic Updates and Plugin Hot Reload Across 4,179 Merged PRs

The MIT-licensed self-hosted personal agent shipped 2026.9.5, bundling 4,179 pull requests and 64 direct commits from 502 contributing accounts. The headline feature, Atomic Updates, validates the next version against a private copy of the user’s setup while the current Gateway keeps running, rolling back on failure so a working agent always survives to diagnose the break. Also included: plugin hot reload, read-only Session Share, GPT Live in Meet/Teams/Zoom, shared browser pages and conversation cold storage. Stated limits are refreshingly explicit — rollback cannot undo database migrations, and this release changes the conversation database even with archiving off.
