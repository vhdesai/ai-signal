# Microsoft rolls out AI-native WinUI 3 app generation for Windows 11

Microsoft is enabling AI-driven creation of native WinUI 3 desktop applications for Windows 11 in under 30 minutes, part of the "Project Zenith" developer initiative. The move pushes Copilot-style code generation beyond web-app scaffolding into native desktop deliverables, potentially reducing the barrier for Windows developers building line-of-business tooling. It also positions Microsoft to counter cross-platform browser-first AI generators by tying AI code generation to native Windows APIs.
