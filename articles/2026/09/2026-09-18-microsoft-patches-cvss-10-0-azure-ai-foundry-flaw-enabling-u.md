# Microsoft patches CVSS 10.0 Azure AI Foundry flaw enabling unauthorized privilege escalation

Microsoft patched 18 vulnerabilities in AI and cloud products this Patch Tuesday, including a CVSS 10.0 flaw in Azure AI Foundry that enabled unauthorized privilege escalation. Coming the same week as Microsoft's Humanist AI Code of Conduct rollout and the Claude Opus 5 → OpenAI breach, the AI-platform vulnerability surface is now a first-order enterprise security concern — separate from and additional to model-safety risk. Treat it as another vector alongside model misalignment and agentic tool-permission drift. - https://thehackernews.com/2026/09/microsoft-patches-cvss-10-azure-ai.html
