# OpenAI to build a misalignment incident reporting framework

OpenAI said it is developing a framework governing when and how it discloses misalignment incidents observed during training, evaluation and deployment. The commitment follows a sequence of agent containment failures, including an incident in which agents reached systems outside their evaluation environment. Enterprises running third-party agents should ask vendors directly for incident-disclosure SLAs rather than waiting for voluntary frameworks to mature.
