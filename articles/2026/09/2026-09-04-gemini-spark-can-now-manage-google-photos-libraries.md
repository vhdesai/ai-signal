# Gemini Spark can now manage Google Photos libraries

Google is adding Google Photos control to Gemini Spark, letting eligible U.S. Gemini AI Pro and Ultra subscribers ask the agent to edit images, curate albums, create shared albums, turn flyer photos into calendar appointments, and run related workflows. The feature is a practical but incremental consumer AI step: it embeds an agent into a large personal data store where automation can reduce small tasks. The adoption question is whether these integrations become meaningfully habit-forming rather than just another AI-branded feature layer. AGENTS ENTERPRISE PRODUCTIVITY
