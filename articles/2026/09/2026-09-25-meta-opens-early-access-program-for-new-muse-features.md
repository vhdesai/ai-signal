# Meta opens early-access program for new Muse features

Meta opened an early-access waitlist for the Muse features announced at Connect, with an unusual signup mechanic: users must ask Muse itself to add them. Upcoming capabilities include a video-chattable digital avatar, expanded shopping connectors, a Mac app that operates desktop applications, and wake-word Muse on Meta's AI glasses. The desktop-control capability puts Meta into direct competition with OpenAI and Anthropic computer-use agents.
