# Company Releases Holo4 Open-Weight Computer-Use Models

Holo4 ships in two sizes — a 27B dense model and a 35B-A3B mixture-of-experts — unifying GUI clicking, code execution and MCP/API tool calls in a single 256K-context model across desktop, web, Android and APIs. It reaches 85.2% on OSWorld at $0.08 per task, versus 84.3% at $0.22 for its Qwen3.8-27B base.
