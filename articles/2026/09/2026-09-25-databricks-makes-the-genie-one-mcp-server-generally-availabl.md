# Databricks makes the Genie One MCP server generally available

Databricks moved the Genie One MCP server to general availability in Unity Gateway, exposing Genie over Model Context Protocol so any MCP client — Claude, ChatGPT or Cursor — can ground data questions in Genie with Unity Catalog permissions enforced per request. The same release shipped Genie Code document-processing pipelines and GA tags for dashboards, notebooks, apps and Genie Agents. The beta MCP endpoint sunsets October 31, 2026, so enterprise pipelines on the preview path need migration planning.
