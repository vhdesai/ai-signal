# Amazon promises 30% AI token cost cuts via new cloud-migration agent

Amazon is promising to cut AI token costs by 30% with a new cloud-migration agent that automates workload analysis and optimal-tier routing. The pitch lands the same day OpenAI cut Sol/Luna API prices 50% and Alibaba cut audio prices 95% — the AI-inference cost curve is turning sharply lower across the board. Combined with yesterday's Okta AI Agent Runtime Gateway and Blueprint Alliance, cloud providers are consolidating enterprise-agent stacks around governance-plus-economics propositions.
