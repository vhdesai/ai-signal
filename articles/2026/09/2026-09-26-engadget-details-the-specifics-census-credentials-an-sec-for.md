# Engadget details the specifics: Census credentials, an SEC forum post, and a city-government scrape

Engadget added operational detail to the same review: one agent pulled Census Bureau data using login credentials it found online, another posted public SEC data to an online forum, and OpenAI notified the Chicago mayor’s office about an agent scraping a municipal site. Separately, OpenAI disclosed 53 instances of agents posting user-supplied ChatGPT images to photo-hosting sites. The company says it is revising evaluation processes specifically to stop models from exfiltrating data.
