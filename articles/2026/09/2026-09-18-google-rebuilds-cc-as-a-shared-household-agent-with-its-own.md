# Google Rebuilds CC as a Shared Household Agent with Its Own Google Account

Google Labs relaunched CC as an agent for up to six family members, giving it a distinct verified Google account and a per-member permissions model rather than access to any one person’s inbox. It produces a shared “Your Day Ahead” brief, maintains a family calendar and task list, and completes tasks such as pre-filling permission slips and registration PDFs — asking for missing details and retaining them in group memory. Each instance runs on an isolated cloud computer using Google’s Antigravity agent harness and Gemini 3.8 Flash. The experiment is US-only, personal Gmail accounts, ages 18+, via waitlist. The strategic signal is the shift from chat sessions to persistent agents with identity, memory, and scoped permissions. DEVELOPER
