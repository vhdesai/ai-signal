# Anthropic launches Plugins as the primary path for third-party Claude extensions

Anthropic introduced Plugins — bundles of MCP connectors and/or Agent Skills — as the main third-party extension mechanism for Claude, with a directory submission portal offering auto-validation, safety scanning, review status and post-launch usage analytics. It also confirmed support for MCP 2.0 with a stateless core, alongside MCP Apps (in-chat interactive UI) and Enterprise Managed Auth. Existing skills and connectors require no changes, so the move is additive rather than breaking.
