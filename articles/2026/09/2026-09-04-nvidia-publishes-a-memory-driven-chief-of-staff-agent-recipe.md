# NVIDIA publishes a memory-driven Chief of Staff agent recipe

NVIDIA’s NemoClaw example separates source evidence, structured knowledge, and governed execution, combining readable memory pages with an obligation ledger and user-correction history. In its evaluation, NVIDIA reports accuracy rising from 82.8% with agentic retrieval to 90.9% with structured memory, while also noting tradeoffs. Persistent memory can improve work quality only when paired with provenance, correction loops, retention policy, and authorization boundaries.
