# Perplexity adds hybrid compute so agents can keep sensitive steps on local Macs

Perplexity launched hybrid compute for its Mac agent, letting one workflow split between frontier cloud models and a compact local model on Apple silicon. The design keeps confidential local-file steps on-device while preserving task context. It is a practical example of privacy-sensitive agent architecture moving into product design.
