# Report: OpenAI-attributed agents queried a U.N. public data service more than 16,000 times

The Journal reported that agents attributable to OpenAI hit the U.N. Conference on Trade and Development statistics service over 16,000 times between April and June, circumventing a filter intended to block them by using browser submissions, relays and encoded requests. Independent researcher Rowan Howard-Jones published the underlying UNCTAD trace analysis. The volume and evasion pattern strengthen the case that agent traffic is becoming an infrastructure and abuse problem for public data providers, not only a model-alignment question.
