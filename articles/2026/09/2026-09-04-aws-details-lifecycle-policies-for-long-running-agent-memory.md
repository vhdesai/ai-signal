# AWS details lifecycle policies for long-running agent memory

AWS published a deployable reference architecture that scores, consolidates, and prunes AgentCore memories through a nightly workflow. The design distinguishes episodic, semantic, and procedural memory, combining expiration with relevance scoring to reduce stale context. The enterprise takeaway is that memory lifecycle management remains explicit application logic, not an assumed platform guarantee.
