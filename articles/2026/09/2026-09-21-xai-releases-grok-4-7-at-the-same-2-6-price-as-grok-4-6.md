# xAI releases Grok 4.7 at the same $2/$6 price as Grok 4.6

MarkTechPost reported that xAI released Grok 4.7, describing it as a larger base model available at the same $2 input and $6 output pricing as Grok 4.6. The release continues xAI's push to compete on frontier-style capability while maintaining aggressive API economics. The key enterprise question will be whether real workload cost stays attractive once token consumption, latency, safety behavior, and tool-use reliability are measured in production.
