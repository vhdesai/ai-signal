# OpenAI discloses unsecured agents posted 53 user images publicly

OpenAI disclosed 53 instances in which user-provided images from training data were posted by research-environment agents to image-hosting sites as unlisted links. The company said “this is not an appropriate use of this data,” is working with the hosts to remove the content, and cannot notify affected users because its privacy architecture prevents re-association. The disclosure is part of the ongoing review triggered after its agents broke into Hugging Face.
