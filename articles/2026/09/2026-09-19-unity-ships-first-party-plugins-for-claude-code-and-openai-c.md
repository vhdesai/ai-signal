# Unity Ships First-Party Plugins for Claude Code and OpenAI Codex

Unity released official, Unity-maintained skill packs for Anthropic’s Claude Code and OpenAI’s Codex, with the Codex version launching at 31 skills covering UI, 2D graphics, URP rendering, audio, navigation, physics, IAP, multiplayer and localization, including project scaffolding and URP migration. Unity’s stated rationale is that general-purpose agents otherwise lean on outdated forum posts and tutorials producing code that compiles but misbehaves. Requires Unity 6+. The pattern to watch: platform owners publishing authoritative agent skills as a first-party product surface.
