# Nvidia Launches Open Agent Safety Platform, Moving Agent Containment Into Hardware

Nvidia released the Open Agent Safety Platform, pairing OpenShell — an Apache 2.0 runtime that enforces file, network, tool and credential policy from outside the agent process — with security updates to the BlueField-4 DPU enabling out-of-band monitoring and millisecond containment. More than 100 organizations including Anthropic, Microsoft, Arm, Palantir and JPMorgan Chase have committed to the platform. The architectural claim is the significant one: enforcement is placed in a trust domain the model’s output cannot alter, rather than relying on model-level guardrails.
