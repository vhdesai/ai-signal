# Microsoft packages work, code, and custom agents into a single Copilot app

Microsoft introduced an updated Copilot app that combines coding, advanced productivity work, and custom-agent creation as it tries to increase enterprise AI adoption. CNBC reported that fewer than 7% of Microsoft’s 450 million-plus commercial Office 365 seats have AI add-on licenses today, and that the new Cowork, Code, and Autopilot capabilities will use consumption-style pricing. The move reflects a broader market shift from standalone assistants toward bundled agent platforms that compete directly with Anthropic, OpenAI, and Meta. VIBE CODING REVENUE
