# OpenClaw 2026.9.5 Adds Atomic, Rollback-Safe Updates for Self-Hosted Agents

The open-source, MIT-licensed personal agent platform shipped 2026.9.5, bundling 4,179 pull requests from 502 contributing accounts. The headline change, Atomic Updates, validates the next version against a private copy of the running configuration and rolls back to the last working state on failure, so a broken upgrade no longer takes the agent offline. The release also adds plugin hot reload without a Gateway restart, read-only conversation sharing, and expanded GPT Live for Meet, Teams, and Zoom. Caveat: rollback cannot undo database migrations, so a verified backup is still required before upgrading.
