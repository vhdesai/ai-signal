# Amazon Blocks Meta's Muse AI Agent from Shopping the Amazon Store

Amazon has blocked Meta's Muse AI agent from placing orders on Amazon.com, citing Terms-of-Use violations, the fact that Muse did not identify itself as agentic, and credential-capture security concerns. Meta did not notify Amazon before launching Muse's shopping capability. It is the first high-profile platform-vs-agent standoff following Amazon's earlier Perplexity lawsuit and prior ChatGPT/Gemini agent blocks, and it will define legal precedent for whether platforms can exclude third-party agents from purchase workflows. pcmag.com — Amazon blocks Meta's Muse agent <https://nam06.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.pcmag.com%2Fnews%2Famazon-blocks-metas-new-ai-agent-from-shopping-its-store&data=05%7C02%7Cvdesai%40microsoft.com%7Cc14fb613b1ac463d126e08df1878657c%7C72f988bf86f141af91ab2d7cd011db47%7C1%7C0%7C639256577572376242%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=eThgpJpHv%2FVnu%2FwxIYiFBdMxWFxnykTrUW2bF05R%2B8o%3D&reserved=0>
