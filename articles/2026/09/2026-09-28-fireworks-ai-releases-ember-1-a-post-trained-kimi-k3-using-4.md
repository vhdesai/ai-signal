# Fireworks AI Releases Ember-1: A Post-Trained Kimi K3 Using ~40% Fewer Tokens

Rather than dialling down reasoning effort, Fireworks post-trained Kimi K3 to emit shorter reasoning traces at the same effort level. A production A/B test cut output from 49.3K to 29.9K tokens per task with scores essentially flat (0.753 vs 0.751).
