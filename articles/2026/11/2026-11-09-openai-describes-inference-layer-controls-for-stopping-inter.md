# OpenAI describes inference-layer controls for stopping internal research

OpenAI describes Control Room as an inference-layer enforcement system that stops model output within 35 seconds of a decision to stop or pause an internal research workload. The company says the system fails closed if Control Room goes down; these controls apply to internal research, not customer ChatGPT or API workloads.
