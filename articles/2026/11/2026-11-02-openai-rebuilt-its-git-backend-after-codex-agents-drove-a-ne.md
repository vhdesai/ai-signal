# OpenAI rebuilt its Git backend after Codex agents drove a nearly 15-fold rise in commits

OpenAI built Pando, a Git-compatible backend written in Rust that now serves its entire monorepo. One engineer designed the core, and teams of Codex agents built it in 10 weeks. Commits to the main branch rose 1,378% in Q3 2026 compared with Q1 2024, and by late 2025 the reliability of pushes and fetches sometimes fell below 90%. Pando handles each branch independently and reuses stored data across fetches. OpenAI says this cut median push latency by nearly 80%, and Pando now delivers almost a petabyte of Git data a day; Pando is not open source. Companies scaling up coding agents should expect source control, testing pipelines, and code review to become bottlenecks before model quality does.
