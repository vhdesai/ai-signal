# Meta launches Muse Ember, a $0.10-per-million-token multimodal model for high-volume agent work

Ember is the smallest Muse model, built for tool calls, coding subtasks, routing, extraction and long-document parsing, with text, image and audio input and a 1M-token context per MarkTechPost. Meta positions it as cheaper and stronger than Claude Haiku and OpenAI Luna on Artificial Analysis cost-per-task, and price-competitive with DeepSeek and GLM flash models. The intended pattern is Muse Wonder planning and Ember executing at volume, pushing the planner/worker split into mainstream agent design.
