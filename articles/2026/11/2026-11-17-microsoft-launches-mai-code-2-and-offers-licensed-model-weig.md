# Microsoft launches MAI Code 2 and offers licensed model weights at Ignite

At Ignite, Microsoft introduced new MAI models for coding, image editing, transcription and cyber defense, and said it will license model weights so customers can customize a frontier MAI model with their own data and run it in their own Azure environment. MAI Code 2 and Code 2 Flash are live in GitHub Copilot, while MAI Cyber 2 Flash reaches Microsoft security products from mid-December. Microsoft pitched the lineup on price, with commercial chief Judson Althoff claiming that "everything you can do in Claude or ChatGPT, you can do better in Copilot for less." Licensing weights sets Microsoft apart from OpenAI and Anthropic, neither of which gives customers access to model weights.
