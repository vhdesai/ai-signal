# llama.cpp and ggml reach version 1.0 with a stable-API commitment for local inference

The ggml-org project released v1.0.0 of llama.cpp and ggml after 3.5 years. It commits to semantic versioning, so any breaking change to the public C API will now require a major version bump. Distribution now spans Docker, Debian, Homebrew, conda-forge, MacPorts, Winget, and iOS/macOS XCFramework. A stable API makes llama.cpp easier to use as a dependency in on-device and private-deployment products. This is especially relevant as TechCrunch reports doubts about whether Nvidia will keep supporting open source after Huang's departure.
