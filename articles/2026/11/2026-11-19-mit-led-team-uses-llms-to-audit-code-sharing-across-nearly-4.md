# MIT-led team uses LLMs to audit code sharing across nearly 4,000 medical AI studies

Researchers led by MIT and Dana-Farber Cancer Institute used large language models to scan nearly 4,000 clinical prediction studies for statements about shared code, then followed those links to assess hundreds of repositories. They found that code sharing remains uncommon and that public code often lacks the documentation and supporting information needed for reuse. The findings, published in Nature Medicine, are informing TRIPOD-Code, a new reporting guideline for code in clinical prediction research.
