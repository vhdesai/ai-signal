# Meta releases Muse Ember, a low-cost hosted model for repetitive agent tasks

Muse Ember is the fourth model in Meta's Muse family and the first trained using its largest model, Muse Wonder Full. It accepts text, images, audio, and video, and has a 1 million-token context window and up to 512,000 output tokens. It scores 36 on the Artificial Analysis Intelligence Index, the same as Claude Haiku 5.5 at maximum effort, at about one-third the cost per task, because it uses fewer tokens at the same list price. It leads on business-automation tests (37.8% vs. 13.9% for Haiku) but trails on real-repository coding. Weights are not released, and most results are reported by Meta. Together with Meta's new enterprise sales push, Ember targets cost-sensitive, high-volume agent work. Products & Tools OPENAI AWS ENTERPRISE
