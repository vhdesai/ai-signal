# Stanford's Memorilla gives a frozen LLM an entire document store in just 16 tokens

Jure Leskovec's SNAP group at Stanford released Memorilla, a 194-million-parameter memory module that reads a whole document collection and hands a frozen LLM 16 memory tokens per question. With a frozen Qwen3-8B it scored 84.33% on FactKG versus 80.43% with every document in context, while using 108 times fewer document tokens, although it underperformed on short-context tasks such as PubMedQA. Code and checkpoints are released under Apache 2.0, offering retrieval teams an alternative to ever-longer prompts.
