# Microsoft adds MAI Code 2 and Code 2 Flash to the coding-model mix

Microsoft is distributing MAI Code 2 and Code 2 Flash through GitHub Copilot, positioning the former for more involved repository changes and the latter for fast, routine development work. This expands the choice of specialist models inside an established enterprise development workflow, while leaving model access subject to administrator policy. The advertised price-performance comparisons depend on launch discounts scheduled to end on May 17, 2027, so procurement teams should model steady-state costs rather than treat promotional economics as permanent.
