# Databricks turns Genie into an always-on business agent as the Linux Foundation backs an agent naming standard

Databricks unveiled an updated Genie agent that runs long, multistep jobs unsupervised, using an ontology built from customer data on its platform, and CEO Ali Ghodsi demonstrated it on employee-survey analysis, lost-deal reviews and interview preparation. Its Unity Gateway lets customers cap usage and swap in cheaper open-weight models to control cost. The Linux Foundation separately added the Agent Name Service, backed by 11 companies including Cisco and Salesforce, to make agents discoverable across the internet.
