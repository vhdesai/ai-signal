# NVIDIA's Apache 2.0 Auto Ontology generates a starting ontology from enterprise metadata, validates agent SQL against…

NVIDIA's Apache 2.0 Auto Ontology generates a starting ontology from enterprise metadata, validates agent SQL against certified business definitions, and exposes read-only tools over MCP. It connects to Databricks, Snowflake, Postgres, and DuckDB and runs Nemotron models through NIM or any OpenAI-compatible endpoint. NVIDIA reports a 90% cut in ontology build time but has published no text-to-SQL accuracy results, so teams will need to benchmark it themselves.
