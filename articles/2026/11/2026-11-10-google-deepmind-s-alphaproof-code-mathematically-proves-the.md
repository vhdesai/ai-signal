# Google DeepMind's AlphaProof Code mathematically proves the security of Signal's encryption code

Human experts and AI models first wrote Signal's security goals as formal specifications, with humans reviewing every one. Agents powered by Gemini Carbon then generated more than 6 million lines of proofs in Lean, a language for machine-checked proofs, and flagged only about 1% for human review. DeepMind says the work took four weeks, compared with years by traditional methods. It covers the code that actually runs on devices, not just the protocol design, and DeepMind says this is the first such verification of a widely deployed protocol by any method. When two real bugs that had previously been fixed were put back into a test copy, the system proved the flawed version was insecure. Mathematical proof of security at this depth could become practical for other critical software. BAIDU AUTOMATED RESEARCH CHINA AI
