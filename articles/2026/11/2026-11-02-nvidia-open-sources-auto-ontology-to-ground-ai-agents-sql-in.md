# NVIDIA open-sources Auto Ontology to ground AI agents' SQL in approved business definitions

According to MarkTechPost, Auto Ontology is an Apache 2.0 library that generates a semantic layer from enterprise metadata. Agents' SQL queries are then based on certified definitions, and the context is served through MCP, a command-line tool, and an API. It targets a main way enterprise data agents fail in practice: wrong joins and inconsistent metric definitions. NVIDIA is also continuing to move up the stack into agent tooling.
