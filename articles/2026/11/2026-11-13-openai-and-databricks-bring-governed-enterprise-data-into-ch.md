# OpenAI and Databricks bring governed enterprise data into ChatGPT as Perplexity's Teammates agents reach the Mac

A Databricks Genie plugin for ChatGPT, built on Genie MCP, lets employees query company data using the metric definitions in Genie Ontology while enforcing each user's existing permissions, and Unity Gateway is positioned as the control point for rolling out OpenAI Codex with usage and cost tracking. Perplexity brought Teammates, persistent background agents that plan work, spawn sub-agents and keep running in the cloud, to its Mac app for $200-a-month Max subscribers. The data platform is emerging as the trust layer between frontier models and enterprise systems, while consumer-grade autonomous agents remain a premium tier.
