# Meta bought Conductor, whose platform runs teams of coding agents in parallel workspaces using models from Anthropic…

Meta bought Conductor, whose platform runs teams of coding agents in parallel workspaces using models from Anthropic and OpenAI. Founder Charlie Holtz will work with Alexandr Wang and Nat Friedman at Meta Superintelligence Labs and teased a new interface early next year. Conductor's cloud service shuts down November 20. The deal adds to Meta's Muse Code push as the race to own multi-agent software development heats up.
