# Enterprise agents move into existing channels: IBM-Microsoft Imagine Enterprise, ChatGPT on AWS Marketplace and Gemini for healthcare

IBM and Microsoft launched Imagine Enterprise, which pairs more than 6,000 prebuilt IBM Consulting agents and assets with Microsoft Foundry, Copilot Studio, Fabric, Entra and Purview, plus forward-deployed engineers for regulated industries. OpenAI made ChatGPT Enterprise purchasable through AWS Marketplace, counting toward customers' AWS commitments, and Google Cloud previewed Gemini for healthcare with HCA Healthcare, Highmark Health and Northwell Health to automate records synthesis and prior authorization. The common thread is distribution: agent vendors are riding existing procurement, cloud and consulting relationships rather than selling standalone.
