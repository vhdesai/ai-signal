# Meta introduces Muse Ember for lower-cost agent execution

Meta has introduced Muse Ember, a lightweight model aimed at agent execution and subagent work, with input pricing of $0.10 per million tokens, according to TechCrunch. Its positioning suggests an option for assigning bounded tasks to a cheaper model rather than using a larger model for every step. The cited performance comparisons come from vendor benchmarks and have not been independently verified.
