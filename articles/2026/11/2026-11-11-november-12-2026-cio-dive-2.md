# [November 12, 2026] · [CIO Dive]

Databricks unveiled an updated Genie agent that runs long, multistep jobs unsupervised using an ontology built from customers' Databricks data, with a Unity Gateway that caps usage and swaps in cheaper open-weight models. The Linux Foundation added the Agent Name Service, backed by 11 companies including Cisco and Salesforce, to make agents discoverable across the internet. Northern Trust says an onboarding agent built with Microsoft forward-deployed engineers cut analysts' data-preparation time by 83%.
