# OpenAI brings GPT-Live-1.1 to its API with a cheaper standby mode for idle calls

OpenAI made GPT-Live-1.1, the full-duplex voice model behind ChatGPT Plus and Pro voice since October, available in its API with better accents, transcription and task completion, though it has published no benchmark scores. A new standby mode pauses inference during silence and bills idle WebRTC time at $0.02 a minute instead of $0.05. Harder reasoning and tool calls can be handed to GPT-6 Astra, Luna or a customer's own backend, which makes always-on voice agents such as call centers cheaper to run.
