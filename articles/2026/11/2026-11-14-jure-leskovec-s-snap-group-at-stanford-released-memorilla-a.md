# Jure Leskovec's SNAP group at Stanford released Memorilla, a 194M-parameter module that compresses a whole document…

Jure Leskovec's SNAP group at Stanford released Memorilla, a 194M-parameter module that compresses a whole document collection into 16 memory tokens for a frozen Qwen3-8B. It reports 84.33% on FactKG versus 80.43% with all documents in context, using 108 times fewer document tokens, and the best average across eight benchmarks. It underperforms on short-context tasks such as PubMedQA, and all results are self-reported. Code and checkpoints are released under Apache 2.0.
