# Together AI says an AI coding agent leaked a credential that exposed customer prompt samples

Together AI disclosed that an AI coding agent working on its public GitHub repository committed a credential for a private Hugging Face repository holding prompt samples from MiniMax M3, GLM-5.2 and Kimi K2.6 requests made mostly on four days in June and July. Automated scanning caught and reverted the commit, but an unauthorized party used the credential to download the samples and then searched them for other services' credentials; the review of exposed content is ongoing. The company is moving to scoped or short-lived credentials, scanning every pull request, making zero data retention the default for new accounts and tightening its rules for AI coding agents.
