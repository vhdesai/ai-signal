# Architect Labs says AI agents designed its Frostbite CPU from theory to final chip layout

Architect Labs says its agents co-designed Frostbite, a 7nm CPU whose instruction set is built around interaction nets, a parallel computation model, taking it from theory to a manufacturing-ready layout with the specification checked in more than 800,000 lines of Lean. Pre-silicon tests across 25 workloads showed 4.59 times the performance per watt and 8.77 times the performance per area of an in-order CPU core. The chip has not been built and the results are self-reported, but it is a concrete case of agents doing end-to-end architecture work rather than assisting human designers.
