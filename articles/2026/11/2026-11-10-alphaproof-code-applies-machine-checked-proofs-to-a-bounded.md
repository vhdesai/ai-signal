# AlphaProof Code applies machine-checked proofs to a bounded Signal build

DeepMind says AlphaProof Code machine-checked security properties of a compiled AArch64 build of Signal’s libsignal-cli, using multiple agents with human goal-setting and review. The company reports producing 6.5 million lines of Lean proofs over four weeks, supported by 26,000 lines of trusted specifications and semantics. The result is bounded to a fresh-process build and does not cover key generation or group messaging, so it is not a blanket assurance that all of Signal is secure. For technology leaders, the important distinction is between checking a defined property against trusted assumptions and certifying an entire product.
