# Google DeepMind's AlphaProof Code formally verifies key Signal protocol guarantees

DeepMind used a new agentic framework, AlphaProof Code, to formally prove several core cryptographic properties of the Signal protocol in about four weeks. It found no new flaws, but correctly failed to verify older versions with known, long-fixed vulnerabilities. Scope was limited to the protocol, not the full app, and DeepMind is releasing the specification and proof. It is a credible signal that AI-assisted formal verification is becoming practical for high-value code. RESEARCH
