# Berkeley's CyberBinGym shows AI agents can reverse-engineer security patches into working exploits

Berkeley RDI and collaborators built CyberBinGym, a benchmark of 100 real vulnerabilities across 53 open-source projects in which agents receive only a stripped vulnerable binary and its patched version. Codex running GPT-5.6 Sol recovered 88% of the vulnerabilities and produced working exploits in 20% of cases, versus 85% and 6% for Claude Code with Claude Opus 5. Access to the patched binary raised Codex's exploit success from 10% to 25% on matched tasks, but standard binary hardening cut its 20 successful exploits to two. The gap between patch release and deployment is now a measurable AI-era risk, which raises the value of faster patching and layered defenses.
