# Architect Labs unveils Frostbite, a CPU its AI agents designed from theory to final layout

Architect Labs says its AI agents designed Frostbite, a 7nm CPU whose instruction set is built around interaction nets, a model that lets the chip execute work in parallel. The agents took it from theory to a final chip layout ready for manufacturing. The specification was checked through more than 800,000 lines of Lean. Pre-silicon tests report 4.59 times the performance per watt and 8.77 times the performance per area of an in-order CPU core across 25 workloads. The chip has not been manufactured, but it is a concrete case of agents doing end-to-end architecture work rather than assisting human chip designers. Academic Research MIT EDA
