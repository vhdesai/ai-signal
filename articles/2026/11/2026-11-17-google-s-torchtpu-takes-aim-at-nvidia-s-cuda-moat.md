# Google's TorchTPU takes aim at Nvidia's CUDA moat

Google's TorchTPU, developed with Meta, lets developers run existing PyTorch workloads built for Nvidia GPUs on its TPUs with minimal code changes. It targets the software gap that kept developers on CUDA, since Google's own JAX framework was widely seen as clunky. With Nvidia under leadership and export scrutiny, lower switching costs could help Google, AMD and Amazon win more AI chip business. POWER UPDATE
