# OpenAI merges ChatGPT's Chat and Work tabs and puts ChatGPT and Codex on one usage pool

An email to users says the merged experience will roll out first to selected users for feedback. In it, ChatGPT can take a task from initial idea to finished output using the user's files and plugins. Codex remains a separate experience in the desktop app, but ChatGPT and Codex will now draw from the same token allowance, so heavy users may hit resets more often. Anthropic made a similar change in September. With usage pooled, how products ration tokens across tools is becoming part of pricing. NVIDIA AGENTS DATA
