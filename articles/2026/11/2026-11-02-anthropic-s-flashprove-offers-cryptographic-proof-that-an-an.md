# Anthropic's FlashProve offers cryptographic proof that an answer came from a specific model

Anthropic and academic collaborators released FlashProve, an open-source research prototype that uses zero-knowledge proofs to show an LLM output was produced by a committed set of weights without revealing them. Anthropic reports proving at about 110 tokens per second on Llama 4 Maverick using one 80 GB GPU plus host memory. Potential uses include customer integrity checks, third-party evaluations and enforcement of approved-model requirements.
