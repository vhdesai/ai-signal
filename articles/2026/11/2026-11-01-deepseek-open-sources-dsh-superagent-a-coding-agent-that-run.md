# DeepSeek open-sources dsh-superagent, a coding agent that runs work in parallel

DeepSeek's Harness team released dsh-superagent v0.1.0, an MIT-licensed prototype. A long-running router takes requests from GitHub or Feishu and assigns each authorized task to its own worker session. In DeepSeek's simulation, the 95th-percentile task completion time fell to 15.7 minutes from 29.5 minutes for a single-session agent. The test used only synthetic messages, and code quality was not measured. The design treats human attention as the bottleneck, which mirrors how Western agent tools are developing.
