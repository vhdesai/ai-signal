# OpenAI introduced Images 2.6 across ChatGPT, Codex and the API

OpenAI introduced Images 2.6 across ChatGPT, Codex and the API. It adds animated GIF creation from prompts or uploaded photos, reusable named reference images, and more consistent multi-turn edits for characters and product details. OpenAI says generation is 50% faster and users now create about 4 billion images a week. Developers get two updated API models, which MarkTechPost reports include SVG export.
