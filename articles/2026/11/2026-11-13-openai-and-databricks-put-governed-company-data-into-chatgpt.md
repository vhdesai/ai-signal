# OpenAI and Databricks put governed company data into ChatGPT and Codex through Genie and Unity Gateway

A Databricks Genie plugin for ChatGPT, built on Genie MCP, lets employees query company data in Databricks. It applies the metric definitions stored in Genie Ontology, such as what counts as revenue or an active customer, and enforces each user's existing permissions, with answers linked back to their sources. Databricks Unity Gateway is positioned as the control point for giving OpenAI Codex to every engineer while tracking usage, cost and where code and data go. Combined with ChatGPT Work's ability to carry out actions the user approves, this makes the data platform the trust layer between frontier models and enterprise systems.
