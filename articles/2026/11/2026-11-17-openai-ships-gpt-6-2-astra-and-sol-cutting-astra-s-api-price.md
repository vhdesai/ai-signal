# OpenAI ships GPT-6.2 Astra and Sol, cutting Astra's API prices by 20%

OpenAI released GPT-6.2 Astra and GPT-6.2 Sol in ChatGPT Work, Codex and the API, saying both finish demanding tasks with fewer output tokens. Astra remains the pick for the hardest work, with better slide-template matching and more focused code changes, and its standard API prices are 20% lower than GPT-6 Astra's. On Cognition's FrontierCode 2.0, Sol came within half a point of Astra at about one-fifth of the cost, making it the likely everyday workhorse. A new Ultrafast mode generates tokens up to 4.5 times faster for Pro subscribers and eligible Enterprise and Edu workspaces.
