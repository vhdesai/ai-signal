# Perplexity open-sources Decider v1.3, small models that return probabilities instead of text

Perplexity released pplx-decider-v1.3 at 27 billion parameters and a 4-billion-parameter Flash variant under Apache 2.0, both of which answer yes/no, multiple-choice and scoring questions by returning a probability for each option. Version 1.3 adds Locate for extracting exact text spans and isolates batched questions from one another, which Perplexity says cuts the answer-flip rate to 0.27%. Coming a day after Google's Gemini Decision 1, the release gives enterprises an open-weight option for the routing, guardrail and triage steps inside agent pipelines, although all benchmarks are self-reported. https://www.marktechpost.com/2026/11/13/perplexity-decider-v1-3-open-weight-decision-models-locate/
