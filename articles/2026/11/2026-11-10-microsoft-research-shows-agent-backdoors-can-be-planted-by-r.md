# Microsoft Research shows agent backdoors can be planted by rewiring fewer than ten dormant neurons

Researchers describe editing fewer than ten rarely used neurons to implant a hidden behavioral trigger in an agent's underlying model without retraining. The attack assumes an adversary can modify model weights; it does not show that a prompt alone can induce the change. The practical lesson is that behavioral safety testing must be paired with checkpoint provenance, weight-integrity checks and constrained tool permissions. https://www.microsoft.com/en-us/research/blog/lazare-veni-foras-reprogramming-dormant-neurons-to-backdoor-ai-agents/
