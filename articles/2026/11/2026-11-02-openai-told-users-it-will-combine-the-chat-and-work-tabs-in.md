# OpenAI told users it will combine the Chat and Work tabs in ChatGPT so users can move from exploring an idea to having…

OpenAI told users it will combine the Chat and Work tabs in ChatGPT so users can move from exploring an idea to having ChatGPT execute tasks in one place, starting with a limited feedback group. Codex stays a separate experience in the desktop app, but ChatGPT and Codex will now draw from a shared token allowance, which may mean more frequent waits for heavy users. The change mirrors Anthropic's September merge of Claude chat and Cowork, and signals tighter compute rationing across consumer and coding products.
