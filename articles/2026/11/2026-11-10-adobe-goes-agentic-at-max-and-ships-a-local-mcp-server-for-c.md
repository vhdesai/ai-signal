# Adobe goes agentic at MAX and ships a local MCP server for Creative Cloud

Adobe expanded its Firefly agent to be proactive and always on, added a Builder prototyping tool that moves toward Figma's territory, and released a local MCP server exposing more Creative Cloud features to ChatGPT, Claude and Gemini. Google separately announced deeper Adobe integration, including PDF editing in Drive and Adobe AI inside Gemini. Creative software vendors are now treating third-party assistants as a primary distribution channel. ENTERPRISE
