# App vendors adapt to assistants: Adobe opens Creative Cloud via MCP as Apple meters AI with usage packs

At MAX, Adobe released a local Model Context Protocol server that exposes Photoshop, Illustrator, After Effects and Premiere features to ChatGPT, Claude and Gemini, alongside an always-on Firefly agent and a Figma-like Builder prototyping tool. Apple introduced one-time $49.99 Intelligence Usage Packs that extend cloud AI features in Logic Pro and other Creator Studio apps after monthly limits are reached. Both moves reflect a new reality for software vendors: third-party assistants are becoming a front door, and heavy AI use is being priced as consumption rather than bundled into subscriptions.
