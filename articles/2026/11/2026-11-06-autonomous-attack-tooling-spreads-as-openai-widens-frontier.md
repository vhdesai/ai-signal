# Autonomous attack tooling spreads as OpenAI widens frontier access for defenders

Censys found more than 800 internet-exposed, password-free deployments of Artex, a Chinese-made open-source agent system that runs attacks from reconnaissance through data theft and has been tied to the ConnectWise breach and attacks on South Korean banks. Some exposed instances revealed attack implants and victim data. OpenAI announced a partnership with Hacktron for joint vulnerability testing, granting expanded frontier-model access through its Daybreak Red program for authorized security research.
