# Autonomous attack tooling spreads as labs widen access for defenders

Censys found more than 800 internet-exposed, password-free deployments of Artex, a Chinese-made open-source agent that runs attacks from reconnaissance through exfiltration and has been tied to the ConnectWise breach and attacks on South Korean banks; some instances exposed implants and victim data. OpenAI announced a partnership with Hacktron for joint vulnerability testing, granting expanded frontier-model access through its Daybreak Red program for authorized security research. Defenders should now assume adversaries operate agentic tooling at scale. Sources: TechCrunch | OpenAI
