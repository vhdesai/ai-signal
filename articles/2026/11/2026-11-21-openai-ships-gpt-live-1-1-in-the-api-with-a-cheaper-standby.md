# OpenAI ships GPT-Live-1.1 in the API with a cheaper standby mode for idle calls

OpenAI made its full-duplex voice model GPT-Live-1.1 available in the API. It claims better accents across languages, transcription, handling of letters and numbers, and task completion, but has published no benchmark scores. A new standby mode bills idle WebRTC time at $0.02 a minute instead of $0.05 while active. Harder reasoning can be handed off to GPT-6 Astra or Luna. Cutting the cost of idle time matters most for always-on voice agents such as call centers. OPEN WEIGHTS EFFICIENCY
