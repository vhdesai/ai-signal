# Google previews Tool Retrieval in the Gemini API for agents with large tool libraries

Google launched Tool Retrieval in preview in the Gemini Interactions API, letting agents keep large tool libraries available without sending every parameter schema in every prompt; the model sees only each tool's name and a short description and loads the full schema when a task needs it. Google's documentation notes that a few dozen function declarations can otherwise consume tens of thousands of tokens per request. In server-side mode, search, schema loading and the function call resolve in a single API request and work with remote MCP servers, though Google still recommends static loading for fewer than 20 stable tools.
