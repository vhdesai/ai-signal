# Google's /teamwork multi-agent system helps settle long-open math problems, with proofs checked in Lean 4

Google says /teamwork, the multi-agent system in Antigravity, runs many solution attempts in parallel and checks each with automated verifiers such as the Lean 4 proof checker, test suites and simulators. It also gives each agent only the files and tools it needs, so long tasks don't overload any one agent's context. Researchers from Google, CUHK, USC and CMU used it to prove the 2013 Courtade-Kumar conjecture from information theory in full generality, with a formal proof of about 50 million lines of Lean. A related agent system called LEAP produced, on its own, a 1.8-million-line formal proof of the Weil conjectures. Google reports other results that have not yet been independently reviewed: progress on Tarjan's 1985 Deque Conjecture, a solver for identifying molecular structures from spectroscopy data that was correct 95% of the time on its first answer, and graph-processing systems 60-90x faster. Google says these tools are now available to outside users in Antigravity. Academic Research STANFORD MEMORY OPEN SOURCE
