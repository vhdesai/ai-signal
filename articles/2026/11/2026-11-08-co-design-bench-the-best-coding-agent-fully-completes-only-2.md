# Co-Design Bench: the best coding agent fully completes only 26% of real-world change requests

Researchers from Alibaba and several Asian universities built Co-Design Bench from real user change requests to existing web apps, sometimes with image, audio, video or document inputs. GPT-6 Astra led ten models, meeting about 70% of a task's requirements on average but fully completing only 26.4% of tasks, ahead of Claude Opus 5 and Qwen3.8-Max. Scores fell as change types were combined, and extra compute did little: GLM-5.2 used nearly six times GPT-6 Astra's tokens and still scored significantly worse.
