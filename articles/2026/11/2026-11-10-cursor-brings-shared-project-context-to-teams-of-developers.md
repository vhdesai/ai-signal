# Cursor brings shared project context to teams of developers and agents

Cursor is rolling out a multiplayer beta for Projects that shares requirements, decisions, task state, and agent communications across a team. The intended benefit is continuity: a developer or agent can pick up work without reconstructing the project's context from separate sessions. The announcement makes coordination and dependency management a more explicit part of the coding-agent product, although it does not establish independently measured productivity gains. Timing: Original beta announcement dated November 10; publication time unavailable. 24–48-hour exception. Verified URL: https://cursor.com/blog/projects-multiplayer
