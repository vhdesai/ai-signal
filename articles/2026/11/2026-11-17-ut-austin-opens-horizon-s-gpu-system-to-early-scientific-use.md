# UT Austin opens Horizon’s GPU system to early scientific users

UT Austin’s Texas Advanced Computing Center opened Horizon to early users with a 4,000-GPU NVIDIA Grace Blackwell system for AI, simulation, and scientific datasets. A CPU expansion is planned for early 2027 and should not be counted as current capacity. The opening expands access to shared scientific-AI compute; it is an infrastructure milestone for academic research, not a new model breakthrough. Freshness: The original November 17 date is verified; precise publication time is unavailable.
