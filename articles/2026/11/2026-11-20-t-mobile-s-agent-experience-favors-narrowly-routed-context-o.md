# T-Mobile’s agent experience favors narrowly routed context over more documents

Strict 24h — exact publication timestamp confirmed. VentureBeat’s new reporting on implementation experience presented at an October event describes how extensive customer-service support documents gave T-Mobile’s agents conflicting instructions; a subsequent knowledge graph was too slow and difficult to navigate. The approach shifted to key-value lookup routing requests to agents holding narrow, relevant context. This is a deployment case study, not a new product launch or proof that less context is universally better.
