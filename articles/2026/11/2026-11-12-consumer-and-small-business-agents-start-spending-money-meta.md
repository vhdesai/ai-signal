# Consumer and small-business agents start spending money: Meta's Muse places calls and Replit Agent makes purchases

Meta's Muse agent, which has over 10 million users, can now call US businesses on a user's behalf, but only for paid subscribers. Plans start at $20 a month for 500 million tokens per week. Replit separately gave Replit Agent two new jobs: buying supplies through Stripe's Link agent wallet and Visa, using a Browserbase browser that stops at checkout for owner approval, and running Google Ads campaigns. Replit says payment approvals are enforced in code and shell access is disabled during payment, a design pattern enterprises will likely require for any agent that can spend money.
