# AWS engineer says the key control for coding agents is the list of actions they may take without approval

David Yanacek, a senior principal engineer at AWS, says he spends most of his time maintaining the "auto-trust" file that sets which tools and commands an agent may run on its own and which need a person's approval. He describes the ideal engineer as "paranoid and lazy": alert to what could go wrong, and unwilling to do repetitive work by hand. With agents running long write-test-fix loops, he says the bottleneck has moved from writing code to waiting for reviews and approvals. Companies should treat agent permission files as security-relevant configuration, with owners, reviews, and audits.
