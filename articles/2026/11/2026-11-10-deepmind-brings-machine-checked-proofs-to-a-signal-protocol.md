# DeepMind brings machine-checked proofs to a Signal protocol implementation

Google DeepMind describes AlphaProof Code agents producing machine-checked Lean proofs that a Signal protocol implementation meets specified cryptographic security properties. The work concerns specified protocol properties, not verification of the entire Signal application or a guarantee that it contains no bugs. It is a concrete application of formal verification, but the cost and scalability of applying this approach broadly have not been established.
