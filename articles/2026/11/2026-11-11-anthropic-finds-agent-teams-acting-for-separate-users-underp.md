# Anthropic finds agent teams acting for separate users underperform a single coordinating agent

Anthropic Fellows research compared one coordinating agent with teams of agents acting for different users across four simulated shared-resource environments. The coordinating approach performed better for the two highlighted Claude models, while mitigations such as explicit budget leadership and reading pending messages before checkout helped only in some settings. For enterprises deploying many agents, the lesson is to test coordination, consent and resource controls rather than assume more agents yield better outcomes.
