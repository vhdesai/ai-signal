# Microsoft expands agentic Azure operations with distinct availability stages

Microsoft described Azure Resource Manager MCP capabilities that let agents create, manage and update resources under Azure Policy. The Azure Copilot deployment agent and Azure Monitor health models are generally available; Azure Copilot spaces and custom skills, plus additional SRE Agent security and coordination capabilities, are in public preview. Azure Workload Center is in limited preview, making governance boundaries and availability stages important to deployment planning. Published November 16; exact time not disclosed, so strict 24-hour placement is unconfirmed.
