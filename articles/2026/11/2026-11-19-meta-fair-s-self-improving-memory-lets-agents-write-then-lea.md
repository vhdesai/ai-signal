# Meta FAIR's Self-Improving Memory lets agents write, then learn, their own memory strategy

Meta FAIR, with co-authors from the University of Washington and Johns Hopkins, had Kimi-K2.6 iteratively rewrite its own LOAD and OFFLOAD prompts for a file-based memory that carries across subtasks, then distilled that behavior into the model with a LoRA adapter. Self-discovered memory prompts averaged 56.0 across three continual-learning tasks versus 44.6 for the best human-written harness, with the largest gain (+20.6 points) on the codebase task. Distilling the behavior into weights delivered smaller gains, as little as 2.9 points on one task.
