# Automattic launches Spacefast to host and deploy apps built with any coding agent

The WordPress.com owner's new service provides the backend that AI-built apps need: databases, authentication, file uploads, email, and analytics. It works with ChatGPT, Claude, Cursor, Opencode, Amp, and other agents, or with a connected Git repository. Spacefast competes with Lovable and Emergent but does not require a particular agent, and Automattic is pitching it to companies that want to consolidate the many landing pages their marketing teams build on separate services. It is a sign that hosting and governing AI-built apps is becoming a market of its own. OPEN SOURCE CODING AGENTS DEVOPS
