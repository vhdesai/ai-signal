# ChatGPT Enterprise is now available through AWS Marketplace

OpenAI made ChatGPT Enterprise purchasable through AWS Marketplace, letting organizations buy it through their existing AWS purchasing relationships. It removes a procurement hurdle for AWS-centric enterprises and puts OpenAI directly alongside Anthropic's models in Amazon's channel, the same day AWS added Claude Mythos and Fable 5.2 to Bedrock.
