# OpenAI brings GPT-Live-1.1 to its API with cheaper standby billing for voice agents

OpenAI made GPT-Live-1.1, the full-duplex voice model behind ChatGPT voice since October 15, available to developers, citing better accents, transcription, handling of letters and numbers, and task completion, though it has published no benchmark scores. A new standby state pauses inference during silence and bills idle WebRTC time at $0.02 a minute instead of $0.05 when active. Harder reasoning and tool calls can be handed to GPT-6 Astra or a customer's own backend, making always-on voice agents such as call centers cheaper to run.
