# [November 5, 2026] · [Reuters]

OpenAI gave a handful of approved customers access to GPT-6 Cyber, a model built to find software vulnerabilities and exploit them so defenders can fix them. Its preparedness framework classifies the model's cybersecurity capability as Critical, which is why access is gated. OpenAI said it used the model to find 81 previously unknown problems in Firefox, and Mozilla said patches are on the way.
