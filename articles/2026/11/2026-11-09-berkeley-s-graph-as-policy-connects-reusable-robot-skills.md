# Berkeley’s Graph-as-Policy connects reusable robot skills

Berkeley describes Ken Goldberg’s team’s CoRL work on Graph-as-Policy, which composes existing robot skills into programs and tests them in simulation, alongside open-source code and an industrial-task benchmark using NVIDIA Isaac. The university also reports that a related Ambi Robotics update has reached 30% of its U.S. fleet, a deployment claim that should not be read as evidence of universal robot autonomy.
