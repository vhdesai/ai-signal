# Replit Missions packages outcome-driven software execution

Replit Missions coordinates agent swarms around an outcome, spending cap, approvals, and acceptance criteria, with cloud-based building, testing, and iteration. A separate AI judge evaluates the work, and a mission stops unresolved when its budget is depleted. Replit’s controlled vendor tests do not establish universal production superiority. Teams should test outcome delegation with explicit success criteria and consequential-action approvals set before execution.
