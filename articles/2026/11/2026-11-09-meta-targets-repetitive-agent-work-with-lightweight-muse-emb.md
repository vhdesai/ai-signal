# Meta targets repetitive agent work with lightweight Muse Ember

Meta introduced Muse Ember, its smallest model, for high-volume repetitive tool calls and coding subtasks. TechCrunch reports Meta Model API prices of $0.10 per million input tokens and $0.50 per million output tokens; the cited benchmark claims come from the company rather than independent testing. For enterprise teams, the useful test is whether routing narrow tasks to this cheaper model reduces total workflow cost without increasing retries or supervision.
