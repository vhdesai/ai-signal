# MIT's SLIC uses a small language model to speed up analog chip design

MIT researchers, working with IBM Research and Analog Devices, built SLIC (Small LM Iterating on Circuits), a small language model that iteratively designs analog circuits and matches or beats frontier LLMs on the task. Because it runs on a laptop, engineers can keep confidential design data local instead of sending it to cloud models. The work, led by Yan Xu, will be presented at NeurIPS 2026.
