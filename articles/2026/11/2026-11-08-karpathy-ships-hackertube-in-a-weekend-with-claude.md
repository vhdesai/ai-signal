# Karpathy ships HackerTube in a weekend with Claude

Andrej Karpathy used Claude Opus 5.5 to mine 43 million comments from 20 years of Hacker News for 6,454 frequently recommended videos, launching HackerTube as a login-free alternative to YouTube recommendations. He says Claude Code handled nearly everything from data analysis to server setup, leaving him only an API key, a rented server and a domain. He then built a second site with 47,000 videos in about three minutes, a vivid data point on solo, agent-built software.
