# Adobe launches an MCP server so ChatGPT, Claude, and Gemini can use Creative Cloud features

At its MAX conference, Adobe released a local Model Context Protocol (MCP) server that exposes features in Photoshop, Illustrator, After Effects, and Premiere to other AI assistants. It also introduced Builder, a prototyping tool in Firefly in private beta that competes with Figma, and made its Firefly agent proactive and always on. Adobe says it will expand what the MCP server exposes based on how people use it. Separately, Google said it is bringing Adobe tools into Google apps. This shows established software companies accepting that third-party AI assistants are becoming a main way users reach their products. Infrastructure ENERGY GEOTHERMAL DATA CENTERS
