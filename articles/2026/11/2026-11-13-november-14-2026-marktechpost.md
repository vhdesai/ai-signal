# [November 14, 2026] · [MarkTechPost]

Jure Leskovec's SNAP group at Stanford released Memorilla, a 194-million-parameter memory module that reads a whole document collection and hands a frozen LLM 16 memory tokens per question. With a frozen Qwen3-8B it scored 84.33% on FactKG versus 80.43% with every document in context while using 108 times fewer document tokens, though it underperformed on short-context tasks. MIT researchers separately made topology optimization interactive, letting engineers steer AI-generated structures as they form, which improved buckling load by 39% for about 15 seconds of extra design time.
