# ChatGPT Enterprise is now sold through AWS Marketplace, as AWS markets its own Quick agent workspace

AWS customers can now buy ChatGPT Enterprise, including Codex and the dots agent, through their AWS accounts and count eligible spending toward their AWS commitments. ChatGPT for Healthcare and ChatGPT for Financial Services are also available. The listing adds to OpenAI's models already offered on Amazon Bedrock. The same day, AWS launched its first brand campaign for AWS Quick, its enterprise-only agent workspace, highlighting integration with Microsoft Purview and Active Directory. Amazon is now both reselling OpenAI's flagship product and competing with it. GOOGLE HEALTHCARE AGENTS
