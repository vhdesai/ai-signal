# Baidu released downloadable weights for ERNIE-5.5-Flash-Base, a text-only mixture-of-experts model with 280B total…

Baidu released downloadable weights for ERNIE-5.5-Flash-Base, a text-only mixture-of-experts model with 280B total parameters, of which 14B are active per token. The checkpoint stops at the end of pre-training on 33.5T tokens and supports 1M-token contexts, which gives developers a clean base for domain adaptation and RL research. Baidu says a post-trained ERNIE 5.5 Flash will follow. This is its first open release in about 16 months.
