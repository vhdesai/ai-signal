# OpenAI ships Images 2.6 with GIF creation across ChatGPT, Codex and the API

Images 2.6 adds animated GIF creation from prompts or photos, reusable saved reference images and more consistent multi-turn edits. OpenAI says generation is faster, a vendor-reported claim, and some features are still rolling out. The release pushes image generation further into developer and production content workflows.
