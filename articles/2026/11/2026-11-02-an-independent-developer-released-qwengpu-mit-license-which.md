# An independent developer released qwenGPU (MIT license), which adds 45 compiler-generated, untrained layers to…

An independent developer released qwenGPU (MIT license), which adds 45 compiler-generated, untrained layers to Qwen3.5-2B that act as a 4-lane SIMT processor executing CUDA compiled to PTX inside the model's forward passes. The developer reports exact results on all tested launches and matching a real Tesla T4 on 49 of 49 kernels, with negligible drift in text output. It is a research curiosity at 10–15 tokens per second, but it shows a path to exact computation inside a pretrained LLM rather than via external tools.
