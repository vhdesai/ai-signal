# Cursor traces a malicious Claude Code extension to a key leaked by Fireworks as AI fuels a ransomware boom

Cursor says an attacker used a Cursor access key exposed by its inference vendor Fireworks to copy historical coding traces from non-Privacy Mode sessions, harvested unredacted credentials from a small share of them, and pushed a malicious Claude Code extension build to its extension cache during an 11-hour window. Cursor says production systems, signing keys and Privacy Mode data were unaffected and that it has moved inference off Fireworks. Wired separately reports that AI is lowering the barrier to ransomware, with about 111 groups claiming attacks from July to September and newcomers listing dozens of victims within weeks. Retained agent session logs and inference vendors now belong squarely in supply-chain risk reviews.
