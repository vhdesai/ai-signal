# Agent infrastructure draws capital: LangChain doubles to $3 billion and IBM buys AuthMind for agent identity

LangChain raised $300 million led by Alphabet's CapitalG, more than doubling its valuation to $3 billion on the strength of its LangSmith suite for building and monitoring agents. IBM is acquiring AuthMind to add runtime visibility into how agents use credentials and secrets inside HashiCorp Vault, including detection of unsanctioned shadow agents. PitchBook also lists Kindo raising $30 million for agent management, Nebuly raising $21 million to measure the return on agents, and inference cloud Luminal raising $25 million. Capital is flowing to the control layer that makes agents governable in production.
