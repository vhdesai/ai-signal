# At BoxWorks 2026, Box launched Box Content Retrieval

At BoxWorks 2026, Box launched Box Content Retrieval. Built on Nvidia's Nemotron Retriever embedding models, it turns unstructured enterprise content into a permission-aware knowledge base for AI agents. Box claims 20% better search accuracy, up to 90% lower token consumption and about 4x faster agent responses. It also announced a multistep workflow orchestrator and threat detection for rogue agents.
