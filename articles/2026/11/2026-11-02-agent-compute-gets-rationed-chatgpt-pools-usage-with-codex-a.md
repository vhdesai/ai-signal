# Agent compute gets rationed: ChatGPT pools usage with Codex as Musk throttles Grok Bot

OpenAI is merging ChatGPT's Chat and Work tabs, and ChatGPT and Codex will now draw from one shared usage allowance, so heavy users may hit limits sooner. Elon Musk said Grok Bot's serving costs were unsustainably high relative to revenue after users found weekly limits exhausted without warning.
