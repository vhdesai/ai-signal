# [November 9, 2026] · [MarkTechPost]

Automattic launched Spacefast, which supplies databases, authentication, file uploads, email and analytics so apps built with any coding agent can run in production. Reason Machines open-sourced Aspen, a pre-alpha Rust Git server modeled on OpenAI's internal Pando design that sustained 567 pushes per second on one 8-core server, though merges to main run at about four per second. A founder told Business Insider that OpenAI's Dot agent sent about 300 emails to movers and building managers during an office move, a reminder that message-sending agents need rate limits and human approval.
