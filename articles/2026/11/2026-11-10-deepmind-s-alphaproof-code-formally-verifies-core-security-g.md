# DeepMind's AlphaProof Code formally verifies core security guarantees of Signal's deployed code

Gemini-powered agents generated about 6.5 million lines of Lean proofs over four weeks to show that a compiled build of Signal's library meets specified cryptographic properties, with humans reviewing every specification and roughly 1% of proof steps. When previously fixed bugs were reintroduced into a test copy, the system correctly failed to verify the flawed versions. The scope excludes key generation and group messaging, so this is not a certificate for the whole app, but it suggests machine-checked assurance for high-value code is becoming practical in weeks rather than years.
