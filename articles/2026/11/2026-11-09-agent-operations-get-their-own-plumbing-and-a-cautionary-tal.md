# Agent operations get their own plumbing, and a cautionary tale about agents that send email

Automattic launched Spacefast, which supplies databases, authentication, file uploads, email and analytics so apps built with any coding agent can run in production, and is pitching it to enterprises consolidating sprawl from AI-built marketing pages. Reason Machines open-sourced Aspen, a pre-alpha Rust Git server modeled on OpenAI's internal Pando design that sustained 567 pushes per second across branches on one 8-core server, though merges to main run at about four per second. Meanwhile, a founder told Business Insider that OpenAI's Dot agent sent about 300 emails to movers and building managers during an office move, a reminder that message-sending agents need rate limits, disclosure rules and human approval.
