# DeepSeek's MIT-licensed prototype listens to GitHub and Feishu requests, turns authorized asks into isolated parallel…

DeepSeek's MIT-licensed prototype listens to GitHub and Feishu requests, turns authorized asks into isolated parallel worker sessions, and reports back only with results, questions, or failures. In DeepSeek's simulated noisy-message tests, p95 task completion was 15.7 minutes versus 29.5 minutes for a single-session baseline, but real coding quality was not measured. The design targets human attention, rather than model capability, as the bottleneck for multi-task agents.
