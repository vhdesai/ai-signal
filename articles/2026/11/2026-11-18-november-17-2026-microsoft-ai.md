# [November 17, 2026] · [Microsoft AI]

At Ignite, Microsoft introduced new MAI models for coding, image generation, transcription and cyber defense, with MAI Code 2 and Code 2 Flash live in GitHub Copilot. It will license model weights so customers can build customized versions with their own data, a step neither OpenAI nor Anthropic offers. Commercial chief Judson Althoff claimed everything you can do in Claude or ChatGPT you can do better in Copilot for less, alongside new agent-oversight tools and isolated Azure hosting for agents.
