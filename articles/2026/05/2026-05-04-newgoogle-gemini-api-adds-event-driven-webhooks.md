# NEWGoogle Gemini API adds event-driven webhooks

Gemini API now supports webhook callbacks for long-running and event-driven workflows, eliminating the need for client-side polling on async generation jobs and agent runs. The addition closes a meaningful gap with OpenAI's Responses API and AWS Bedrock for production agent deployments.
