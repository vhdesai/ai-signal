# Snowflake targets AI agent adoption with AWS deal and Natoma acquisition

Snowflake is pushing toward the “agentic enterprise” with expanded AWS commitments, additional compute and governance capabilities, and a plan to acquire Natoma, a Model Context Protocol platform. The move highlights how the data layer is becoming a strategic control point for enterprise agents: orchestration matters, but governed access to enterprise context may matter more. AAPLTI
