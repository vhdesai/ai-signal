# Microsoft Agent 365 Generally Available

Microsoft Agent 365 became generally available on May 2, extending enterprise identity, security, and governance tooling to AI agents across Microsoft 365 environments. The platform enables organizations to deploy, manage, and govern AI agents with the same compliance controls applied to human workers. It represents Microsoft's answer to the enterprise agentic orchestration layer, directly competing with Anthropic's Claude Agent SDK and OpenAI's Workspace Agents for Teams. 💼 Industry News & Deals
