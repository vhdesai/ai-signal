# Perplexity launches Brain, a self-improving memory system for agent work

Perplexity launched Brain, described as a memory system that builds a context graph from an agent’s work and updates over time. The product direction is important because persistent memory is becoming a key differentiator for agentic workflows, but it also raises governance questions around retention, provenance, and user control. Executives should view this as part of the shift from single-session assistants toward systems that accumulate operational context.
