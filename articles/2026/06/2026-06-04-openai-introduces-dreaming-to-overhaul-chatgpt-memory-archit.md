# OpenAI Introduces "Dreaming" to Overhaul ChatGPT Memory Architecture

OpenAI began rolling out "Dreaming," a major upgrade to ChatGPT's memory system that processes and consolidates user context in the background — analogous to how sleep consolidates human memory. The v3 architecture enables fresher, more personalized responses by continuously reorganizing stored context. OpenAI says it cut memory-synthesis compute cost by roughly 5×, making enhanced memory viable for free users. Launching first to Plus and Pro users in the US.
