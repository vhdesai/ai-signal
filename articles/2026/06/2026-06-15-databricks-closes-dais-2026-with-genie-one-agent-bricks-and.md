# Databricks Closes DAIS 2026 With Genie One, Agent Bricks, and Unity AI Gateway GA

Databricks' Data+AI Summit concluded at Moscone Center with its highest-density agentic platform announcement slate to date. Key GAs: Genie One (agentic coworker integrating Google Drive, Jira, Slack, Confluence, SharePoint); Agent Bricks (horizontal autoscaling agent runtime supporting Claude Code SDK, LangGraph, and OpenAI Agent SDK); Unity AI Gateway (governance and cost control); and Genie Ontology (self-improving context layer). The announcements represent Databricks' most direct move into enterprise AI operations, competing with Microsoft Fabric, Snowflake Cortex, and standalone orchestration vendors. Tags: INFRASTRUCTURE
