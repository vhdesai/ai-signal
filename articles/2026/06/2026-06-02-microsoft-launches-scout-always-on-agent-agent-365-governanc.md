# Microsoft Launches Scout Always-On Agent, Agent 365 Governance, and Surface RTX Spark Dev Box

Microsoft launched Scout, the first of a new "Autopilots" class of always-on autonomous agents, built on the open-source OpenClaw project and grounded in Work IQ across Teams, Outlook, OneDrive, and SharePoint. Each agent receives its own managed Entra identity, while Agent 365 and Microsoft IQ give IT teams governance and context layers for agent fleets. In hardware, Jensen Huang joined Satya Nadella to announce the Surface RTX Spark Dev Box—a compact desktop delivering up to 1 petaflop with 128GB unified memory, capable of running 120B-parameter models locally. Microsoft also confirmed its Maia 200 accelerator is live in Iowa and Arizona data centers. Scout is available immediately to Frontier-program customers.
