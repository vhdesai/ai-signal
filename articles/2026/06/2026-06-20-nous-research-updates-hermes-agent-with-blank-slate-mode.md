# Nous Research updates Hermes Agent with Blank Slate mode

Nous Research updated Hermes Agent with a Blank Slate setup mode that starts with most capabilities disabled and lets users explicitly enable toolsets. This is a useful governance pattern for agents: restrict defaults, then opt in to tools and permissions as needed. The direction aligns with enterprise requirements for least-privilege agent design and auditable tool access.
