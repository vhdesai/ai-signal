# Microsoft Build 2026: Scout Agent, Project Solara, and Frontier Tuning

Microsoft's Build keynote delivered three headline product announcements. Scout is an always-on personal AI agent — built on the open-source OpenClaw project and grounded in Work IQ — that operates across Windows, mobile, and web with its own managed Entra identity. Project Solara is an Android-based OS designed for AI agent gadgets that run agents instead of apps. Frontier Tuning allows enterprises to customize models on their own data without fine-tuning infrastructure. Agent 365 and Microsoft IQ give IT teams governance layers for fleet management.
