# Cisco AI introduces FAPO for pipeline-aware prompt optimization

Cisco Foundation AI introduced FAPO, described as an automated prompt-optimization system for multi-step LLM pipelines with step-level failure attribution and Claude Code orchestration. The notable idea is moving prompt engineering from manual iteration toward measured, pipeline-aware optimization. If the approach holds up in production, it could reduce operational friction in agentic workflows where failures often occur at intermediate steps rather than final outputs.
