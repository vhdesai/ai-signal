# Multiple developers reported markedly different performance from ChatGPT and Codex this week, fueling speculation that…

Multiple developers reported markedly different performance from ChatGPT and Codex this week, fueling speculation that OpenAI is A/B testing GPT-5.6 under the GPT-5.5 Pro label. Users noted significantly improved web design outputs, longer generation times (suggesting a larger model), and enhanced 3D game development capabilities. Prediction markets and leaks point to a possible June 23 formal release, though OpenAI has not confirmed.
