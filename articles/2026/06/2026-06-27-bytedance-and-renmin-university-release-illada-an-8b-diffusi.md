# ByteDance and Renmin University release iLLaDA, an 8B diffusion language model

Researchers at ByteDance and Renmin University released iLLaDA, an 8-billion-parameter masked-diffusion LLM trained from scratch on 12T tokens that refines tokens in parallel rather than left-to-right. iLLaDA-Base edges autoregressive Qwen2.5 7B on average (63.9 vs. 63.3), leading on MMLU, BBH, ARC-C and GSM8K, though the instruction-tuned variant still trails on math and code without RL alignment. The release adds momentum to diffusion-based text generation as a credible alternative architecture. Infrastructure INFRA
