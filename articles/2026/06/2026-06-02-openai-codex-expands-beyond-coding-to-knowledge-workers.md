# OpenAI Codex Expands Beyond Coding to Knowledge Workers

Axios reports that OpenAI's Codex—originally a developer-focused coding tool—is being embraced by office workers for research, report generation, and spreadsheet tasks. The expansion signals OpenAI's push to reposition Codex as a general-purpose autonomous work agent, not just a code assistant. If adoption holds, it represents a meaningful broadening of OpenAI's enterprise TAM beyond the developer segment.
