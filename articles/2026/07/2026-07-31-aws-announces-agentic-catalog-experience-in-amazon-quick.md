# AWS announces agentic catalog experience in Amazon Quick

AWS announced a preview of an agentic catalog experience in Amazon Quick that lets data curators use natural language to discover and onboard assets from AWS Glue Data Catalog and Databricks Unity Catalog. The workflow creates datasets and topics while inheriting metadata and governance context from upstream catalogs. This is a concrete example of agentic AI moving into enterprise data operations, where accuracy, lineage, and governance are core adoption constraints.
