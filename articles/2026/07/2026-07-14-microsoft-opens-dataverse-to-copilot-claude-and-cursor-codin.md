# Microsoft opens Dataverse to Copilot, Claude, and Cursor coding agents

Microsoft shipped a Dataverse plugin for GitHub Copilot, Claude, and Cursor, embracing rival agents on its own data platform. The move reinforces multi-agent interoperability as an enterprise expectation and suggests Microsoft is prioritizing workflow and data-platform control over exclusivity to one assistant. For customers, it lowers friction for using multiple coding agents against shared enterprise data.
