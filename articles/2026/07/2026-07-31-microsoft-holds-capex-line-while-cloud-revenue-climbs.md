# Microsoft holds capex line while cloud revenue climbs

CIO Dive reported that Microsoft executives framed the company's existing data-center investment posture as sufficient while cloud revenue continues to rise. In a market newly focused on AI capex discipline, the message stood out because Microsoft did not raise its spending forecast even as investors rewarded cloud growth.
