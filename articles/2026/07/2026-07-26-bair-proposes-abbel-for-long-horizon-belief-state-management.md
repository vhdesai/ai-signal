# BAIR proposes ABBEL for long-horizon belief-state management

BAIR researchers introduced ABBEL, a framework that trains language models to maintain compact natural-language belief states instead of repeatedly summarizing full interaction histories. The work targets a practical failure mode in long-horizon agents: context compaction can save tokens but degrade performance by dropping information needed later. ABBEL's belief grading improved collaborative coding performance while reducing context load, making it relevant to enterprise agents that must work across long tasks without losing state.
