# XBOW’s autonomous security agent finds two critical Bing Images RCEs (CVSS 9.8)

XBOW’s autonomous offensive-security agent uncovered two critical remote-code-execution flaws in Bing Images (CVE-2026-32194 and CVE-2026-32191), each rated CVSS 9.8 and exploitable without authentication; a crafted one-pixel SVG escaped ImageMagick’s handler to run commands as SYSTEM on Windows and root on Linux in Bing’s production fleet. Microsoft fixed both server-side. Signal: AI agents are now discovering — and weaponizing — critical vulnerabilities at machine speed, raising the stakes for both offense and defense.
