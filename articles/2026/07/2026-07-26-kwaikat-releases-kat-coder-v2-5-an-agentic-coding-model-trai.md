# KwaiKAT releases KAT-Coder-V2.5, an agentic coding model trained in 100,000+ repository environments

KwaiKAT (Kuaishou) released KAT-Coder-V2.5, an agentic coding model trained inside more than 100,000 verifiable, executable repository environments in the SWE-bench lineage. The team reports topping the “PinchBench” benchmark with a 94.9 score and has published an open-weight KAT-Coder-V2.5-Dev variant on Hugging Face under Apache-2.0. Benchmark figures are self-reported and not yet independently replicated.
