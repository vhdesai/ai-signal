# KwaiKAT releases KAT-Coder-V2.5 trained on 100,000+ repository environments

MarkTechPost reports that KwaiKAT released KAT-Coder-V2.5, an agentic coding model trained on more than 100,000 verifiable repository environments. The release reflects the increasing use of repository-scale, execution-verifiable environments to train coding agents, rather than relying only on static code datasets. If the approach generalizes, coding-agent competition will increasingly depend on environment quality and evaluation loops, not just base model size.
