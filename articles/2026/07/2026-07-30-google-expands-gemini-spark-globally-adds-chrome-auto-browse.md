# Google Expands Gemini Spark Globally, Adds Chrome "Auto Browse" for Agentic Web Tasks

Google expanded Gemini Spark worldwide and introduced Chrome auto-browse, which can complete multi-step tasks using saved sessions and credentials. With permission, the agent can schedule appointments, begin bookings, and fill forms across sites before handing control back for sensitive actions. Google says it hardened the system against prompt injection, but the model still raises serious questions about account scope and session security. Because Chrome is already the dominant browser, this is one of the biggest real-world deployments yet of consumer-facing agentic browsing. Organizations will likely need new browser policies defining which sites, credentials, and workflows AI agents may be allowed to touch. Links: Google
