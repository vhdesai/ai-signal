# DeepSeek launches upgraded V4-Flash API with big agent gains

DeepSeek officially released the lightweight DeepSeek-V4-Flash-0731 (284B total / 13B active), citing large agentic gains that it says surpass its V4-Pro preview (DSBench Full-Stack 68.7; DSBench-Hard 59.6). The update adds OpenAI/Codex compatibility to ease migration of agent applications and debuts DeepSeek's own execution “Harness.” The figures are per DeepSeek's own release notes.
