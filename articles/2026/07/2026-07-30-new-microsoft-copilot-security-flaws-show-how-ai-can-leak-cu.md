# New Microsoft Copilot security flaws show how AI can leak customer secrets

The Information reported new Microsoft Copilot security flaws that show how enterprise AI systems can expose customer secrets when connected to corporate data and workflows. The broader issue is not specific to one assistant: retrieval, permissions, prompt injection, and agent actions can combine into leakage paths that traditional application security controls were not designed to catch. Enterprises deploying copilots should treat data-bound AI as a privileged software surface requiring identity, logging, red-teaming, and least-privilege enforcement.
