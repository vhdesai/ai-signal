# 28.9M-Parameter LLM Now Runs Locally on an $8 ESP32 Microcontroller

A developer ran a 28.9M-parameter TinyStories model entirely on an ESP32-S3 (~$8, 512KB SRAM), generating text at ~9.5 tokens/sec with nothing sent to a server. Uses per-layer embeddings in flash to pack more capacity onto the device. A pointed reminder that useful edge inference is migrating onto commodity, sub-$10 hardware.
