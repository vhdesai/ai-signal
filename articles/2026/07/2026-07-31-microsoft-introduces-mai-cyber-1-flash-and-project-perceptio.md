# Microsoft introduces MAI-Cyber-1-Flash and Project Perception

Microsoft announced MAI-Cyber-1-Flash, its first dedicated AI cybersecurity model, along with Project Perception, an agentic security platform. Microsoft says the model is designed to handle most security tasks efficiently while routing harder cases to more expensive frontier systems, and claims strong benchmark performance and cost reductions versus prior MDASH configurations. The launch is strategically important because it shows Microsoft moving from general-purpose copilots toward vertical, workload-specialized AI models in security.
