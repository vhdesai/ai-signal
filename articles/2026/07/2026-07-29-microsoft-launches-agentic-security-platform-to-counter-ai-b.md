# Microsoft launches agentic security platform to counter AI-based attacks

CIO Dive reported that Microsoft launched an agentic security platform designed to combat AI-based attacks. The launch comes amid rising concern that attackers can use autonomous methods to scale campaigns and evade traditional controls. Security remains one of the clearest enterprise use cases for agentic AI because defenders need automation that can match AI-enabled threat speed.
