# Nvidia locks down SK Hynix memory supply in a deal potentially worth ~$500B

Nvidia moved to secure high-bandwidth memory (HBM) supply from SK Hynix as part of a partnership that could be worth up to $500 billion over several years, announced late Friday at a San Francisco AI summit. The arrangement helps insulate Nvidia from a worsening global memory shortage and includes large data-center builds, with SK Telecom set to build a cloud on Nvidia’s Vera Rubin systems. Nvidia’s own newsroom corroborated the “$500-billion-plus” SK Group tie-up.
