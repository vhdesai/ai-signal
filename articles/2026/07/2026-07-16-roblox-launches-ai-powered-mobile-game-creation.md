# Roblox launches AI-powered mobile game creation

Roblox announced Build, a mobile feature that turns text prompts into basic games using open-source and proprietary Roblox models. The company says Build handles gameplay mechanics, environments, characters, style, and sound, with public alpha testing beginning in New Zealand. The launch shows generative AI moving into end-user creation platforms, while also raising quality-control and creator-economy concerns around AI-generated game volume.
