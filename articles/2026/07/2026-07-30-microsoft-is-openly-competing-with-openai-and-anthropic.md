# Microsoft is openly competing with OpenAI and Anthropic

TechCrunch reports that Microsoft is now more openly pitching its own AI models, harnesses, chips, and cybersecurity tools as alternatives to services being built by OpenAI and Anthropic. Satya Nadella told analysts that enterprises should keep harnesses, memory, and context separate from any one model so models remain swappable. The strategic message is that Microsoft wants to own the enterprise AI control plane even while it continues to invest in leading frontier labs.
