# Microsoft FQ4: Azure +43%, crosses $100B run rate, 30M+ Copilot seats

Microsoft reported about $90.0B in revenue (+18%), with Azure and cloud up 43% and full-year Azure passing $100B for the first time. It cited 30M+ paid Copilot seats, with net income lifted partly by a gain on its Anthropic stake. Shares rose about 7% after hours; the company guided to roughly 45% Azure growth next quarter and disclosed $130B+ in new data-center leases signed during the quarter.
