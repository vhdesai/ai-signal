# Anthropic ships MCP 2026-07-28 spec: stateless core, hardened auth, standardized extensions

Anthropic released the fifth Model Context Protocol spec, moving MCP from a stateful, bidirectional protocol to a stateless request/response core so servers can run on serverless and edge infrastructure. It graduates MCP Apps and Tasks into a versioned extensions framework and aligns authorization with production OAuth 2.0/OIDC (e.g., Entra, Okta). With MCP past 400M monthly SDK downloads (4x this year) and 950+ servers listed in Claude, the release further cements MCP as the de facto integration standard for agents.
