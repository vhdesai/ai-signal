# 28.9M-parameter LLM runs locally on an $8 ESP32 microcontroller

A public GitHub project demonstrates TinyStories running locally on an ESP32-S3 microcontroller with about 512 KB of SRAM, achieving roughly 9.5 tokens per second without sending data to a server. It points to useful local inference migrating onto commodity sub-$10 edge devices.
