# Meituan open-sources LongCat-2.0, a 1.6-trillion-parameter agentic-coding model

Meituan released LongCat-2.0, a Mixture-of-Experts model with 1.6 trillion total parameters (~48B active per token) and a native 1M-token context window, positioned specifically for agentic coding. Meituan says the model completed its full training and inference lifecycle on a 50,000-card domestic GPU cluster and ships with inference code optimized for Chinese accelerators. Open-weighted on GitHub and Hugging Face, it extends the pattern of Chinese labs shipping frontier-scale open models tuned for developer and agent workloads while reducing Nvidia dependency.
