# SonicWall joins Anthropic's Project Glasswing to test Claude Mythos 5 for defense

SonicWall confirmed it is participating in Anthropic's opt-in Project Glasswing program and is testing Claude Mythos 5 — Anthropic's vetted-access cybersecurity model — for defensive security work. The disclosure is an early, named example of enterprise security vendors operationalizing frontier models under controlled-access programs. It reinforces a broader pattern this week of AI-and-cybersecurity convergence, from Microsoft's dedicated cyber model to gated defensive-model pilots.
