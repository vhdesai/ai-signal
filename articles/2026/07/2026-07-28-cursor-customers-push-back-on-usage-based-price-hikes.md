# Cursor customers push back on usage-based price hikes

Cursor customers are reportedly pushing back on large renewal increases as the AI coding company moves more accounts toward usage-based pricing. Buyers are comparing Cursor with Claude Code and open-source harnesses as procurement teams scrutinize per-seat and usage economics. The broader signal is that AI coding tools are entering a normalization phase in which adoption alone is no longer enough; cost predictability matters.
