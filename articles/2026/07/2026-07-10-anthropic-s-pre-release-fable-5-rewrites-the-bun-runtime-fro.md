# Anthropic's Pre-Release "Fable 5" Rewrites the Bun Runtime from Zig to Rust — ~1M Lines in 11 Days

Bun creator Jarred Sumner (now at Anthropic) used a pre-release Claude "Fable 5" to port Bun's ~960,000-line codebase from Zig to Rust, running ~64 parallel instances over 11 days at ~$165,000 in API cost — work estimated at ~1 year of engineer time. The Rust port reportedly reached ~99.8% test compatibility on Linux x64. One of the largest public demonstrations of AI-driven software migration to date.
