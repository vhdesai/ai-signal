# UK CMA investigates Microsoft over Copilot-linked Microsoft 365 price hikes

Britain's Competition and Markets Authority is probing whether Microsoft clearly disclosed changes to consumer Microsoft 365 plans that bundled Copilot and renewed at higher prices. Microsoft said it will cooperate with the inquiry. The case is an early regulatory test of how AI features are packaged and priced for consumers.
