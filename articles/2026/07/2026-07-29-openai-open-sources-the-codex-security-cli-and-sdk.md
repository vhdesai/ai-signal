# OpenAI open-sources the Codex Security CLI and SDK

OpenAI released an open-source Codex Security CLI and TypeScript SDK under Apache-2.0 (install via npm i @openai/codex-security). The tool scans repositories, validates vulnerabilities, generates patches, tracks findings, and adds security gates to CI/CD pipelines. OpenAI described it as an early beta and is actively soliciting developer feedback.
