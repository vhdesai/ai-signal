# AWS, CrowdStrike, and Cerebras push AI-native security controls

AWS's latest Security Hub updates reposition it as an AI-aware, multicloud security control plane, acknowledging that AI is now the fastest-growing attack surface for customers. Separately, CrowdStrike and Cerebras announced a partnership to run AI-powered threat detection and response on Cerebras's high-speed inference infrastructure. Together, the moves show cybersecurity becoming a first vertical where AI agents, low-latency inference, and cross-cloud control planes converge.
