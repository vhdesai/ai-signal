# JetBrains Research open-sources KotlinLLM, an IntelliJ plugin with runtime “Smart macros”

JetBrains Research open-sourced KotlinLLM (Apache-2.0), an IntelliJ IDEA plugin that adds “Smart macros” whose bodies are LLM-generated Kotlin source rather than live model calls. The plugin captures runtime values via the JVM Debug Interface, asks an agent for a narrow code update, compiles it and hot-reloads the class so covered paths run as plain Kotlin. On an adapted Spring Petclinic project it reported 24/24 scenarios with 100% hot-reload success and about 1% runtime overhead.
