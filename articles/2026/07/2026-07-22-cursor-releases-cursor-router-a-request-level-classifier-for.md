# Cursor releases Cursor Router, a request-level classifier for cheaper frontier-quality coding

Cursor made Cursor Router generally available for Teams and Enterprise plans — a classifier trained on more than 600,000 live requests that inspects each request and dispatches it to the best-suited model. Cursor reports frontier-quality output at roughly 60% savings in online A/B tests and 30–50% savings for early-access enterprise accounts. The launch reflects a broader shift toward request-level model routing to control agentic-coding costs.
