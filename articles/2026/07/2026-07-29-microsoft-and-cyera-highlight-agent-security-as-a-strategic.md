# Microsoft and Cyera highlight agent security as a strategic enterprise category

Microsoft launched an agentic security platform designed to counter AI-based attacks, while Cyera agreed to acquire Oasis Security for about $1 billion to secure non-human identities, including AI agents. Together, the announcements show enterprise security shifting from human identity and data loss controls toward agent permissions, behavior monitoring, and automated defense. Security remains one of the clearest high-value use cases for agentic AI because defenders need automation that can match AI-enabled attack speed.
