# Nadella previews a unified Copilot "super app" spanning chat, Cowork, autopilot and code

On Microsoft's earnings call, Satya Nadella said the company will fold Copilot's chat, Cowork, agentic "autopilot," and GitHub Copilot coding features into a single flagship "super app" launching later in 2026. The stated aim is a consistent experience across roles as Copilot evolves "from chat to Cowork to Autopilots." Consolidation could simplify licensing and adoption, but it also deepens dependence on the Microsoft AI stack. Infrastructure INFRASTRUCTURE
