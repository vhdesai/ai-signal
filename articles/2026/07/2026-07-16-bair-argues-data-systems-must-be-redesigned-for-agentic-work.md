# BAIR argues data systems must be redesigned for agentic workloads

BAIR researchers published a perspective on how near-zero inference costs could make AI agents dominant workloads for data systems. The post frames three directions: systems for agents, systems of agents, and systems by agents, including support for agentic speculation, shared query work, memory, coordination, and verification. The executive implication is that the database and data-platform layer may need redesign as AI agents create high-volume, exploratory, and redundant query patterns.
