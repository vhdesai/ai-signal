# Microsoft reportedly prepares Mythos-like AI bug finder

The Information reports that Microsoft is preparing a Mythos-like AI bug finder. The effort follows Microsoft's record Patch Tuesday volume and wider industry movement toward AI-assisted vulnerability discovery. If successful, the tool would deepen AI's role in secure software development and could shift vulnerability discovery from episodic audits toward continuous automated testing.
