# AI memory shortage puts pressure on governments to act

A global shortage of AI memory, including high-bandwidth memory and advanced DRAM, is escalating into a geopolitical issue as countries move to secure domestic supply. Memory has become a gating constraint for AI system throughput, adding a second bottleneck alongside logic chips. The shortage could intensify state intervention, industrial policy, and export-policy maneuvering.
