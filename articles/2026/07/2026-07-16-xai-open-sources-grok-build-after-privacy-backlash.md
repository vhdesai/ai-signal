# xAI open-sources Grok Build after privacy backlash

xAI published the source for Grok Build, its terminal-based coding agent, on GitHub so developers can inspect the agent loop, tool calls, and context assembly. The move follows criticism that the assistant uploaded more repository data than users expected. It is a transparency play amid a broader trust stress test for AI coding tools, and it gives the open-source community a reference implementation of a production coding agent.
