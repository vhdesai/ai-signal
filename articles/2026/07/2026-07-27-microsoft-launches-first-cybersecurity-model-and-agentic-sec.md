# Microsoft launches first cybersecurity model and agentic security platform

Microsoft introduced MAI-Cyber-1-Flash, its first cybersecurity-specialized model, and Perception, an agentic security platform for detecting, triaging, and remediating vulnerabilities. Microsoft says the model, used with its MDASH harness, outperforms competing cyber models on CyberGym while lowering cost.
