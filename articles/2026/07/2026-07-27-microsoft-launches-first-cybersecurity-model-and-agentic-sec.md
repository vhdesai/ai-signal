# Microsoft launches first cybersecurity model and agentic security platform

Microsoft introduced MAI-Cyber-1-Flash, its first cybersecurity-specialized model, and Perception, an agentic security platform for detecting, triaging, and remediating vulnerabilities. Microsoft says the model, used with its MDASH harness, outperforms competing cyber models on CyberGym while lowering cost. The release shows major platform vendors treating AI security as a specialized model-and-agent stack, not just a feature inside existing security products.
