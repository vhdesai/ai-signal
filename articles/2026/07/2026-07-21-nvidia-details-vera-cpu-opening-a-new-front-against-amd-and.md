# Nvidia Details Vera CPU, Opening a New Front Against AMD and Intel

Nvidia published specs for Vera, its first server CPU designed from the core rather than off-the-shelf Arm IP, claiming 50% better AI-agent performance than x86 and up to 1.5TB of low-power memory per chip. Already shipped in June to OpenAI, Anthropic, and SpaceX, with OpenAI planning volume deployment this quarter. Directly challenges AMD and Intel's CPU businesses.
