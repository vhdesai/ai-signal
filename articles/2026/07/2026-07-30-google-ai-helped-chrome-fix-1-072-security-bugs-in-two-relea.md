# Google AI Helped Chrome Fix 1,072 Security Bugs in Two Releases

Google said AI agents helped Chrome fix 1,072 security bugs across versions 149 and 150, more than the prior 23 milestones combined. The work covered discovery, triage, patching, and test generation, showing end-to-end automation rather than isolated code suggestions. One AI-found bug was a 13-year-old sandbox escape that had survived human review for more than a decade. The result strengthens the case that defenders must automate remediation because AI is accelerating vulnerability discovery on both sides. For security teams, the looming challenge is not just finding more flaws, but absorbing and fixing them without drowning in operational noise. Links: BleepingComputer
