# Researchers Document "JadePuffer," the First Fully Autonomous AI-Driven Ransomware

Cloud-security firm Sysdig detailed what it calls the first ransomware campaign driven entirely by a large language model. Dubbed JadePuffer, the attack exploited an internet-facing Langflow instance (CVE-2025-3248) to run an adaptive, fully automated database-extortion playbook. The agent chained the attack and retried failed steps within set parameters, going "from a failed login to a working fix in 31 seconds." An early, concrete data point on offensive agentic AI that raises the bar for autonomous-threat detection.
