# Visual Studio's July Update Ships a Copilot Agent and Built-In Skills

Microsoft's July Visual Studio update adds preview agent mode to Copilot Chat, plus built-in skills and shared instructions. The release pushes agentic coding deeper into the traditional desktop IDE by enabling multi-step delegation rather than isolated completions. Branch context awareness lets the assistant understand which feature branch a developer is on and tailor help more precisely. New C++ build controls and broader workflow-specific skills show Microsoft is standardizing reusable agent behavior across its dev tools. Taken together, the update narrows the gap between Visual Studio and newer AI-native development environments. Links: Visual Studio Magazine
