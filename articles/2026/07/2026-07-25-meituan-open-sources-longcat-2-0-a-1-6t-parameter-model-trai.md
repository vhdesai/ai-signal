# Meituan open-sources LongCat-2.0, a 1.6T-parameter model trained on domestic GPUs

LongCat-2.0 is a mixture-of-experts model with 1.6 trillion total parameters (~48B active per token), native 1-million-token context, and tuning for agentic coding. Meituan says it is the first trillion-parameter model trained and served entirely on a domestic ~50,000-card cluster, with inference code optimized for local hardware. Signal: another data point in China’s push for compute sovereignty and open-weight competitiveness independent of Nvidia.
