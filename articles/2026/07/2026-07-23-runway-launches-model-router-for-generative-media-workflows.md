# Runway launches model router for generative media workflows

Runway launched Media Router, a developer tool that automatically chooses image, video, or audio generation models based on quality, speed, or cost preferences. The company is positioning itself as infrastructure for generative media rather than only a model provider, with customers able to access Runway and third-party models through API workflows. The move mirrors LLM model routing and suggests media generation will become a multi-model orchestration problem.
