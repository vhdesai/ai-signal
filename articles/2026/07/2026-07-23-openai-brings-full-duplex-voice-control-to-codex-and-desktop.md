# OpenAI brings full-duplex voice control to Codex and desktop ChatGPT

VentureBeat reports that OpenAI is bringing GPT-Live's full-duplex voice control to Codex and ChatGPT on desktop, enabling hands-free agentic coding workflows. The product direction matters because developer tools are moving from command-line or chat-only experiences toward interactive, multimodal collaboration loops. If reliable, voice-controlled coding agents could change how developers specify, monitor, and redirect long-running software tasks.
