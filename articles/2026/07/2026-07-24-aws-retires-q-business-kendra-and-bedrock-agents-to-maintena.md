# AWS Retires Q Business, Kendra, and Bedrock Agents to Maintenance Mode

AWS is retiring several first-generation AI services ~2 years after launch, reflecting a fast reset toward newer agent frameworks. Buyers running production workloads should plan migration paths now. The churn is a caution against over-committing to any single vendor's rapidly evolving AI primitives.
