# Anthropic discloses a Claude Cowork sandbox-escape flaw on macOS

The Next Web reports a flaw in Anthropic's Claude Cowork that could let the agent escape its local virtual machine and read credentials and files outside its sandbox on macOS. The disclosure lands amid heightened scrutiny of agentic-AI containment following the OpenAI evaluation breach earlier in the week. It is a concrete reminder that agent sandboxing remains an unsolved security surface as coding and agent tools gain broader system access.
