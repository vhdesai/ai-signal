# Anthropic’s unreleased “Claude Mythos” model discovers two novel cryptographic attacks

Anthropic reported that its unreleased Claude Mythos Preview model, running for roughly 60 hours, uncovered two previously unknown cryptographic attacks. It exploited a lattice automorphism in HAWK — a NIST post-quantum signature candidate — to cut small-key security from 2^64 to 2^38, and introduced a “Möbius Bridge” technique that speeds the best known 7-round AES-128 attack by 200–800x. No deployed system is broken; each discovery cost about $100K in API usage, and Anthropic followed responsible disclosure. The result is an early, concrete demonstration of frontier models contributing original security research.
