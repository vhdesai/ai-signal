# Microsoft confirms a unified Copilot “super app” is coming this year

Microsoft confirmed it will launch a unified Copilot app this year that combines conversational AI, coding assistance and autonomous agents in a single surface. The move consolidates today's fragmented Copilot experiences into one agentic app. It signals Microsoft's intent to make Copilot the default entry point across consumer and enterprise workflows.
