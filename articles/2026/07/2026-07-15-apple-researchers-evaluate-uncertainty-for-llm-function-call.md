# Apple researchers evaluate uncertainty for LLM function-calling safety

Apple researchers published an evaluation of uncertainty quantification methods for LLM function calling, where incorrect tool calls can have irreversible consequences such as transferring money or deleting data. The work finds that function-calling outputs require different uncertainty techniques than natural-language Q&A, including syntax-aware clustering and more targeted token scoring. This is directly relevant to enterprise agent deployment, where confidence estimation can act as a gate before high-impact actions execute.
