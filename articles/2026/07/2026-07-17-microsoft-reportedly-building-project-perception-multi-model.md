# Microsoft Reportedly Building "Project Perception" Multi-Model AI Security Tool

Microsoft is developing Project Perception, an AI security product combining Anthropic, OpenAI, and Microsoft models to scan and remediate enterprise vulnerabilities. Positioned as a lower-cost alternative to Anthropic's Mythos security offering, with distribution leverage from Azure's Fortune 500 footprint. Deepens multi-model strategy while keeping rival labs as suppliers rather than direct competitors in enterprise security.
