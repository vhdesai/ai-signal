# Cursor patches a high-severity Git remote-code-execution flaw (CVE-2026-63093)

Cursor (Anysphere) patched a high-severity Windows vulnerability that let malicious Git repositories execute code, roughly seven months after it was first flagged. The flaw spotlights the expanding attack surface of AI coding assistants. Users are advised to update to the patched build. ________________________________
