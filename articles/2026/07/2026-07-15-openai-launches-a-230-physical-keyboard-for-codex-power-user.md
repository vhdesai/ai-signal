# OpenAI launches a $230 physical keyboard for Codex power users

OpenAI launched Codex Micro, a $230 light-up keyboard co-designed with Work Louder for managing AI coding agents. The device includes agent-status keys, configurable shortcuts, and a dial for adjusting reasoning effort. While limited-run and niche, it marks OpenAI's first shipping physical device and points to a future where agent workflows may get dedicated control surfaces rather than being confined to chat windows.
