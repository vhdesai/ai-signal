# Anthropic upgrades Claude voice mode with Opus, Sonnet, and Haiku support

Anthropic updated Claude voice mode so users can select Opus, Sonnet, or Haiku, and the assistant can connect with tools such as Gmail, Google Calendar, Slack, Canva, and Notion. TechCrunch notes that this differentiates Claude from OpenAI's voice mode by allowing more tool-mediated actions such as rescheduling meetings, drafting emails, and creating documents. The change reinforces that voice interfaces are becoming front ends for agentic work, not just conversational companions.
