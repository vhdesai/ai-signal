# Microsoft Readies "Project Perception," a Multi-Model AI Security Tool

Microsoft is preparing an AI cybersecurity product that routes vulnerability analysis, code review, and incident response to models from Microsoft, OpenAI, or Anthropic based on which performs best. Expected to launch this month and aimed partly at Anthropic's growing security influence. By spanning model families across Azure, Defender, and GitHub, Microsoft positions as the platform layer rather than a single-provider bet.
