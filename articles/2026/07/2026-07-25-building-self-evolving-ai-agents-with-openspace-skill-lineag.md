# Building self-evolving AI agents with OpenSpace, skill lineage, and MCP

A MarkTechPost tutorial walks through building “self-evolving” AI agents with OpenSpace, using a SQLite-backed skill lineage and versioning layer alongside the Model Context Protocol (MCP). It demonstrates FIX, DERIVED, and CAPTURED skill categories so agents can accumulate and cheaply reuse capabilities over time.
