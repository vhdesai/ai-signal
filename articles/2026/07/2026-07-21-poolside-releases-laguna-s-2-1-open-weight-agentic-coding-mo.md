# Poolside releases Laguna S 2.1 open-weight agentic coding model

VentureBeat reports that Poolside released Laguna S 2.1, an open-weight coding model that beats much larger rivals on software-engineering benchmarks. The model is positioned around multilingual SWE-Bench performance and agentic coding tasks, reinforcing the trend toward smaller, specialized models that compete on workflow economics rather than raw scale. If results translate to production, enterprises may increasingly route coding workloads to task-specific open models.
