# Apple proposes environment-free synthetic data generation for API-calling agents

Apple published research on generating synthetic trajectories for API-calling agents without requiring fully implemented executable environments and populated backend databases. The method uses LLMs as on-the-fly digital world models given only API specifications. If scalable, this could reduce one of the biggest bottlenecks in training enterprise agents: producing realistic, high-quality tool-use trajectories without building full simulated business systems.
