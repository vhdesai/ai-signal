# OpenAI details GPT-Red, an automated red-teamer for prompt-injection defense

OpenAI detailed GPT-Red, a system that uses self-play to discover prompt-injection attacks and adversarially harden production models. The company says GPT-5.6 Sol recorded roughly six times fewer injection failures than GPT-5.5 after this process. The work points toward models generating the attacks used to secure the next generation of models, making automated red teaming part of the model-release pipeline.
