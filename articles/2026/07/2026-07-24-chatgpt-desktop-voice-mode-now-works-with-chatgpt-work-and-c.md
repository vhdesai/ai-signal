# ChatGPT desktop voice mode now works with ChatGPT Work and Codex

TechCrunch reports that OpenAI's updated voice mode is now available in the ChatGPT desktop app and can work with ChatGPT Work and Codex to complete tasks and control agents. The release moves voice from a conversational feature toward an interface for managing work across agentic systems. If reliable, voice control could become a useful supervisory layer for long-running tasks where users need to interrupt, redirect, or approve work without staying in a text prompt loop.
