# Nvidia details Vera CPU for AI-agent workloads

Nvidia detailed Vera, its first server CPU designed from the core rather than built from off-the-shelf Arm IP, with 1.5TB of low-power memory per chip and claims of roughly 50% better AI-agent performance than x86. The chip has reportedly already shipped to OpenAI, Anthropic, and SpaceX, with volume deployment starting this quarter. Vera opens a new front against AMD and Intel by targeting latency and memory behavior in agentic workloads, not just GPU acceleration.
