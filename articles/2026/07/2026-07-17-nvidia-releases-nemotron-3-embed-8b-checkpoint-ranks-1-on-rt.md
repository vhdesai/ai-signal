# NVIDIA Releases Nemotron 3 Embed; 8B Checkpoint Ranks #1 on RTEB Retrieval Benchmark

NVIDIA published Nemotron 3 Embed, an open collection of text-embedding models whose 8B checkpoint takes the top overall spot on the RTEB retrieval benchmark. Models target production-scale RAG, agentic retrieval, and agent memory. Stronger open embeddings matter because retrieval quality — not just model size — increasingly bounds how well agentic systems perform.
