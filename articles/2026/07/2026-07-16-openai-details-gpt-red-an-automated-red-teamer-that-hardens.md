# OpenAI Details GPT-Red, an Automated Red-Teamer That Hardens Its Models

OpenAI disclosed GPT-Red, an internal automated red-teaming model that uses self-play to discover prompt-injection attacks and adversarially harden production models. GPT-5.6 Sol, trained against GPT-Red, recorded ~6× fewer direct-injection failures than GPT-5.5. Points toward a future where models generate the attacks used to secure the next generation.
