# Model Context Protocol update aims to make agent integrations easier to scale

TechCrunch reports that the Model Context Protocol is moving toward a looser, more stateless approach to session IDs on the server side. The change is technical but important: large-scale MCP servers should become easier and cheaper to operate behind load balancers and distributed infrastructure. For enterprises, this is a sign that the agent ecosystem is maturing from demos toward production integration plumbing.
