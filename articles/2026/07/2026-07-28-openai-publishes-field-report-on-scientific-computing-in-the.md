# OpenAI publishes field report on scientific computing in the agentic AI era

OpenAI published a field report on how scientists use AI coding agents to modernize scientific computing and accelerate software development in genomics and related fields. The report fits the broader trend of AI agents moving into scientific workflows where legacy code, reproducibility, and specialized tooling are major constraints. For research organizations, the opportunity is not only faster coding but faster modernization of scientific software stacks.
