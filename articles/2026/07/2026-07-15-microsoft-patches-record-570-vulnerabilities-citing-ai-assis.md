# Microsoft patches record 570 vulnerabilities, citing AI-assisted discovery

Microsoft issued patches for 570 security flaws across Windows, Office, SharePoint, and other products, a record Patch Tuesday volume. The company said AI-assisted vulnerability discovery is increasing the number of issues defenders can find, even as some vulnerabilities were already being exploited. The item is a practical signal that AI is changing software security operations by accelerating both discovery and patch-management load.
