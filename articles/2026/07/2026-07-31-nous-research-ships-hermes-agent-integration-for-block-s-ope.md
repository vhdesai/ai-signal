# Nous Research ships Hermes Agent integration for Block's open-source Nostr workspace Buzz

Nous Research released Hermes Agent support for Buzz, Block's Apache-2.0, self-hostable workspace where humans and AI agents share the same Nostr-based channels. Because every message is a signed Nostr event and each participant is a keypair, agents gain their own identity, channel memberships and audit trail, replacing the bot-token model. Three integration paths preserve Hermes memory, skills, approvals and scheduled delivery.
