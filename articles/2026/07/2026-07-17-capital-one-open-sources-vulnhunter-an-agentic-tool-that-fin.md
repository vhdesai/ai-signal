# Capital One Open-Sources VulnHunter, an Agentic Tool That Finds Code Flaws

Capital One released VulnHunter as open source — an agentic AI security tool that hunts exploitable code vulnerabilities, maps attack paths, and helps developers remediate faster. Publishing from a major regulated bank is a notable signal that enterprises treat agentic security as production-ready. Gives defenders a free alternative to commercial scanners.
