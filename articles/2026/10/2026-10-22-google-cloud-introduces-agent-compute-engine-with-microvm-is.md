# Google Cloud introduces Agent Compute Engine with microVM isolation per agent session

MarkTechPost reports Google Cloud announced Agent Compute Engine, designed to run each agent in a hardware-isolated microVM with minimal credential exposure in the sandbox. The positioning is infrastructure-grade isolation with higher agent density and resumability characteristics for long-running workflows. If broadly adopted, this could standardize stronger execution boundaries for enterprise agent platforms.
