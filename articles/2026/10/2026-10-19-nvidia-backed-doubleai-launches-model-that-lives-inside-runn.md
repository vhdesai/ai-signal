# Nvidia-backed doubleAI launches model that lives inside running code

Nvidia-backed doubleAI unveiled an AI model designed to live inside running code and reduce compute costs; early customer data reportedly showed a 67% cost reduction. The approach targets runtime optimization rather than pre-deployment code generation. If it works at scale, it could become a new category of embedded AI that continuously optimizes software as it runs.
