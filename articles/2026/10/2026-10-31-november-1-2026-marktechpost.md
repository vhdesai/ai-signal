# [November 1, 2026] · [MarkTechPost]

DeepSeek's Harness team released dsh-superagent, an MIT-licensed research prototype that listens to a GitHub repository and turns authorized requests into isolated parallel worker sessions that report back with results or pull requests. In DeepSeek's simulations, 95th-percentile task completion fell to 15.7 minutes from 29.5 minutes for a single-session agent, though real-world code quality was not measured. The design treats human attention, not model capability, as the bottleneck for scaling agent work.
