# AWS Strands Labs releases "Decider 2B" — a 115ms open-source decision model

AWS's Strands Labs quietly open-sourced "Strands Decider 2B," a two-billion-parameter decision model that selects among discrete options in roughly 115 milliseconds. MarkTechPost emphasizes the pitch is latency, not reasoning depth — enabling agent routers that pick tool calls deterministically fast. It arrives the same day AWS unveils a "Well-Architected" cloud-architect agent, hinting at a coordinated AWS push into the agent-routing and professional-services layers.
