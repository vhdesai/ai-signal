# Microsoft releases Decision-1, a Qwen3.5-9B decision-scoring model

Microsoft released Microsoft-Decision-1, a Qwen3.5-9B decision-scoring model designed to rank options rather than generate long text. The model fits a pattern across OpenAI’s Decisions API, TypeSafe’s Jev and Nace AI’s Drex: enterprises increasingly need models that make bounded, inspectable decisions inside applications. The strategic question is whether decision models become a cheaper and safer substrate for agent orchestration than general-purpose frontier models. OPEN WEIGHTS AGENTS
