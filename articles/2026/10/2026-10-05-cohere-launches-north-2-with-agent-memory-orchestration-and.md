# Cohere launches North 2 with agent memory, orchestration, and cost governance

Cohere launched North 2, adding cross-session memory, reusable skills, shared libraries, app creation, automations, enterprise connectors, and granular cost controls. The platform can run in cloud, hybrid, on-premises, or air-gapped environments, with controls for roles, model use, token spend, quotas, and agent autonomy. North 2 reflects the enterprise agent market's near-term priorities: memory and workflow depth, but with strict governance and budget controls. RECOMMENDERSGENERATIVE AI
