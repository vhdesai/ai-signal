# Microsoft Copilot in Word adds answer provenance; AWS demonstrates "trust-earned autonomy" in banking

Windows Central reports Microsoft is adding source-citation visibility to Copilot in Word, addressing a long-running enterprise trust complaint for legal, policy and executive-document workflows. AWS separately published a Texas Capital Bank case study in which an AI agent commits to a core banking ledger, detects an issue and reverses itself under a "trust-earned autonomy" pattern. Both updates point to the same enterprise requirement: agents need auditable provenance, reversible actions and confidence-building guardrails before they can touch production systems of record.
