# OpenCode breach exposes API keys and triggers unauthorized AI usage charges

OpenCode said attackers breached an older system used by its hosted Console, affecting 1.4% of Console users whose API keys were stored there; the open-source app and CLI were not affected. Users reported unauthorized charges across multiple model providers, which said they disabled exposed keys and began refund processes. The incident underscores the operational risk of centralizing provider credentials in agent platforms and the need for scoped keys, spend limits, rapid revocation, and clear incident boundaries.
