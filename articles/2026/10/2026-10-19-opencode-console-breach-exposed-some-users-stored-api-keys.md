# OpenCode Console breach exposed some users’ stored API keys

OpenCode said an older system supporting its Console was breached, affecting 1.4% of Console users whose API keys were stored in workspaces; users reported unauthorized charges. The company said its open-source application and command-line tool were not affected, while model providers disabled keys and refunds were initiated. The incident highlights the financial and operational exposure created when developer platforms retain reusable model credentials. MILITARY AI SAFETY
