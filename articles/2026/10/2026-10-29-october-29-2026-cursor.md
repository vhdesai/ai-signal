# [October 29, 2026] · [Cursor]

Cursor said a maliciously modified Claude Code extension in its marketplace attempted to install a persistent SSH backdoor, affecting at most 5,000 users, and warned that uninstalling may not remove the payload. Separately, researchers found embedded-browser flaws in Cursor, GitHub Copilot, Claude Desktop, VS Code and Codex that could allow code execution or file theft, with the Codex and VS Code issues reported unpatched. Agentic coding tools now warrant the same supply-chain controls as production dependencies.
