# AWS uses TorchNeuron to lower PyTorch migration friction to Trainium

AWS released TorchNeuron, which it says can run PyTorch applications on Trainium with a configuration change rather than a code rewrite, and plans to contribute hardware-agnostic changes upstream to PyTorch. The strategic objective is to weaken software lock-in as a barrier to alternative accelerators; actual migration effort and workload economics will determine adoption. CONSUMER AI AGENTS
