# REA connects Claude Code and Cursor to Ghidra and IDA Pro; Warden Stealer targets agent data

CyberSecurityNews reports the REA tool connects Claude Code and Cursor to Ghidra and IDA Pro, letting AI coding agents reverse engineer binaries through professional analysis tools. GBHackers separately reports Warden Stealer is targeting Claude, Codex, Grok, and Cursor data. Together, the stories show the dual-use edge of AI coding agents: defenders get stronger automation, while attackers increasingly target local prompts, credentials, and tool permissions.
