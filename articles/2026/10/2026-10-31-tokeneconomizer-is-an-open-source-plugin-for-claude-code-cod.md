# TokenEconomizer is an open-source plugin for Claude Code, Codex, GitHub Copilot CLI, and Pi that learns from prior…

TokenEconomizer is an open-source plugin for Claude Code, Codex, GitHub Copilot CLI, and Pi that learns from prior sessions in a repository. It promotes verified project facts into the prompt, prunes unused tool schemas, and stops failure loops. On 277 SWE-Bench tasks it reduced mean cost by 18.4% to 30.9% across five agent-model settings, with small accuracy trade-offs in some configurations. It is directly relevant to the CFO-level scrutiny of agentic-coding token budgets.
