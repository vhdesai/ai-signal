# Block introduced a voice model it says can run locally on high-end consumer hardware while speaking and listening…

Block introduced a voice model it says can run locally on high-end consumer hardware while speaking and listening concurrently. The positioning emphasizes natural prosody, lower latency, and reduced cloud dependency for real-time interactions. If this class of local model matures, it could materially shift cost and privacy trade-offs for voice-first enterprise workflows.
