# CIO Dive: Dev speed up, but code reviews are eating the gains; skills gaps killing projects

CIO Dive quotes Purna Doddapaneni of Bain & Co.: "The bottleneck has moved from writing code to trusting it." A Pluralsight report finds most businesses wasted $250K+ last year because expertise didn't match project aspirations. More than 67% of US companies report using AI (Pipefy survey), but few can run an orchestrated process. Yesterday's CIO Dive also tracked soaring demand for AI security training and CIO calls for AI transparency.
