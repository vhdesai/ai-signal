# OpenAI Decisions API enters public beta for typed, low-latency answers

OpenAI's Decisions API is in public beta and is designed to convert text or images into typed answers such as predicates, choices, and rubric scores. MarkTechPost reports OpenAI's claim that the endpoint is roughly 10x faster than the Responses API for supported decision workloads, with GPT-6 Luna currently the only supported model. This is another sign that major AI providers are productizing structured decision layers as first-class infrastructure for applications and agents. Infrastructure N INFRASTRUCTURE NVIDIA
