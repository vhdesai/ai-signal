# Factory's Droid 1.0 makes harness design a cost lever for coding agents

Factory's Droid 1.0 turns on programmatic tool calling by default, letting the model write a sandboxed program that drives many tool calls while keeping raw outputs out of context, and its base prompt shrank 37%. Factory reports 65.2% on Terminal-Bench 4 with Claude Opus 5.5 at $4.73 per passed task, a self-reported result. The harness, not just the model, increasingly sets agent accuracy and cost per solved task.
