# Block unveils a local full-duplex voice model for real-time interaction

TechCrunch reports Block introduced a voice model designed to speak and listen concurrently with expressive prosody. The company says it can run on consumer-grade hardware and is being evaluated with external safety researchers before broader access. If this class of model matures, it could materially reduce latency and cloud cost for voice-first workflows.
