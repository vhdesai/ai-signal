# ChatGPT desktop app can now route inference to Amazon Bedrock in AWS GovCloud

AWS says the ChatGPT desktop app is now available on Amazon Bedrock in AWS GovCloud (US). AWS published a reference deployment that sends model inference to GovCloud (US-West) using API-mode sign-in and managed device policies. This gives regulated and public-sector buyers a way to use OpenAI's client inside an AWS compliance boundary, a further sign that OpenAI distribution is going multicloud. CODING AGENTS HARNESS
