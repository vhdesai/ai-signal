# Factory releases Droid 1.0, a coding-agent harness that works with any model

Factory's Droid 1.0 makes programmatic tool calling ("script mode") the default and does not depend on a specific model. On Factory's own Terminal-Bench 4 runs, Droid scored 65.2% with Claude Opus 5.5 at $4.73 per passed task. These are vendor-run results. The more durable point is that harness design and cost per solved task are becoming the main competitive measures. COMPUTER USE OPEN SOURCE
