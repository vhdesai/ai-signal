# Microsoft open-sources Agensh, a decentralized harness tested up to 1,024 coding agents

MarkTechPost reports Microsoft Research released Agensh, which removes a central orchestrator and lets worker agents self-coordinate across shared state and repository workflows. Reported scaling tests indicate better results on hard software tasks as agent count increases, with meaningful gains at larger team sizes.
