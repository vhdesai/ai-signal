# Google, Amazon and Oracle push deeper into enterprise-agent tooling

Google Cloud introduced a refreshed modernization portfolio with AI agents for application migration, refactoring and cloud operations. Amazon hired a former Microsoft Copilot CTO to accelerate its agent buildout, reinforcing AWS’s move beyond infrastructure into enterprise-agent orchestration. Oracle added a VS Code extension for Fusion AI Studio, giving developers a direct surface for enterprise AI workflows and a response to Copilot Studio, Google Agentspace and Salesforce Agentforce.
