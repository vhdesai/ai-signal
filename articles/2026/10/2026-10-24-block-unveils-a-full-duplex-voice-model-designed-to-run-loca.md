# Block unveils a full-duplex voice model designed to run locally

TechCrunch reports Block introduced Dessa, a voice model with real-time conversational turn-taking and expressive speech behavior. The company says the model can run on consumer-grade hardware and is being assessed with external safety researchers before broader access. If validated, this could lower cost and latency for voice-first workflows in commerce and support contexts.
