# OpenAI updates ChatGPT with interactive graphics

OpenAI updated ChatGPT with interactive graphics, expanding the assistant beyond static text and charts into explorable visual interfaces. The feature complements the company's recent "Intelligent UI" framing and pushes ChatGPT closer to a dynamic application canvas. It is also a defensive move against Google Playground and other prompt-to-experience tools.
