# Reflection debuts Beam, the strongest open-weight model built outside China

Nvidia-backed Reflection released Beam, a 501B-parameter MoE model activating 23B parameters per token. Early tests suggest Beam approaches Chinese open-weight leaders on coding, reasoning, and agentic tasks while using 3–4x less compute. https://the-decoder.com/reflections-beam-becomes-the-most-capable-open-weight-model-built-outside-china/
