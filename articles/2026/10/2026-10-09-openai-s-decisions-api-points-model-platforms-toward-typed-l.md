# OpenAI’s Decisions API points model platforms toward typed, low-latency workflow control

OpenAI’s Decisions API is in public beta for typed outputs such as predicates, choices and rubric scores from text or images. The product direction matters because many enterprise AI use cases require auditable, low-latency decisions rather than long-form generation. If the approach holds up under production evaluation, decision APIs could become a standard control plane for routing, classification and agent workflow gates. CONSUMER AI MODEL ROUTING
