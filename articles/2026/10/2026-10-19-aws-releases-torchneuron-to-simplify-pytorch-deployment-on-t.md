# AWS releases TorchNeuron to simplify PyTorch deployment on Trainium

AWS introduced TorchNeuron, a PyTorch-oriented tool intended to let developers run AI applications on Trainium with minimal code changes. Amazon says roughly 85% of AI applications are written in PyTorch and is contributing changes upstream to make the framework less tied to specific chip vendors. If the portability claim holds in production, the tool could lower migration friction for AWS customers and strengthen Trainium's position against NVIDIA's CUDA ecosystem; actual workload performance and economics still need independent comparison.
