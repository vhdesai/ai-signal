# Walmart opens an agent gateway while rivals continue blocking shopping bots

TechCrunch reported Walmart's MCP-based Agent Gateway and account-level controls for AI-agent transactions, including policy and spending guardrails. The strategy contrasts with retailer approaches that deny third-party agent access entirely. This is a concrete move from conversational AI experimentation toward governed transaction execution.
