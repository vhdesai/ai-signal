# Factory's Droid 1.0 harness has models write sandboxed JavaScript that orchestrates tools, so one model request can…

Factory's Droid 1.0 harness has models write sandboxed JavaScript that orchestrates tools, so one model request can drive hundreds of tool calls while keeping raw outputs out of the context window. Factory reports 65.2% on Terminal-Bench 4 with Claude Opus 5.5, ahead of the other harnesses it tested on the same model, at up to 24% lower cost; these are self-reported results. The release reinforces that harness design, not just model choice, now materially affects agent cost and accuracy.
