# SECURITYMicrosoft adds Guardian Agents to monitor enterprise AI agents

Microsoft introduced Guardian Agents as part of Project Perception and added agent discovery to Defender, positioning agent monitoring as an enterprise security control. The company frames agents as an insider-risk surface because they may access sensitive data and act through consequential tools.
