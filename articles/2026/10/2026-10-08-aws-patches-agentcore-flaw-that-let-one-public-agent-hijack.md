# AWS patches AgentCore flaw that let one public agent hijack every agent in an account-region

Zenity Labs found that one public-facing Amazon Bedrock AgentCore agent could read, rewrite, and delete every other AgentCore agent in the same AWS account and region via an internal credential interface. AWS has patched the issue and tightened default permissions.
