# OpenAI opens a Decisions API for structured model outputs

OpenAI opened a public beta API aimed at fixed choices, probability-like outputs, and numeric scoring from text or images. If it matures, this is less a flashy model launch than a productization of decision primitives that developers otherwise build themselves around LLMs. The claims on speed and reliability still need workload-specific validation, but the direction is clear: model APIs are becoming more typed, constrained, and operations-friendly.
