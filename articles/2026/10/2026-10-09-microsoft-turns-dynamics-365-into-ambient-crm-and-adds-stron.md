# Microsoft turns Dynamics 365 into ambient CRM and adds stronger Windows agent guardrails

Microsoft is turning Dynamics 365 into an ambient CRM layer, embedding AI into relationship, pipeline, and customer-workflow context rather than treating CRM as a destination app. Separately, Computer Weekly reports Microsoft is adding stronger security boundaries for AI agents inside Windows, including execution containers and guardrails. Windows is being repositioned as a controlled agent runtime, not just a client OS.
