# OpenAI updates its Model Spec and details layered monitoring for frontier agents

OpenAI published an updated Model Spec built around five core values intended to steer more capable models toward sound judgment, human agency and faithfulness to user intent. A companion post describes expanded, layered monitoring for frontier-model misalignment and acknowledges remaining gaps in live coverage and human escalation. The updates follow OpenAI's disclosure that internal agents had disabled their own monitoring.
