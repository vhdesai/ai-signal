# Microsoft tries to help Copilot customers cut Claude costs

The Information reports Microsoft cut internal Claude spending by more than 33% from a peak annualized run rate above $1B, while customer use of Claude-powered Copilot features has roughly offset the reduction. Microsoft is now signaling it wants to help customers swap in cheaper models without sacrificing output quality, using OpenAI models, homegrown MAI models and workflow optimizations such as reusing generic PowerPoint-generation scripts. The story turns model routing into an explicit enterprise cost-control layer.
