# JetBrains Air expands as Claude Code plugins become official

JetBrains Air’s early-access program expanded to five IDEs and now runs multiple AI agents, positioning JetBrains as an agentic coding environment rather than a traditional IDE vendor with a chatbot sidebar. Claude Code plugins also became official in version 2.1.302, expanding Claude Code from an assistant into a more programmable developer platform. Both changes raise the stakes for extension governance, credential handling and enterprise review as coding agents gain deeper local access.
