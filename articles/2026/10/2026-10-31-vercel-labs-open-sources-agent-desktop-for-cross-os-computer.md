# Vercel Labs open-sources agent-desktop for cross-OS computer use

agent-desktop is an Apache-2.0 Rust command-line tool that lets an AI agent operate macOS, Windows, and Linux. It reads operating-system accessibility trees and acts on stable element references instead of screen pixels. Accessibility-tree control is likely to be more reliable and cheaper than vision-based clicking, which could make computer-use agents practical for routine enterprise automation.
