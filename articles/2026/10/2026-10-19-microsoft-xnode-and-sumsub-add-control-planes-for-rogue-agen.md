# Microsoft, Xnode and Sumsub add control planes for rogue agents and agent identity

Microsoft unveiled tools to monitor and contain rogue AI agents, extending its recent "agents as insider risk" posture. Xnode launched Cortx Sentinel to control agent actions across cloud marketplaces, and Sumsub expanded "Know Your Agent" for AI access control. These launches define a fast-growing category: agent control planes that sit between models, tools and enterprise systems.
