# Kyutai releases REKI, a 2.4B vision-language-action model for robot manipulation

Kyutai, with Inria and École des Ponts, released REKI, a 2.4B vision-language-action model for robot manipulation pretrained only on public data. The model uses a lightweight memory mechanism for recent visual history and reports strong out-of-distribution benchmark results, including 90.4% on LIBERO-Plus. The release is significant because robotics models are moving toward smaller, open, memory-aware systems that can operate efficiently rather than relying only on very large general-purpose models.
