# 1Password launches delegated agent login without exposing user passwords

TechCrunch reports 1Password for Agents, which lets agents complete account sign-ins through user-approved flows while credentials remain inside 1Password. The model relies on agent identity checks plus explicit user confirmation before session authorization. This addresses a key adoption blocker for agentic commerce and productivity: delegation without credential leakage.
