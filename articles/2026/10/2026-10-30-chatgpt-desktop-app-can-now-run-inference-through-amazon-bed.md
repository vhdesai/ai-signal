# ChatGPT desktop app can now run inference through Amazon Bedrock in AWS GovCloud

AWS says the ChatGPT desktop app is now available on Amazon Bedrock in AWS GovCloud (US) and published a reference deployment that keeps model inference inside GovCloud identities, endpoints and regional controls. The release gives regulated and public-sector buyers a compliant path to OpenAI's client. It is another marker of OpenAI's distribution going multicloud.
